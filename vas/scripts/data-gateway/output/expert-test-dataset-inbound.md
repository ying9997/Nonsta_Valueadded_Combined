## 字段说明

| 字段 | 说明 |
|------|------|
| 测试场景 | PMS 标准异常 eventName（由 EVENT_CODE 映射） |
| EVENT_CODE | 异常事件编码 |
| IS_CHARGE | Y=收费 / N=不收费 |
| 关联增值单 | 是=VASC_CODE 有值 / 否=无增值单 |
| STATUS | CO=已完成 / SBC=待客户确认 / CL=已关闭 / UNR=未识别 / SBF=计费失败 / FBD=已禁止 / TSP=处理中 |
| EVENT_NO | 可直接用于测试的真实单号 |
