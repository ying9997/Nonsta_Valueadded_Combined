# HANDOFF - 非标页内嵌智能引导

> 新会话先读本文。本模块是方案乙，包含标准页 AI 下单指引弹窗前置模块和非标页内嵌智能引导主模块，只维护 `module_非标页内嵌智能引导/` 下的方案、评估、原型和评测材料。

## §0 主线

**目标：** 在万邑联创建增值单链路中增加方案乙智能引导能力：前置模块在标准页通过 AI 下单指引弹窗判断客户真实需求能否由标准增值覆盖；主模块在 Step 2 非标页面内嵌智能引导输入框，客户先自然描述“希望仓库做什么”，AI 基于异常单上下文、候选产品/服务项、当前页面已选值和 SOP 模板库，判断正确路径，并给出页面字段建议。

**三类核心分支：**

| 分支 | 名称 | 成功标准 |
|------|------|----------|
| 2d | 标准增值纠偏 | 客户已进入非标页，但需求可由候选内标准增值覆盖；AI 建议返回标准增值路径，不继续引导填写非标字段 |
| 2a | 命名/具体非标服务直选 | 客户需求命中当前候选内具体非标服务项，且不是“入库/库内/出库其他服务需求”；AI 直接输出应选择的增值产品和服务项，不进入 SOP 长追问 |
| 2b | 其他服务需求 + SOP | 客户需求无法命中具体非标服务项，但可走其他服务需求；AI 先匹配 SOP 模板，有模板则最小追问并生成客户确认摘要，无模板则按 SOP 模板结构追问，不编造 SOP |

**边界：**

- 产品/服务项范围权威仍是 `systemScopedVascList` / `listAllVasc` / `getVascInfo`，AI 不扩推圈定外内容。
- 不宣称已枚举全部非标服务项。
- 不凭空列出类似 `包裹串仓异常调拨` 的服务项；其他具体项必须从候选清单实地枚举。
- 一键填入原字段是目标能力，按钮为【填入需求背景说明】、【填入需求描述】；文字指引 + 可复制内容是降级方案。
- 本期附件能力是“附件要求提示 + 基础元数据轻量检查”，不做复杂附件内容理解，不做强制拦截提交。
- 本期只预留“费用预估待接入”，不实现费用预估。
- 视频 SOP 解析保留为下期迭代，不纳入本期验收。
- 结构化输出 schema 是评测与中间层接口强约束，非法 JSON 应判失败或进入兜底重试。
- 只改本模块文档、原型和评测材料；不改代码，不改其他方案。
