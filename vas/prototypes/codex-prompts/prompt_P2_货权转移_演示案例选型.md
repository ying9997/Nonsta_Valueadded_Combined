### Case 5 核心信息（已确认选用）

- 客户原始表述："账户上的库存可以转移到其他账户上去吗"
- 场景类型：货权转移（改数/换标需追问判断）
- 分流规则：指定SKU全部转移 ≤300个→换标模式；>300个→改数模式；部分库存→换标模式
- 增值产品：库内非标增值（特批）
- 增值服务：货权转移（换标模式）或 货权转移（改数模式）

### 货权转移 SOP 模板（两种模式）

**换标模式**：
```
操作类型：货权转移-换标模式
转出账号：[原账号]
转入账号：[目标账号]
转移SKU：[SKU列表]
转移数量：[数量]
操作步骤：
1. 确认双方签署《商品库存转移协议》
2. 转出方提交出库单（自提单）
3. 转入方提供新入库单
4. 仓库下架指定商品
5. 更换商品标签（贴转入方标签）
6. 按新入库单重新上架
7. 拍照留存
计费方式：按换标数量×单价
```

**改数模式**：
```
操作类型：货权转移-改数模式
转出账号：[原账号]
转入账号：[目标账号]
转移SKU：[SKU列表]
转移数量：[数量]
操作步骤：
1. 确认双方签署《商品库存转移协议》
2. 系统内修改商品货主归属（由IT操作）
3. 更新库存账目
4. 无需物理操作（不换标签、不移动货物）
计费方式：按数据修改笔数计费
备注：适用于指定SKU全部转移且数量>300
```
