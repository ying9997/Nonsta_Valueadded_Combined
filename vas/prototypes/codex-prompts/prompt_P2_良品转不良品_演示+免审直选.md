## §3 文档一：特批 SOP 生成（良品转不良品上架）

### 场景说明

- 交叉验证分类：**B 类**（未上线为命名服务，知识库有模板）
- 系统路由：增值产品="库内非标增值（特批）" → 增值服务="库内其他服务需求"
- 表单需填：需求背景说明 + 需求描述（AI 生成并一键填入）
- 知识库模板来源：3.41【库内】良品转不良品上架

### 使用 Case 1 的核心信息

客户背景（从真实对话提炼）：
- 客户有一批在库商品（SKU 绑定了三方条码）
- 即将有亚马逊退仓货物入库，使用相同三方条码
- 同一三方条码无法绑定两个 SKU
- 客户希望将在库老货转为不良品存储，与新货区分
- 需要：下架旧货 → 无箱单预报新入库单 → 补贴包裹标签 → 按不良品上架

### 演示对话要求

**Turn 1 — AI 开场**（同通用模板）

**Turn 2 — 客户输入**（基于真实表述改写为客户直接口吻）：
```
我有一批货跟马上要退仓入库的新货用了同一个三方条码，系统里没法区分，想把老的那批转成不良品存着
```

**Turn 3 — AI 追问**（识别为"良品转不良品"方向，追问关键信息）：
- 确认 SKU 和数量
- 确认仓库
- 确认是否已有新入库单
- 确认是否需要下架出库单
- 确认转不良品的原因（区分库存 vs 实际不良）

**Turn 4 — 客户补充**

**Turn 5 — AI 判定 + SOP 生成**：
- 判定为 B 类场景 → 路由到"库内其他服务需求"
- 匹配知识库模板 3.41
- 生成 SOP 卡片（操作步骤）
- 展示费用预估占位

### SOP 填充内容

需求背景说明：基于客户描述提炼（客户视角，口语化）
需求描述：基于知识库 3.41 模板填充具体操作步骤

### 金标评测 Case

含 input / expectedOutput / forbiddenOutput，其中：
- expectedOutput.product = "库内非标增值（特批）"
- expectedOutput.service = "库内其他服务需求"
- expectedOutput.sopTemplate = "良品转不良品上架"
- forbiddenOutput 包含："不得推荐'不良品转良品'"、"不得省略下架出库单步骤"

## §4 文档二：免审推荐直选（货权转移）

### 场景说明

- 交叉验证分类：**A 类**（已上线为命名服务）
- 系统路由：增值产品="库内非标增值（特批）" → 增值服务="货权转移（换标模式）"（OSF6V1646）
- **不需要填**需求描述和需求背景说明（该服务有自己的专属表单字段）
- **不需要生成 SOP**
- AI 做的事：识别意图 → 推荐命名服务 → Tool Call 选中 → 完成

### 使用 Case 5 的客户原始表述

```
账户上的库存可以转移到其他账户上去吗
```

### 演示对话要求

**Turn 1 — AI 开场**

**Turn 2 — 客户输入**（真实）

**Turn 3 — AI 追问**（判断改数/换标）：
- 转移哪些 SKU？
- 数量多少？（≤300 换标，>300 改数）
- 全部还是部分？

**Turn 4 — 客户回答**（模拟：3 个 SKU，150 个，全部转移）

**Turn 5 — AI 推荐**：
```
已判断：您的需求属于【货权转移（换标模式）】，这是已上线的库内非标增值服务，可直接选择提交。

已帮您选中：
· 增值产品：库内非标增值（特批）
· 增值服务：货权转移（换标模式）

该服务有专属表单字段，请按页面提示填写相关信息后提交即可。
```

**关键区别**：
- **不生成 SOP**
- **不填需求描述/需求背景说明**
- Tool Call 只有 `select product` + `select service`，没有 `fill`
- AI 告知客户"按页面提示填写专属字段"

### 金标评测 Case

- expectedOutput.product = "库内非标增值（特批）"
- expectedOutput.service = "货权转移（换标模式）"
- expectedOutput.sopGenerated = false
- expectedOutput.requirementBackground = null
- expectedOutput.requirementDescription = null
- forbiddenOutput: "不得生成 SOP"、"不得填入需求描述"、"不得路由到库内其他服务需求"
