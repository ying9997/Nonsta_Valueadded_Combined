# 原型版本对比

四个原型展示同一套 AI 引导链路（标准增值推荐直选 / 非标免审推荐直选 / 非标特批需求填写指引），
区别仅在于"非标特批 AI 指引窗口"以什么形式出现在页面上。

## 版本一览

| 版本 | 文件 | 特批指引窗口形式 | 对原页面影响 |
|------|------|-----------------|-------------|
| A | A_特批指引-表单区展开.html | 在表单区域内直接展开 | 大 — 展开时撑开页面 |
| B | B_特批指引-客服栏对话.html | 在右侧在线客服对话栏内 | 小 — 仅收窄主区域 |
| C | C_特批指引-独立弹窗.html | 弹出一个可拖拽的独立小窗 | 小 — 浮在页面上方 |
| D | D_特批指引-弹窗转表单区.html | 判断阶段弹小窗，填写阶段切回表单区 | 中 — 仅填写阶段撑开 |

## 各版本说明

### A — 表单区展开
- AI 指引窗口（决策 + SOP 填写）直接嵌在卡片选择区和非标表单区
- 展开后把后续内容推下去，用户视线跟着表单走

### B — 客服栏对话
- 点击"AI 下单指引"后，右侧弹出在线客服对话栏
- 整个引导过程在客服聊天窗内完成，一个连续对话流
- 不新增任何弹窗或页面内面板

### C — 独立弹窗
- 弹出一个 400px 小窗，右下角悬浮
- 可拖拽移动、最小化、关闭
- 底层页面始终保持完整不动

### D — 弹窗转表单区
- 判断走哪条路径时先弹小窗（轻量提问）
- 确认走非标特批后小窗自动关闭，表单区内展开 SOP 填写指引
- 两种形态按阶段自动切换

## 体感优劣势

| 版本 | 优势 | 劣势 |
|------|------|------|
| A | 填写效果所见即所得，上下文紧贴表单 | 页面被撑开变长，对线上改动大 |
| B | 复用已有客服入口，用户无学习成本；对页面改动最小 | 栏宽有限，SOP 长卡片需要多滚动 |
| C | 对页面零侵入，开发成本最低 | 小窗可能遮挡内容；SOP 卡片在窗内阅读局促 |
| D | 判断阶段轻量 + 填写阶段就近，兼顾两者 | 两种形态切换有跳跃感；实现最复杂 |

## 演示建议

按 A → B → C → D 顺序给业务方看：
- A 最直观（展开就看到）
- B 最自然（像找客服问问题）
- C 最轻量（弹个窗不影响页面）
- D 最灵活（分阶段用不同形态）

如果业务方倾向"对线上改动最小" → 优先 B 或 C
如果业务方倾向"填入体验最好" → 优先 A 或 D
