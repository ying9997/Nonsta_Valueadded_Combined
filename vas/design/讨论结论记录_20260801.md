## 三、AI 推荐逻辑

| 决策 | 结论 |
|------|------|
| 推荐关系链 | 异常→场景条件→可用增值服务原子（反查增值产品展示） |
| 表述 | "建议选择以下增值服务"（不是"建议以下处理方式"） |
| 数据来源 | 系统事实（VASC list）+ 知识库（SOP 模板）互补 |
| 系统事实 | 线上页面 select options = 客户可选什么 |
| 知识库 | 非标审核 SOP 知识库 = AI 参考什么写 SOP |
| 审核后台下拉框 | 第三种数据，用于审核回填，不等于增值服务原子 |

## 四、SOP 生成与填入

| 决策 | 结论 |
|------|------|
| 一键填入的内容 | 从 SOP 提炼的"需求背景说明"+"需求描述"（客户视角），不是 SOP 原文 |
| SOP 展示给谁 | 展示给客户确认→确认后→操作步骤回填审核端 |
| 客户确认按钮 | "确认 SOP" / "我要修改"两个按钮 |
| 无模板 SOP | LLM 按 6 章结构自由生成，标注"AI 生成，需人工审核" |
| 客户确认后 | = 客户认可，正常提交。审核端标注来源 |

## 五、审核回填

| 决策 | 结论 |
|------|------|
| 回填时机 | 增值单提交后→状态变为"待审核"时自动填 |
| 回填位置 | TOM 审核页面：【场景概述】下拉框 + 【操作SOP】textarea |
| 审核人员 | 可在已填内容基础上编辑 |
| 数据存储 | 需存 LLM 生成版本 + 客户调整版本（为二期语料储备） |

## 六、对话边界

| 场景 | 规则 |
|------|------|
| 客户关闭侧栏再打开 | 保留对话（Coze conversation 原生支持） |
| 客户说"算了不搞了" | "好的，如果后续有需要随时找我。" + 结束 |
| 连续无关内容 | 第 2 轮提示范围，第 3 轮引导转人工 |
| 最大追问轮数 | 初始 3 轮，上线后数据验证调整（不拍脑袋） |

## 七、短期记忆

| 决策 | 结论 |
|------|------|
| 是否需要单独设计 | 不需要，直接复用现有 AI 客服机制 |

## 八、降级容错

| 场景 | 策略 |
|------|------|
| AI 服务不可用 | 侧栏显示"AI 暂时不可用，请手动填写"，页面不阻塞 |
| LLM 响应超时（>15s） | "正在思考..." → 超时提示"请重试或手动填写" |
| JSON 解析失败 | 重试 1 次 → 降级为纯文字建议（不自动填入） |
| 一键填入字段不匹配 | 静默处理 → 提示"自动填入失败，请手动复制" |

## 十、评测集

| 决策 | 结论 |
|------|------|
| 金标集 vs 历史验证 | 两件事：金标=人工理想态（15-30条），历史验证=跑量 |
| 不用平庸数据定义理想态 | 历史客服数据只用于发现覆盖度不够的场景，不作为标杆 |
| 量级 | 每分支 5 条 × 3 分支 = 15 条最低 |
