## 一、复审问题补全说明

### 1. 问题 #1：2d 标准增值纠偏判定依据

2d 标准增值纠偏的运行时判定必须依赖 `systemScopedVascList` 中每个候选 VASC 的标准/非标类型字段。现有 `pms.vasc.listAllVasc` 文档只明确返回 `vascCode`、`vascName`、`vascAttributeMap`，没有可直接用于区分标准/非标增值的字段；`wh.va.order.getVasList` 中虽有 `vasType`，但它属于已下单原子列表，不适合作为 Step 2 候选路由的权威来源。

因此本期口径固定为：需接口侧在中间层注入的 `systemScopedVascList` 候选项上新增 `vascType` 枚举字段，枚举值为 `standard` / `nonstandard`，作为 2d 路由自动化判定依据。

字段定义：

| 字段 | 类型 | 必填 | 取值 | 用途 |
|------|------|------|------|------|
| `systemScopedVascList[].vascType` | string | 是 | `standard` / `nonstandard` | 区分候选增值产品是否为标准增值，供 2d 标准纠偏与 2a/2b 非标分流使用 |
| `systemScopedVascList[].vascCode` | string | 是 | 接口返回编码 | 候选内校验 |
| `systemScopedVascList[].vascName` | string | 是 | 接口返回名称 | 客户展示与按钮文案 |
| `systemScopedVascList[].services[]` | array | 否 | 当前 VASC 下可选服务项 | 2a 命名非标服务项与 2b 其他服务需求判断 |

2d 分支决策逻辑：

1. 输入客户自然语言、异常单上下文、当前页面已选非标值、`systemScopedVascList`。
2. 先从 `systemScopedVascList` 中筛选 `vascType = "standard"` 的候选。
3. 若客户诉求能被标准候选覆盖，且匹配置信达到 `routeConfidence >= 0.75`，输出 `route = "2d_standard_redirect"`。
4. 2d 命中时只提示返回标准增值路径，输出候选内标准增值名称，不生成非标 `fieldSuggestions`，不触发填入非标字段按钮。
5. 若没有 `vascType = "standard"` 候选，或标准候选与诉求不匹配，则继续进入 2a。
6. 若接口未返回 `vascType`，本次原型标注的页面展示降级为“无法自动判断是否应返回标准增值，请按当前非标候选继续填写或联系人工确认”，不得由 AI 自行猜测标准/非标类型。

### 2. 问题 #2：SOP 模板匹配状态字段

废弃原 `sopTemplateMatched` 布尔字段，统一替换为：

| 字段 | 类型 | 必填 | 取值 | 用途 |
|------|------|------|------|------|
| `matchState` | string | 2b 必填 | `matched` / `partial` / `none` | 表示 SOP 模板匹配状态 |
| `matchConfidence` | number | 2b 必填 | 0 到 1 的浮点数 | 表示最优 SOP 模板匹配置信度 |

三种状态的 2b 追问策略：

| `matchState` | 阈值口径 | 页面策略 | 追问策略 |
|--------------|----------|----------|----------|
| `matched` | `matchConfidence >= 0.82` | 展示“已匹配可参考 SOP 场景” | 只做最小追问，围绕模板缺失字段补齐；字段齐全时直接生成客户确认摘要 |
| `partial` | `0.62 <= matchConfidence < 0.82` | 展示“匹配到相近 SOP 场景，需补充关键信息确认是否适用” | 先追问 2 到 4 个关键差异字段，不直接生成完整确认摘要 |
| `none` | `matchConfidence < 0.62` | 展示“未匹配可复用 SOP 场景” | 按《非标增值服务SOP模板》结构追问，不编造历史 SOP |

### 3. 问题 #3：`pageActions` 数组定义

`pageActions` 是 AI 输出给前端消费的页面动作清单，用于标注页面应展示什么按钮、提示、可复制内容或轻量定位。它不替代原页面提交逻辑，不触发自动提交，不绕过审核。

数据结构：

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `action` | string | 是 | 页面动作枚举 |
| `target` | string | 是 | 页面目标区域或字段 |
| `label` | string | 否 | 按钮或提示文案 |
| `payload` | object | 否 | 动作所需内容 |
| `enabled` | boolean | 是 | 当前是否可点击或可展示 |
| `disabledReason` | string | 否 | 不可用原因 |
| `scope` | string | 是 | `phase1` / `next` |

`action` 枚举：

| action | 本期/下期 | 前端消费逻辑 |
|--------|-----------|--------------|
| `show_redirect_notice` | 本期 | 在 AI 指引框回复区展示 2d 标准路径纠偏提示 |
| `show_service_selection_hint` | 本期 | 在 AI 指引框展示应选择的候选内非标产品/服务项 |
| `fill_field` | 本期目标态 | 点击后把 `payload.value` 写入 `target` 指向的原页面字段 |
| `copy_text` | 本期降级态 | 点击后复制 `payload.value`，供客户手动粘贴 |
| `show_attachment_requirement` | 本期 | 在【操作说明附件】上传区域旁展示附件要求 |
| `show_attachment_check_warning` | 本期 | 基于附件元数据展示建议补充/更换附件提示，不拦截提交 |
| `scroll_to_field` | 下期增强 | 滚动到目标字段 |
| `highlight_field` | 下期增强 | 临时高亮目标字段 |
| `open_standard_vasc_selector` | 下期增强 | 自动打开标准增值选择器或跳转标准路径 |

### 4. 问题 #4：SOP 模板匹配机制收口

SOP 知识库索引标准结构：

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `templateId` | string | 是 | SOP 模板唯一 ID |
| `title` | string | 是 | SOP 场景标题 |
| `routeScope` | string | 是 | 固定为 `2b_other_service_sop` |
| `serviceScope` | array | 是 | 适用服务项，必须指向候选内“其他服务需求” |
| `sceneOverview` | string | 是 | 场景概述 |
| `triggerKeywords` | array | 是 | 触发词和业务表达 |
| `requiredFields` | array | 是 | 生成摘要前必须补齐的客户字段 |
| `optionalFields` | array | 否 | 可选补充字段 |
| `attachmentRequirements` | array | 是 | 附件要求 |
| `customerConfirmationPattern` | string | 是 | 客户确认摘要模板，必须包含“确认不等于审核通过” |
| `forbiddenCustomerOutput` | array | 是 | 不可直接对客输出的仓内细节 |
| `sourceRef` | string | 是 | SOP 来源文件或知识库引用 |

向量相似度匹配阈值：

| 阈值 | `matchState` | 处理 |
|------|--------------|------|
| `score >= 0.82` | `matched` | 可复用模板，进入最小追问或确认摘要 |
| `0.62 <= score < 0.82` | `partial` | 相近模板，只追问关键差异字段，不直接输出完整确认稿 |
| `score < 0.62` | `none` | 不复用历史模板，按 SOP 标准结构追问 |

无匹配兜底逻辑：

1. `matchState = "none"` 时，不输出 `matchedTemplateId` 和伪历史 SOP 标题。
2. 页面提示“未匹配可复用 SOP 场景，将按非标 SOP 模板结构补齐信息”。
3. 追问字段按 SOP 模板结构收口：场景概述、业务单据、商品 SKU、需求背景、操作目的、适用范围、操作步骤、关键输出、异常处理、附件要求。
4. 如客户连续两轮仍无法提供关键字段，输出“建议保留当前描述并联系人工确认”，不得编造 SOP。

原型评测时的匹配结果校验标准：

| 校验项 | 通过标准 |
|--------|----------|
| 路由收口 | 只有 `route = "2b_other_service_sop"` 才允许出现 `sopMatch` |
| 候选约束 | `serviceScope` 必须落在 `systemScopedVascList` 候选内“其他服务需求” |
| 阈值一致 | `matchState` 与 `matchConfidence` 所在区间一致 |
| 证据完整 | `matched` / `partial` 必须输出 `evidence`，且证据来自客户描述、异常上下文或 SOP 索引 |
| 无编造 | `none` 不得输出历史 SOP 标题，不得输出完整仓内 SOP |
| 摘要边界 | 2b 客户确认摘要必须包含“确认不等于审核通过”口径 |

### 5. 问题 #5：多轮会话状态边界

会话状态管理硬规则：

1. 客户中途修改需求：同一 `conversationId` 下，如客户输入与当前 `selectedVasc`、`selectedService`、`sopMatch.templateId` 任一关键决策冲突，必须触发路由重算。重算顺序固定为 2d 标准纠偏 -> 2a 命名非标直选 -> 2b 其他服务需求 + SOP。重算后旧的 `fieldSuggestions` 和 `confirmationSummary` 标记为 `stale`，页面按钮置灰，客户重新确认后才能填入。
2. 页面刷新：页面刷新不直接创建新会话。前端若能恢复同一增值单、同一 `eventNo`、同一 Step 2 页面上下文，继续携带原 `conversationId` 和最近一次结构化状态；若候选列表、页面已选值或附件元数据发生变化，必须触发路由重算或附件检查重算。
3. 会话超时：`conversationId` 生命周期从进入非标 Step 2 或首次输入时开始，持续到客户提交、离页、主动清空、或 30 分钟无交互超时。超时后再次输入必须创建新 `conversationId`，只可把历史摘要作为只读参考，不复用旧按钮状态，不直接填入旧字段建议。

会话状态字段示例：

```json
{
  "conversationId": "conv_20260728_event_001",
  "lifecycleState": "active",
  "route": "2b_other_service_sop",
  "stateVersion": 3,
  "lastRouteCalculatedAt": "2026-07-28T18:30:00+08:00",
  "routeRecalculateReason": "customer_requirement_changed",
  "confirmedSummaryVersion": "",
  "staleObjects": [
    "fieldSuggestions",
    "confirmationSummary"
  ]
}
```

## 二、HTML 页面标注

### 1. 页面区域标注

页面依据为线上非标页快照。已验证关键页面元素包括：

- 当前步骤：`2 增值产品信息`
- 当前增值产品：`入库非标增值（特批）`
- 2a 示例服务项：`包裹串仓异常调拨`
- 2b 兜底服务项：`入库其他服务需求`
- 原页面字段：`需求描述`、`需求背景说明`
- 附件区域：`操作说明附件`、`商品和标签的对应关系`、`包裹和标签的对应关系`、`视频拍摄SOP（中文+英文）`、`标签文件`
- 底部按钮：`上一步`、`保存草稿`、`提交`

AI 内嵌指引框固定落点：

| 标注项 | 标注口径 |
|--------|----------|
| 固定位置 | 放在 `增值产品信息` 标题下方、`增值产品` 选择区域上方，作为 Step 2 内容区第一块业务组件 |
| 宽度 | 跟随主内容区宽度，占页面内容列 100%，左右与原表单内容对齐 |
| 最小高度 | 默认空态 160px；回复态根据内容自适应，建议最大可视高度 360px，超出后内部滚动 |
| 层级 | 属于页面内容流，不覆盖原表单；不使用浮层遮挡表格、附件和底部提交按钮 |
| 视觉 | 使用浅色提示框样式，标题为“AI 非标需求引导”，副标题说明“先描述需求，AI 会判断是否应返回标准增值、直选非标服务或补齐 SOP 信息” |

AI 指引框状态：

| 状态 | 展示内容 | 可操作控件 |
|------|----------|------------|
| 默认空态 | 输入框 placeholder：“请描述希望仓库怎么处理，例如需要换标上架、串仓调拨、拍照或其他特殊处理。” | 【发送】按钮；输入为空时置灰 |
| 输入中 loading 态 | 展示骨架屏或三点 loading，文案：“AI 正在根据当前候选服务和异常单信息判断路径，预计 3-5 秒。” | 禁用【发送】；保留【取消本次生成】为下期增强，本期不做 |
| AI 回复展示态 | 展示分支结果、推荐原因、缺失信息、字段建议或纠偏提示 | 按分支展示【填入需求背景说明】、【填入需求描述】、【复制字段建议】等动作 |
| 失败兜底态 | 展示“本次生成失败，请稍后重试；你也可以复制当前需求描述手动填写。” | 【重试】、【复制已输入内容】 |

目标字段落点：

| 页面字段 | 页面位置 | 标注目标 |
|----------|----------|----------|
| `需求描述` | `入库其他服务需求` 行的“服务要求”列内，textarea ID 为 `vaAtoms_OW01V1602_attributes_VAS_ATTR_REL_RD_attributeValue` | 【填入需求描述】按钮写入此字段 |
| `需求背景说明` | `入库其他服务需求` 行的“服务要求”列内，textarea ID 为 `vaAtoms_OW01V1602_attributes_BEOR_attributeValue` | 【填入需求背景说明】按钮写入此字段 |
| `操作说明附件` | `入库其他服务需求` 行的“增值文件”列内，上传按钮 ID 为 `vaAtoms_OW01V1602_vasFiles_VAS_ATTR_REL_AOOI` | 附件要求提示展示在按钮下方、文件格式提示上方 |

附件提示展示区域：

- 附件要求提示固定展示在“增值文件”列对应上传控件附近，优先展示在【操作说明附件】按钮下方。
- 如 `attachmentCheck.status = "warning"` 或 `"missing"`，在附件区域右侧或下方展示浅黄色提示条。
- 附件元数据校验提示弹窗不阻断提交，位置为附件上传区域附近的小型气泡或轻量 modal，标题为“附件建议补充”，按钮为【知道了】和【复制附件要求】。

### 2. 交互按钮标注

【填入需求背景说明】：

| 标注项 | 口径 |
|--------|------|
| 展示条件 | `fieldSuggestions.background` 非空，且当前 `route` 不是 `2d_standard_redirect` |
| 生效条件 | `conversationId` 未超时；`fieldSuggestions` 未标记 `stale`；客户已完成必要确认 |
| 触发逻辑 | 点击后将 `fieldSuggestions.background` 写入 `需求背景说明` textarea |
| 禁用状态 | 缺少客户确认、路由重算中、页面字段不存在、会话超时、字段建议过期 |

【填入需求描述】：

| 标注项 | 口径 |
|--------|------|
| 展示条件 | `fieldSuggestions.description` 非空，且当前 `route` 不是 `2d_standard_redirect` |
| 生效条件 | 与【填入需求背景说明】一致 |
| 触发逻辑 | 点击后将 `fieldSuggestions.description` 写入 `需求描述` textarea |
| 禁用状态 | 与【填入需求背景说明】一致 |

降级方案【复制字段建议】：

- 展示位置：AI 回复卡片底部，填入按钮右侧。
- 样式区分：使用次级按钮；文案为【复制字段建议】，不使用主按钮样式，避免客户误以为已写入页面。
- 展示条件：只要 `fieldSuggestions.background` 或 `fieldSuggestions.description` 有值即展示；当前无法一键写入时仍可用。
- 点击后复制包含字段名的完整文本，客户手动粘贴到原页面字段。

### 4. 响应延迟配套设计

AI 接口 3-5 秒延迟下的页面标注：

| 场景 | 展示样式 | 文案 | 行为 |
|------|----------|------|------|
| 0-1 秒 | 按钮进入 loading | “正在判断需求路径...” | 禁用重复发送 |
| 1-5 秒 | AI 指引框内展示骨架屏 | “AI 正在结合候选服务、异常单信息和 SOP 模板判断，请稍候。” | 保留客户输入内容 |
| 超过 5 秒 | loading 下展示轻提示 | “当前生成较慢，请继续等待或稍后重试。” | 不清空输入 |
| 调用失败 | 失败提示卡片 | “本次生成失败，未写入任何字段。你可以重试，或复制已输入内容手动填写。” | 展示【重试】和【复制已输入内容】 |
| 返回非法 JSON | 兜底重试态 | “AI 返回内容格式异常，系统将重新生成一次。” | 本期最多自动重试 1 次；仍失败则展示失败提示 |

失败兜底样式：

- 不覆盖原页面字段。
- 不自动写入任何内容。
- 不阻止客户继续手动填写、保存草稿或提交。
- 明确提示“未写入任何字段”，避免客户误判。

### 5. 三类分支页面展示差异

#### 5.1 2d 标准增值纠偏

触发条件：客户已进入非标页，但 `systemScopedVascList` 中存在 `vascType = "standard"` 且可覆盖客户诉求的候选。

页面展示：

- 标题：`建议返回标准增值路径`
- 主文案：`当前需求可由标准增值“{selectedVasc.vascName}”覆盖，建议返回标准增值路径选择该服务。本页不继续生成非标字段建议。`
- 按钮：本期展示【复制建议】，不展示【填入需求背景说明】和【填入需求描述】。
- 下期增强按钮：可展示【去选择标准增值】，对应 `open_standard_vasc_selector`。
- 附件提示：不展示非标 SOP 附件要求。

#### 5.2 2a 命名/具体非标服务直选

触发条件：客户诉求命中当前候选内具体非标服务项，且该服务项不是“入库/库内/出库其他服务需求”。

页面展示：

- 标题：`建议选择命名非标服务项`
- 主文案：`当前需求命中候选内服务项“{selectedService.serviceName}”，建议直接选择该服务项；该路径不进入 SOP 长追问。`
- 按钮：展示【复制选择建议】；如该命名服务项存在必填字段且 AI 已生成字段建议，可展示对应填入按钮。
- 示例：命中 `包裹串仓异常调拨` 时，引导客户选择该命名服务项，不把它泛化为“入库其他服务需求”。
- 附件提示：只展示该命名服务项必需附件，不展示 SOP 模板结构追问。

#### 5.3 2b 其他服务需求 + SOP

触发条件：客户诉求未命中 2d/2a，且候选内存在“入库/库内/出库其他服务需求”。

页面展示：

- 标题：`需要补齐非标 SOP 信息`
- `matched` 文案：`已匹配可参考 SOP 场景“{matchedTitle}”，请补充以下必要信息后确认处理方式。`
- `partial` 文案：`匹配到相近 SOP 场景“{matchedTitle}”，还需确认关键差异信息后才能生成摘要。`
- `none` 文案：`未匹配可复用 SOP 场景，将按非标 SOP 模板结构补齐信息。`
- 按钮：客户确认前不展示填入按钮；确认后展示【填入需求背景说明】、【填入需求描述】、【复制字段建议】。
- 固定提示：客户确认摘要必须包含“该确认仅代表确认处理方式和已提供信息，不等于审核通过；最终以增值审核和仓库可执行性为准。”
- 附件提示：展示 `attachmentRequirements`；如附件元数据缺失或不匹配，展示 `attachmentCheck` 建议。

## 三、边界约束

### 1. 同步本期不做清单

本期不做：

- 不承诺审核通过。
- 不自动提交。
- 不做免审，不绕过报价和审核流程。
- 不推荐 `systemScopedVascList` / `listAllVasc` 候选外服务。
- 不宣称已枚举全部非标服务项。
- 不凭空列出候选外服务项。
- 本期不实现费用预估，只展示 `feeEstimatePlaceholder = "费用预估待接入"`。
- 本期不做复杂附件内容理解，不读取真实文件内容，不做图片识别，不做视频解析，不自动上传附件，不强制拦截提交。
- 本期不做视频 SOP 解析，视频 SOP 解析保留下期迭代。
- 本期不实现前端 JS，不做接口联调，不修改线上页面代码。
- 本期不输出接口契约文档，不输出评测集文件；本文中的 JSON 仅用于页面标注和字段落点说明。

### 2. 与 `module_异常单增值客户引导` 的从属关系

`module_非标页内嵌智能引导` 是 `module_异常单增值客户引导` 主线下的非标页内嵌独立切片，服务于“客户在创建增值单 Step 2 主动获得标准/非标增值选择指引”的总目标。

从属关系口径：

- 主线分流顺序保持一致：标准可覆盖先推标准；否则 2a 命名非标直选；再否则 2b 其他服务需求 + SOP。
- 本模块只讨论“非标页内嵌 AI 指引框”路径，不混用右侧在线咨询 AI 侧栏原型。
- 本模块的页面标注只服务 Step 2 非标页面，不替代 `module_异常单增值客户引导` 的固定代发入口、Coze expert、标准推荐矩阵和现有在线咨询 AI 侧栏排期。
- 候选范围权威仍为中间层注入的 `systemScopedVascList` / `listAllVasc` / `getVascInfo`，AI 不扩推。

### 3. 原型范围声明

本原型仅标注交互落点、状态、按钮、字段写入目标、附件提示位置和失败兜底展示，不包含：

- DOM 选择器实现代码。
- 接口请求/响应契约。
- 中间层联调逻辑。
