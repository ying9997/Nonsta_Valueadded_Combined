## 4. 遗留问题与后续建议

- 本契约仍为草案，后续需要前端、中间层和 Agent 实现方共同确认字段命名、错误码和会话超时策略。
- `serviceDomain=return` 当前只保留兜底与扩展入口，若后续要支持退货非标 SOP，需要单独启动切片定义 `2b_return_service_sop`。
- 中间层实现时需补 schema 校验、`pageActions` 白名单过滤和低置信动作禁用逻辑。

## 5. 经验沉淀

接口契约应让 Agent 的自由度收束到“候选内匹配 + 取用 routeBranch”。候选类型、服务语义和路由分支由中间层归一化注入，页面动作由结构化字段驱动，避免自然语言文案反推页面行为。
