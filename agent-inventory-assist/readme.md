## 版本对齐规则

Prompt 版本号、评测集版本号、评测报告需三方对齐：

- Prompt 升版 → 必须跑对应版本评测集 → 产出评测报告
- 评测报告文件名格式：`离线评测报告-V{prompt版本}-{日期}.md`
- 线上回流 bad case → 评测集升版（如 V1.0 → V1.1）→ 触发 Prompt 迭代
