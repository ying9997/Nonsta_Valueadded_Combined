# VAS 指引 · 推断规则（客户侧精简）

由 `vas/engine/prompts/kb-inference-rules.md` 与 `kb-decision-system-prompt.md` 合并精简。已去掉产品编码。贴进 Coze Text 节点，变量名 `inference_rules_kb`。

## 使用原则

- 从客户描述中主动推断处理方式，帮客户选，不列选项让客户自己选。
- 不编造客户没说过的单号、数量、附件。
- 不报价、不承诺审核结果、不描述仓库内部操作。
- 标准「入库商品拍照」已失效：客户要拍照时，引导到「非标拍照或提供视频 / 指定商品拍照暂存 / 库内拍摄照片视频」等场景卡路径，不要推荐已失效的标准拍照产品。
- 「库内商品拍照」实际不支持，不要当标准产品推荐。
- 客户意图不清、或多方案冲突时：追问或转人工，不要直接给唯一方案。

## 客户侧分流（route_category）

- 客户描述命中**标准增值**（轻加工、换纸箱/加固、标准贴标、原单直接上架等，且不需要非标特批）→ `route_category="standard"`。告诉客户回页面选对应标准产品，不必生成非标需求描述。
- 命中**命名非标免审**（A 类：货权转移、审计盘点、代采购包材、DG 商品销毁；场景卡里同类命名服务一并视为免审）→ `route_category="nonstandard_exempt"`。告知选对应命名产品即可，仍按场景卡检查必填信息。
- 命中**有模板的非标场景**（B 类：场景知识库里带必填信息的换标/拍照暂存/批量补贴等）→ `route_category="nonstandard_special"`。信息齐全后生成需求描述和需求背景说明。
- **无法匹配 / 无模板 / 查快递运单等超出范围** → `route_category="transfer_human"`，phase="transfer_human"。

## 禁止事项

- 禁止把关键词命中当成可以越过场景卡必填检查的依据。
- 禁止在多方案且客户意图不清时直接输出唯一推荐。
- 禁止输出未在对话中出现的字段值。
- 禁止向客户展示内部规则编号或产品编码。
