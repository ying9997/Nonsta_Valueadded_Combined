# 时序图你要看懂什么（其余不用懂）

前端发这张图，不是让你去实现 queryToolCall，也不是让你找后台新开 cobra 接口。

他的意思是：**侧栏读写页面我已经做完了。你们只要在对话过程中发出下面两句口令，其余我来做。**

---

## 谁做什么（只记这一张表）

| 时序里的英文 | 人话 | 谁已经做好 | 你要做什么 |
|---|---|---|---|
| EDS 页面 / Page | 卖家后台填单那一页 | 前端宿主页 | 不用做 |
| SDK / AiChatbot | 侧栏聊天窗 | 前端 | 不用做 |
| chatApi / 独立 AI 后台 | 聊天窗后面的服务，把对话转给 Coze | 智能客服后台（已有） | 不用新开接口 |
| queryToolCall | 聊天窗隔几秒问后台「有没有要我办的事」 | 前端轮询，**不是 Coze 节点，不要去画布上找它** | 不用做 |
| pageRead | 「请去读业务页」这句口令 | 前端收到后会读页 | 你在 Coze 用已有插件发出这句 |
| renderA2UI | 「请在侧栏画这张卡」+ commands | 前端按 catalog 画卡 | 你发出这句和 JSON |
| operatePage | 用户点了卡片上的按钮，去点/填业务页 | 前端自己点 | 你只需在卡的 JSON 里写按钮；**不要单独发 operatePage 节点** |
| workflow/run | 把读到的页面内容再送进 Coze 跑一轮 | 前端上报 | 你这边当普通下一轮输入即可 |
| toolCalled | 聊天窗给后台的回执 | 前端打 | 不用画节点 |
| ack | 回执 = 「指令收到了」，不带页面内容 | 前端 | 不用做 |
| PageAgent / loadPageAgent / dehydrated DOM | 前端怎么读 DOM 的内部实现 | 前端 | 阶段一不用懂 |

## 「选择器后面的插件」是哪个？要不要找后台新开接口？

**不要找后台新开。** 也不是时序图里的一个新插件。

Query 画布里已经有很多名叫 **「函数调用」** 的节点，插件名 `cobra_agent_http`，接口名 **`tool_call_send`**。现在用来告诉侧栏「正在思考」（`function_name=stage`）。

你要做的：在 Bot Client 里 **再拖一个同样的「插件」节点**（或从 Query 复制），还是选 `tool_call_send`，只把 `function_name` 换成 `pageRead` 或 `renderA2UI`。

- `Workflow-cobra_api_1-draft-611`：同一插件里 **另一个接口**（查 OMS），不是这个。
- 时序图里的 queryToolCall / toolCalled：**前端和聊天后台之间的约定**，不是 Coze 插件列表里的新工具。

**选择器：** 代码节点算出 `should_send`。真 → 走这个 `tool_call_send` 插件；假 → 直接结束（普通客服问答不要去动页面）。

```
Query 子流程 → 代码 page_intent_emit → 选择器 →（真）插件 tool_call_send → 结束
                                      └（假）直接结束
```

阶段一先导入下面的小工作流，只测代码节点出的 JSON 对不对。测通后再回 Bot Client 加选择器和插件。
