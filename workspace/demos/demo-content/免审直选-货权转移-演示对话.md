# 免审直选-货权转移 — 演示对话内容

> 来源：真实数据
> 原始 Case ID：csdb-nonstandard-guide-3546 / Case 5
> 适用于：免审推荐直选分支 demo

## 选定案例概述

| 字段 | 值 |
|------|-----|
| 客户原始表述 | 账户上的库存可以转移到其他账户上去吗 |
| 对应命名服务 | 货权转移（换标模式）OSF6V1646 |
| 交叉验证分类 | A 类：已上线为命名服务 |
| 增值产品 | 库内非标增值（特批） |
| 增值服务 | 货权转移（换标模式） |
| 表单填充 | 不填需求背景说明，不填需求描述；使用专属表单字段 |

## 完整演示对话（5 轮）

### Turn 1 — AI 开场

AI 侧栏自动弹出后的首条消息：

```text
您好，我看到您正在新增库内增值单。

请描述您希望仓库如何处理库内的这批货物，我来帮您：
· 判断应选择哪个增值服务
· 生成操作 SOP
· 一键填入表单字段
```

### Turn 2 — 客户输入（真实）

```text
账户上的库存可以转移到其他账户上去吗
```

### Turn 3 — AI 追问

```text
可以，这类需求通常属于货权转移。系统里货权转移已上线为命名服务，但需要先判断是换标模式还是改数模式。

请补充三项信息：
1. 需要转移哪些 SKU？
2. 转移数量是多少？如果指定 SKU 全部转移，单次转移单品数 ≤300 个通常走换标模式，>300 个通常走改数模式。
3. 是全部库存转移，还是只转移部分库存？
```

### Turn 4 — 客户回答（模拟，用于判断换标模式）

```text
转 3 个 SKU，一共 150 个，都是这几个 SKU 的全部库存，要从现在账户转到另一个账户。
```

### Turn 5 — AI 推荐

```text
已判断：您的需求属于【货权转移（换标模式）】，这是已上线的库内非标增值服务，可直接选择提交。

已帮您选中：
· 增值产品：库内非标增值（特批）
· 增值服务：货权转移（换标模式）

该服务有专属表单字段，请按页面提示填写相关信息后提交即可。
```

系统动作：

```json
[
  {
    "tool": "select_product",
    "value": "库内非标增值（特批）"
  },
  {
    "tool": "select_service",
    "value": "货权转移（换标模式）"
  }
]
```
