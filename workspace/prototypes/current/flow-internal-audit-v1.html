内部向 · 审核咨询智能体（非客户侧栏）

本页与客户侧 flow-v1.html 并列、勿混用。 用户：审核同事 + 销售/客服（群内协作）；不直连外部客户智能客服。 若图不显示：用 Chrome/Edge 直接打开本文件。

链路开放点（画图已标 ◆，需业务/产品拍板）： ① 描述不完整时是否同时带出附件缺失，避免群内两轮 @； ② 销售/客服补齐后如何回写 OMS、如何再触发智能体（群回复 / 改单后定时扫 / 人工点跑）； ③ 与客户侧提交后「审核 Copilot」是同一套能力复用还是本链路独立批跑； ④ SOP 生成后是仅展示给审核、还是写回单据草稿； ⑤ 定时任务幂等：同一待审单勿反复开话题刷屏。

内部审核咨询智能体 · 流程图

版本：V0.1（业务沟通后初稿）· 与客户侧 F-001 试点并列，非替代
入口：定时任务拉取「待审核」增值单 → 库表取全量（核心：需求描述 / 需求背景说明 + 附件状态）→ 复用既有智能体能力（完整度评估 / 附件校验 / SOP 生成）
追问对象：不直问客户；飞书群开新话题 @ 销售 + 客服（找客户）并 @ 审核同事知会
约束：不做最终审核结论；不承诺时效/费用；校验与追问仍拆开（智能体判缺 → 编排层开口）
