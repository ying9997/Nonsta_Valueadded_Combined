1. **不要用 Cursor 内置预览**（常拦截本地 `file://` 脚本）。
2. 用 Chrome / Edge：资源管理器双击，或拖文件进浏览器。
3. 优先打开英文短名：`current/flow-v1.html`。
4. 确认同目录有 `current/_files/mermaid.min.js`。
