# 方案文档

## 目标

从 `agentic/qa-gen_base.csv` 中抽取“非标页内嵌智能引导”的候选评测用例，优先覆盖：

1. `2d` 标准增值纠偏。
2. `2a` 命名/具体非标服务直选。
3. `2b` 其他服务需求 + SOP。
4. 附件问题候选信号。

## 已验证输入

- `agentic/qa-gen_base.csv` 存在，约 24MB，3158 行。
- CSV 是 qa-gen 知识库/客服数据库导出形态，包含 `question`、`solution_human`、`sys_solution_final`、`possible_scenarios`、`sys_summary` 等字段。
- 源文件不包含完整页面上下文、当前可选 VASC 列表、真实附件元数据、费用或审核结论。

## 节点

| 节点 | 输入 | 操作 | 输出 | 依赖 |
|---|---|---|---|---|
| 1. 读取语境 | AGENTS、叙事 04、value-add-service-guide | 确认任务路由和禁止编造边界 | 抽取口径 | 本地文件 |
| 2. CSV 扫描 | qa-gen_base.csv | 按关键词统计命中量 | 选择候选策略 | Python CSV |
| 3. 原型抽取 | CSV 行 | 启发式打分、2d/2a/2b 分桶、脱敏、Schema 组装 | 候选 JSON/JSONL | 本地脚本 |
| 4. 验证 | 输出文件 | JSON 解析、统计分布、抽样检查 | 验证记录 | 本地脚本 |
| 5. 总结 | 全部产物 | 记录产物和缺口 | 完成总结 | 本地文件 |

## 影响评估

- 新增独立脚本与本地输出，不修改 `value-add-service-guide` 知识库事实。
- 输出只进入候选测试集，默认 `humanReviewStatus=pending`。
- 所有页面/附件/费用/审核信息缺口写入 `needsEnrichment` 或 `evidenceGap`。
