# 出库其他服务需求 — SOP 片段（供生成器用）

出库主单号是 **WO**。禁止套用入库「尺重/标签辨识后换标上架」或任何上架模板。

## 【出库】指定位置贴商品/包裹标签/快递面单

只有自提单才可以补贴快递面单。贴多少张看 TOM 出库单详情 → 打包明细。

```
出库单：[WOxxx]
贴标对象：[商品标签 / 包裹标签 / 快递面单]
贴标位置：[指定位置 / 覆盖 UN3480 UN3481 / 按操作指引]
数量：[打包明细件数]

操作步骤：
1. 按出库单找到对应商品/包裹
2. 按附件操作指引在指定位置贴标或覆盖
3. 继续出库流程
```

## 【出库】暂存单重新装箱

```
暂存单：[VASCxxx]
新出库单：[WOxxx]

操作步骤：
1. 从暂存区取出包裹
2. 按客户装箱思路 / 新订单要求重新装箱
3. 贴新出库单标签
4. 继续出库流程
```

重新装箱及重新打托改数后，可能有包材费及打托费重复收费需退费。

## 【出库】特殊打托需求

```
出库单：[WOxxx]
打托方式：[gaylord 装箱打托 / 客户指定]

操作步骤：
1. 按出库单备货
2. 按客户要求打托（如 gaylord，带盖/不带盖）
3. 拣选后提供拣选明细给客服改数
4. 继续出库 / 交货
```

## 【出库】重新打托（塑料托盘）

```
出库单：[WOxxx]

操作步骤：
1. 按出库单找到已打托货物
2. 改用塑料托盘重新打托
3. 继续出库流程
```

## 【出库】补贴/更换商品标签

```
出库单：[WOxxx]
补贴类型：商品标签（可含包裹箱唛）

操作步骤：
1. 按出库单核对需增值的商品数量
2. 按附件对应关系覆盖旧 EAN / 补贴新商品标签
3. 需要拆箱的先拆箱贴商品标，封箱后再贴外箱箱唛
4. 继续出库流程
```

不要覆盖 EAN 注意事项说明及条码下方网址，除非客户明确要求。

## 【出库】标准出库单拦截

```
出库单：[WOxxx]
拦截原因：[客户要求 / 异常]

操作步骤：
1. 拦截包裹（如已打包）
2. 如未出库，暂停出库流程
3. 按客户要求处理：转新单 / 暂存 / 自提
```

## 【出库】交货时拍照 / 开箱拍照

```
出库单：[WOxxx]

操作步骤：
1. 每个出库单抽 1-2 箱
2. 外箱标签拍 1 张，需清晰可见
3. 开箱拍内部商品标签，每箱抽约 2 件
4. 照片回传后继续交货 / 出库
```
