# F-001 案例书（7 格对照）

场景：入库尺重 / 标签辨识后换标上架（`20250407004`）

**先读 `rules.md` 的主线和 8 条规则，再按规则表回看下面的组。** 单独翻格子没有主线。

扩出来的 10 张标了「扩出」：不在 183 张 F-001 列表里，是按同一异常单号对上的旧单或旁单。

7 格含义：

| 格 | 写什么 |
|---|---|
| 单号 | 增值单号。打回后会换新号，不要拿旧号继续改 |
| 结局 | 已完成 / 已取消 / 异常终止 |
| 审核 | 通过 / 未通过 / 空（接口没给） |
| 异常 | 异常单号 EB。没有就写没有 |
| 上架到哪 | 入库单 WI。扩出单经常没有 WI |
| 要干什么 | 一句话 |
| 2.1 上齐了/缺了什么 | 只对照：对应关系、标签种类、标签文件、上架单、操作说明。接口没字就写「看不出」 |

## 二、扩出来的 10 张，和种子并排

这些单当初没标 F-001 场景（多数场景名为空），所以 183 张列表里没有。用同一 EB 对上之后，才能看见「先失败/先取消，后另开一单」。

扩出单很多**没有 SOP、没有 WI**，2.1 只能写「看不出」。差别主要看：结局、审核、服务名（贴哪种标）。
