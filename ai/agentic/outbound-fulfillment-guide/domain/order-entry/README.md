# 下单与资格

## 目录定位

本目录承载出库下单入口、场景资格和订单创建要求的生成视图，帮助 AI Agent 判断应查询哪些前置条件和结构化信息。

## 计划收录

- 场景与订单类型的适用关系。
- 创建资格、前置条件、必需信息和限制。
- 下单阶段与后续仓内履约阶段的衔接。
- 取消、修改或失败处理在创建阶段的边界。

本目录不保存具体订单、当前库存或线上下单结果，也不凭接口字段存在推断业务支持。

## 生成与维护

- Phase 0 仅保留本 README，不包含业务事实。
- 业务页只从 [Canonical 数据](../../data/canonical/) 生成，不得手工编写。
- 资格结论必须保留场景、订单类型、适用范围、有效期、条件、例外和来源。
- 相关关系同步进入 [关系映射](../../relationship-mappings/) 并接受检索和边界测试。
