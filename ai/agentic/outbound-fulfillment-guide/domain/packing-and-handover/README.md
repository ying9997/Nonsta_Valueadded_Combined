# 包装与交接

## 目录定位

本目录承载包装、打托、贴标及仓库向下一履约责任方交接的生成视图，用于组合对象、动作、产品限制和配置要求。

## 计划收录

- 包装模式与适用对象。
- 打托、称重、贴标和交接阶段的规则关系。
- 包装动作与 VASC 产品、增值服务项、配置字段的关联。
- 交接前后的责任边界、状态变化和证据要求。

本目录不把接口字段、历史案例或空配置推断为标准服务支持，也不保存实时作业结果。

## 生成与维护

- Phase 0 仅保留本 README，不包含业务事实。
- 业务页只从 [Canonical 数据](../../data/canonical/) 生成，不得手工编写。
- 每条适用关系必须保留对象层级、条件、例外、范围、来源和有效期。
- 包装或交接关系变化时同步重建实体、关系映射、配置字段视图和测试。
