# 仓内履约

## 目录定位

本目录承载订单进入仓内后各履约阶段和任务之间关系的生成视图，用于解释仓库处于什么阶段、可能执行哪类任务及其条件。

## 计划收录

- 库存判断与仓内履约前置条件。
- 拣货、复核、称重及其他仓内任务的阶段关系。
- 仓内任务、履约状态、异常和处理动作之间的关联。
- 仓内阶段的可验证开始、转换和结束条件。

本目录不保存实时库存、具体任务进度、操作员信息或生产系统当前状态。

## 生成与维护

- Phase 0 仅保留本 README，不包含业务事实。
- 业务页只从 [Canonical 数据](../../data/canonical/) 生成，不得手工编写。
- 阶段、任务和状态必须区分对象层级与 status domain，不能因名称相同而合并。
- 相关实体、关系、异常和测试必须在 Canonical 变化后同步重建。
