# SLA 与费用

## 目录定位

本目录承载出库履约时效和费用规则的生成视图，用于解释计时或计费口径、适用范围、条件和排除项。

## 计划收录

- SLA 起点、终点、时区、工作日口径和暂停条件。
- 费用类型、币种、计费单位、触发条件和排除项。
- SLA、费用与场景、阶段、承运商、产品、异常或动作的适用关系。
- 规则生效、失效、替代和待核实状态。

本目录不计算具体订单的实时费用，不在缺少有效期或范围时给出确定承诺。

## 生成与维护

- Phase 0 仅保留本 README，不包含业务事实。
- 业务页只从 [Canonical 数据](../../data/canonical/) 生成，不得手工编写。
- SLA 与费用必须保留完整范围、时间、币种或计时口径及来源。
- 规则变化时同步重建关联实体、关系映射、答案测试和过期规则校验。
