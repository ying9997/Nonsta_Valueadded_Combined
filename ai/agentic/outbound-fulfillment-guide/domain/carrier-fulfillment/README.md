# 出库与承运商交接

## 目录定位

本目录只承载面单、仓库出库、集货和承运商接收所需的生成视图，生命周期在交接确认时结束。

## 计划收录

- 与面单生成和仓库出库相关的承运商、派送产品及账号识别信息。
- 仓库、国家地区、尺寸重量及交接前资格限制。
- 集货、交接文件、交接对象、交接确认和责任切换条件。
- Tracked、Non-Tracked、自提等场景在仓库交接终点上的差异。

不收录承运商接收后的首扫、轨迹、运输、派送、妥投或售后能力，也不从单个接口或历史案例泛化产品支持范围。

## 生成与维护

- Phase 0 仅保留本 README，不包含业务事实。
- 业务页只从 [Canonical 数据](../../data/canonical/) 生成，不得手工编写。
- 适用结论必须绑定有证据的产品、地区、范围、时间和例外。
- 产品或承运商变化时只同步检查面单、出库、交接、费用和仓内边界测试。
