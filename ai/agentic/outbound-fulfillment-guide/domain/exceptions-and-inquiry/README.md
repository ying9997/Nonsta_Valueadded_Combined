# 仓内异常

## 目录定位

本目录承载订单创建至仓库出库交接之间的异常和处理动作生成视图。

## 计划收录

- 异常定义、发生阶段、影响对象和证据状态。
- 异常到处理动作及执行角色的关系。
- 下单、库存、波次、拣货、复核、增值、包装、面单、出库和交接异常。
- 异常的恢复、取消、作废、暂存、补充资料或升级边界。

承运商完成交接后的查件、轨迹调查、POD、索赔和派送失败处置不在本次范围。本目录不保存具体订单或任务的实时进度。

## 生成与维护

- Phase 0 仅保留本 README，不包含业务事实。
- 业务页只从 [Canonical 数据](../../data/canonical/) 生成，不得手工编写。
- 异常编码和动作不得凭经验创建，关系必须有明确来源。
- 变化后同步重建相关实体、映射、检索、答案和反幻觉测试。
