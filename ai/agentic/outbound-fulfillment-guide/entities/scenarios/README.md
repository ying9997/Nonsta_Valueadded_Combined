# 场景实体

## 目录定位

本目录承载出库业务场景的生成实体页，用于稳定表达一次履约属于什么场景以及该分类的边界。

## 计划收录

- 场景稳定 ID、规范名称、别名和定义。
- 场景的起点、可验证终点、适用对象和排除范围。
- 与订单类型、履约阶段、派送产品和规则的关系入口。
- 来源、知识状态、适用范围和有效期。

场景分类不保存具体订单，也不能用空范围表示全局适用。

## 生成与维护

- Phase 0 仅保留本 README，不包含场景实体。
- 实体页只从 [Canonical 实体](../../data/canonical/entities/) 生成。
- 新场景必须先有 Schema 合格的 Canonical 记录和项目内来源。
- 场景变化时同步重建资格、阶段、产品映射和检索测试。
