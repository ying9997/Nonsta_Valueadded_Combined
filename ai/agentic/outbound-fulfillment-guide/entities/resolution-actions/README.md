# 处理动作实体

## 目录定位

本目录承载异常或履约问题处理动作的生成实体页，用于描述动作本身、执行角色、前置条件和副作用。

## 计划收录

- 动作稳定 ID、规范名称、定义和执行角色。
- 适用阶段、对象、前置状态、条件和限制。
- 与异常、VASC、费用、SLA 和后续状态的关系入口。
- 来源、知识状态、适用范围和有效期。

“补件”等含义不明确的词不能直接作为正式动作；应先区分补资料、再次派送或新建补发单。

## 生成与维护

- Phase 0 仅保留本 README，不包含处理动作实体。
- 实体页只从 [Canonical 实体](../../data/canonical/entities/) 生成。
- 动作的可执行性不能仅由接口存在或历史案例推断。
- 变化时同步重建异常、状态、VASC、费用关系和答案测试。
