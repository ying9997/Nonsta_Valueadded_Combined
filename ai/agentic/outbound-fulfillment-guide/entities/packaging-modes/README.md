# 包装模式实体

## 目录定位

本目录承载包装模式的生成实体页，用于描述包装方案、作用对象及其适用边界。

## 计划收录

- 模式稳定 ID、名称、定义和对象层级。
- 尺寸、重量、材料或产品等经来源支持的限制维度。
- 与场景、仓内任务、派送产品和服务项的关系入口。
- 来源、知识状态、适用范围和有效期。

包装模式不等同于一次实际包装结果，也不从空配置推断无要求。

## 生成与维护

- Phase 0 仅保留本 README，不包含包装模式实体。
- 实体页只从 [Canonical 实体](../../data/canonical/entities/) 生成。
- 所有限制必须保留单位、条件、范围和来源，未知项不得填经验默认值。
- 变化时同步重建包装流程、产品适用、服务项和字段映射。
