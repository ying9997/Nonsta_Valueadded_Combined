# 生命周期阶段实体

## 目录定位

本目录承载出库履约生命周期阶段的生成实体页，用于描述流程中稳定的业务阶段及其边界。

## 计划收录

- 阶段稳定 ID、定义、进入条件和可验证退出条件。
- 阶段适用的对象层级和 status domain。
- 与仓内任务、状态、异常和处理动作的关系入口。
- 来源、知识状态、适用范围和有效期。

生命周期阶段不是具体订单的实时进度，也不能由单个轨迹事件直接替代。

## 生成与维护

- Phase 0 仅保留本 README，不包含生命周期实体。
- 实体页只从 [Canonical 实体](../../data/canonical/entities/) 生成。
- 阶段转换必须通过 Canonical 关系表达，不能依靠页面排列顺序推断。
- 变化时同步重建流程视图、状态转换映射和边界测试。
