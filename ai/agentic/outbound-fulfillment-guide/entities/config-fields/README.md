# 配置字段实体

## 目录定位

本目录承载增值服务或出库规则所需配置字段的生成实体页，用于描述字段语义、类型、枚举和校验要求。

## 计划收录

- 字段稳定 ID、代码、名称、定义和数据类型。
- 必填条件、枚举值、格式、单位、校验和默认值边界。
- 文件或附件要求及敏感等级。
- 与 VASC 产品、服务项、场景或 API 字段的关系。

字段缺失、空数组或未覆盖记录不能解释为“不需要配置”或“适用于全部”。

## 生成与维护

- Phase 0 仅保留本 README，不包含配置字段实体。
- 实体页只从 [Canonical 实体](../../data/canonical/entities/) 生成。
- 枚举、校验、附件和必填条件必须有字段级证据。
- 变化时同步重建服务项映射、模板、Schema 和字段测试。
