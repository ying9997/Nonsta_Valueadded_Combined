# 费用规则实体

## 目录定位

本目录承载出库履约费用规则的生成实体页，用于表达计费触发、口径和适用边界，而不是存储具体订单账单。

## 计划收录

- 规则稳定 ID、费用类型、币种和计费单位。
- 触发条件、排除项、适用对象和执行阶段。
- 与产品、承运商、异常、动作、VASC 或服务项的关系。
- 来源、知识状态、适用范围和有效期。

缺少币种、计费单位、适用范围或有效期时不得输出确定费用结论。

## 生成与维护

- Phase 0 仅保留本 README，不包含费用规则。
- 实体页只从 [Canonical 实体](../../data/canonical/entities/) 生成。
- 金额和公式必须连同条件、范围、时间及来源保存，不得填入经验默认值。
- 变化时同步重建费用主题视图、适用映射和答案测试。
