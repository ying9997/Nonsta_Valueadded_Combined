# 仓内任务实体

## 目录定位

本目录承载仓内履约任务的生成实体页，用于描述仓库动作类型、作用对象和所在阶段。

## 计划收录

- 任务稳定 ID、名称、定义和对象层级。
- 任务前置条件、完成判据、限制和可能异常。
- 与生命周期、履约状态、VASC 或服务项的关系入口。
- 来源、知识状态、适用范围和有效期。

任务实体不保存具体任务实例、操作员信息或实时作业结果。

## 生成与维护

- Phase 0 仅保留本 README，不包含仓内任务实体。
- 实体页只从 [Canonical 实体](../../data/canonical/entities/) 生成。
- 同名仓内动作与计费服务项不能自动视为同一实体。
- 变化时同步重建仓内流程、状态、异常和相关关系测试。
