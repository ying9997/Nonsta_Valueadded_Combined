# VASC 产品实体

## 目录定位

本目录承载出库相关 VASC 产品的生成实体页，用于描述场景级增值服务方案及其与处理动作和服务项的关系。

## 计划收录

- 产品稳定 ID、代码、名称、定义和状态。
- 适用场景、异常、处理动作、对象层级和限制。
- 所含增值服务项及其必选、可选或条件关系。
- 来源、知识状态、适用范围和有效期。

产品启用状态不自动表示所有仓库、客户和场景都支持，接口中出现产品也不能单独证明可选。

## 生成与维护

- Phase 0 仅保留本 README，不包含 VASC 产品实体。
- 实体页只从 [Canonical 实体](../../data/canonical/entities/) 生成。
- 产品与异常、动作或服务项的关系必须有明确业务来源。
- 变化时同步重建处理动作、服务项、配置字段映射和覆盖测试。
