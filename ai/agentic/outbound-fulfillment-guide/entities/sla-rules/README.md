# SLA 规则实体

## 目录定位

本目录承载出库履约时效规则的生成实体页，用于表达可验证的计时范围和条件，而不是对具体订单作实时承诺。

## 计划收录

- 规则稳定 ID、时效类型、起点和终点。
- 时区、工作日、暂停、恢复和排除条件。
- 适用场景、阶段、仓库、产品、承运商或动作。
- 来源、知识状态、适用范围和有效期。

缺少计时口径、范围或有效期时不得输出确定 SLA。

## 生成与维护

- Phase 0 仅保留本 README，不包含 SLA 规则。
- 实体页只从 [Canonical 实体](../../data/canonical/entities/) 生成。
- 时间值必须连同单位、日历口径、条件、例外和来源保存。
- 变化时同步重建 SLA 主题视图、适用映射和过期规则测试。
