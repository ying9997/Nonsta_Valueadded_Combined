# 异常实体

## 目录定位

本目录承载订单创建至仓库出库交接之间的异常生成实体页，用于解释异常含义、影响对象和发生阶段。

## 计划收录

- 异常稳定 ID、原始编码、名称和定义。
- 发生阶段、影响对象、可能条件和限制。
- 与处理动作、VASC、补充资料、取消、作废、暂存或交接处理的关系入口。
- 来源、知识状态、适用范围和有效期。

异常编码和定义不得凭经验补全；缺少定义或映射时必须保持待核实。

`LAST_JOURNEY` 或其他交接后异常不进入本次实体集合。

## 生成与维护

- Phase 0 仅保留本 README，不包含异常实体。
- 实体页只从 [Canonical 实体](../../data/canonical/entities/) 生成。
- 异常与动作的关系必须有明确来源，不能因相邻展示自动成立。
- 变化时同步重建异常流程、动作映射、覆盖报告和检索测试。
