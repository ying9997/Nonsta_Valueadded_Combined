# 订单类型实体

## 目录定位

本目录承载出库订单类型的生成实体页，用于区分不同履约请求的定义、创建要求和生命周期边界。

## 计划收录

- 订单类型稳定 ID、规范名称、代码和定义。
- 创建前置条件、适用场景和对象层级。
- 与生命周期、派送产品、字段和限制的关系入口。
- 来源、知识状态、适用范围和有效期。

订单类型不等同于具体订单实例，也不得仅凭接口枚举存在判断当前可用。

## 生成与维护

- Phase 0 仅保留本 README，不包含订单类型实体。
- 实体页只从 [Canonical 实体](../../data/canonical/entities/) 生成。
- 代码、名称和支持范围必须分别保留来源，冲突时不得静默合并。
- 变化时同步重建下单资格、场景、生命周期和检索测试。
