# 承运商实体

## 目录定位

本目录承载交接对象所需的承运商生成实体页，只提供稳定身份、别名及与面单、仓库出库和交接有关的关系入口。

## 计划收录

- 承运商稳定 ID、规范名称、别名和识别代码。
- 经来源支持的交接角色和仓库出库适用边界。
- 与派送产品、面单、出库文件和交接方式的关系入口。
- 来源、知识状态、适用范围和有效期。

承运商实体本身不代表尾程能力普遍可用。本次不治理交接后的运输、轨迹、派送或售后能力。

## 生成与维护

- Phase 0 仅保留本 README，不包含承运商实体。
- 实体页只从 [Canonical 实体](../../data/canonical/entities/) 生成。
- 别名归并必须有身份依据，同名或相似名称不能自动合并。
- 变化时同步重建派送产品、面单和交接适用映射。
