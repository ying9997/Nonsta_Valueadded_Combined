# 履约状态实体

## 目录定位

本目录承载 fulfillment status 的生成实体页，通过 status domain 区分订单、库存作业、波次、拣货、复核、包装、出库和交接状态。

## 计划收录

- 状态稳定 ID、所属系统、原始代码和规范化含义。
- status domain、对象层级、进入条件和允许转换。
- 状态下允许或禁止动作的证据关系。
- 来源、知识状态、适用范围和有效期。

承运商完成交接后的扫描和轨迹状态不进入本次模型。同名状态跨系统不得静默合并。

## 生成与维护

- Phase 0 仅保留本 README，不包含状态实体或枚举。
- 实体页只从 [Canonical 实体](../../data/canonical/entities/) 生成。
- 状态转换必须来自 Canonical 关系并保留条件、例外和来源。
- 变化时同步重建仓内生命周期、动作规则和状态测试。
