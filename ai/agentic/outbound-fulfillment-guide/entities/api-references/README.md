# API 参考实体

## 目录定位

本目录承载与出库知识相关的接口来源参考生成页，用于解释字段、编码、状态、查询链路和实时数据边界。

## 计划收录

- 接口参考稳定 ID、用途、业务对象和版本范围。
- 请求或响应字段的规范化含义及对应业务实体。
- 状态、编码、错误或查询链路的来源入口。
- 来源、知识状态、适用范围、有效期和敏感披露边界。

接口参考不能替代业务规则，也不能仅凭字段存在判断产品、动作或 VASC 支持。交接后的轨迹、POD、查件和索赔接口不进入本次来源范围。

## 生成与维护

- Phase 0 仅保留本 README，不包含 API 参考实体。
- 实体页只从 [Canonical 实体](../../data/canonical/entities/) 生成。
- 原始接口资料进入项目前必须完成凭证、签名、Token 和客户数据扫描。
- 变化时同步检查对应实体、状态、字段映射和敏感披露测试。
