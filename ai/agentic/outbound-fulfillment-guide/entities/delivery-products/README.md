# 派送产品实体

## 目录定位

本目录承载派送产品中与面单、仓库出库和交接直接相关的生成实体页。

## 计划收录

- 产品稳定 ID、代码、名称和定义。
- 面单生成、仓库、国家地区、尺寸重量和交接前资格维度。
- 与承运商、包装、称重量方、出库文件、交接和仓内费用的关系入口。
- 来源、知识状态、适用范围和有效期。

产品代码存在不代表所有仓库、客户、国家或场景均可使用，也不能据此推断任何交接后的尾程能力。

## 生成与维护

- Phase 0 仅保留本 README，不包含派送产品实体。
- 实体页只从 [Canonical 实体](../../data/canonical/entities/) 生成。
- 产品能力必须逐项引用当前证据，不能从单一接口字段泛化。
- 变化时同步重建面单、仓库出库、交接适用映射和边界测试。
