# 增值服务项实体

## 目录定位

本目录承载增值服务项、增值原子或增值事件的生成实体页，用于描述可组合的仓库动作、对象和配置要求。

## 计划收录

- 服务项稳定 ID、代码、名称、定义和状态。
- 作用对象、执行动作、条件、限制和附件要求。
- 与 VASC 产品、配置字段、仓内任务和费用的关系。
- 来源、知识状态、适用范围和有效期。

同名仓内动作与服务项不能自动合并；字段为空也不能解释为不需要配置。

## 生成与维护

- Phase 0 仅保留本 README，不包含增值服务项实体。
- 实体页只从 [Canonical 实体](../../data/canonical/entities/) 生成。
- 服务项定义及其字段、附件关系必须分别有来源。
- 变化时同步重建 VASC 编排、配置字段、任务和费用映射。
