# 发布记录

## 目录定位

本目录保存知识版本历史、包外校验摘要和发布状态证据，不保存重复的完整发布包。实际可重建发布产物位于 dist，并且不得成为业务事实来源。

Phase 0 不发布知识版本，不创建 tag、Release 或运行时知识包。

## 收录口径

- 版本号、发布 profile、知识范围和 breaking changes。
- 对应 Git commit、预期 tag、归档摘要和验证结果。
- 本地构建、远程推送、Release、下游导入和线上生效的分层状态。
- 已知缺口、适用边界和回滚或替代关系。

## 维护规则

- 版本记录必须与 [VERSION](../VERSION)、[CHANGELOG](../CHANGELOG.md) 和发布 manifest 一致。
- dist 中的包由构建命令生成，不在本目录复制保存。
- 本地构建成功不得描述为已推送、已发布、已导入或线上生效。
- tag、Release、远程资产和任何外部发布必须获得 Henry 当次确认。
- 发布记录不得包含凭证、外部本机路径或会改变不可变包摘要的运行时时间。
