# 关系映射视图

## 目录定位

本目录把 Canonical 关系转换为可读映射，支持 AI Agent 判断“两个对象是否关联、在什么条件下关联、关系是否可用于回答”。映射页是生成视图，不是独立事实源。

Phase 0 仅建立目录说明，不创建关系结论或空映射文件。

## 收录口径

- 场景与资格、阶段与状态转换。
- 异常与处理动作、动作与 VASC 产品。
- VASC 产品、增值服务项与配置字段。
- 包装、称重量方、面单、派送产品、仓库出库和交接的适用关系。
- 仓内 SLA、费用及其适用范围。
- 事实和关系的来源证据覆盖状态。

本次不生成轨迹、查件、POD、索赔或派送失败处置关系；对应目录存在不代表这些关系进入当前范围。

两个实体出现在同一来源中不自动形成关系。每条关系必须有明确来源或可复现的推导规则，并保留条件、例外、适用范围、有效期和知识状态。

## 生成与维护

- 唯一输入是 [Canonical 关系](../data/canonical/relationships/) 及其引用的实体和受控词表。
- 除本 README 外，不得手工维护映射页。
- Phase 0 不得通过空数组、空表格或占位结论暗示“无条件适用”或“没有配置要求”。
- 关系变化后同步重建正向映射、反向链接、覆盖报告、测试和 [根索引](../index.md)。
- 映射进入运行时前必须通过事实级、关系级、来源和披露门禁。
