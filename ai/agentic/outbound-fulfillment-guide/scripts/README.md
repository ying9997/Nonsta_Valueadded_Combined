# 项目脚本

## 目录定位

本目录保存来源盘点、校验、生成、索引、覆盖、测试和发布构建工具。脚本服务于知识治理，不承载业务事实。

Phase 0 只实现 phase0-skeleton 校验；尚未实现的能力必须明确返回 not implemented 和非零退出码。

## 收录口径

- 可重复执行的 Node.js 与 TypeScript 工具源码。
- 命令参数、输入输出边界和机器报告契约。
- 路径、安全、敏感扫描和 mutation guard 的共用逻辑。
- 后续阶段的生成、覆盖、测试和发布构建实现。

## 维护规则

- 工程修改遵守 [编码规则](../rules/coding.md) 和 [校验规则](../rules/validation.md)。
- 脚本不得把外部来源绝对路径写入项目文件、配置、报告或发布包。
- validate 和 test 不得修改 Canonical 或生成视图；生成命令只能写入声明的目标。
- 所有生成输出应确定、可检查，并记录工具版本和输入摘要。
- 命令返回成功只证明对应 profile 门禁通过，不代表业务知识、发布或外部系统已完成。
