# 术语与受控词表视图

## 目录定位

本目录提供术语、代码、履约状态域、对象层级和别名的可读视图，帮助 AI Agent消歧并稳定检索。内容由 Canonical 受控词表和相关实体生成。

Phase 0 仅建立目录说明，不定义正式业务术语、代码或状态枚举。

## 收录口径

- 业务术语的规范名称、别名、定义和适用语境。
- 代码与其所属系统、对象和有效范围。
- fulfillment status 的仓内 status domain，以及订单状态、仓内任务状态和交接状态的边界。
- 主单、子单、shipment、container、包裹、SKU、任务和 handover 等对象层级。
- 名称冲突、旧称、废弃项和待核实项的显式说明。

## 生成与维护

- 权威输入来自 [Canonical 受控词表](../data/canonical/vocabularies/) 和相关实体。
- 除本 README 外，不得手工维护术语、代码或状态页面。
- 新术语不得只因旧文档出现即提升为规范词；必须保留来源和知识状态。
- Canonical 变化后同步重建本目录、实体交叉链接、检索测试和 [根索引](../index.md)。
- 生成页不得把未知、空值或同名项静默合并。
- 交接后的轨迹和尾程术语只允许作为范围排除说明，不进入当前受控业务词表。
