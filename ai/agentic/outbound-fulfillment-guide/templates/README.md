# 模板

## 目录定位

本目录保存 Canonical、治理记录和来源记录的标准模板，用于约束结构和必填信息。模板是创建内容的起点，不是业务事实或可发布知识。

Phase 0 模板只能使用明确的示例占位值，不得写入真实业务编码、客户数据、凭证或未经验证的规则。

## 收录口径

- 实体与事实记录模板。
- 流程或主题视图所需结构模板。
- 关系和规则记录模板。
- 来源台账与派生记录模板。
- 后续经 Schema 明确定义的治理 artifact 模板。

## 维护规则

- 模板字段必须与 [SCHEMA.md](../SCHEMA.md) 和 data/schemas 下的机器 Schema 一致。
- 示例必须显式标记为示例，不能复制为正式 Canonical 内容后直接发布。
- Schema 变更时同步更新模板、validator、fixture 和相关说明。
- 模板不得包含本机绝对路径、目录外依赖或敏感样例。
- 生成视图不得把模板文件当成来源证据。
