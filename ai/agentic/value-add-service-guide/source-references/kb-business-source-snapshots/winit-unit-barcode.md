# 万邑联导入单品条码（第三方条码入库）流程

背景：通过使用单品条码导入功能，绑定自有单品码（第三方条码）与商品注册SKU码，使后续万邑通入库等作业能通过第三方条码获取到对应商品信息；

# 1  申请权限

如有需要使用自有单品码（第三方条码）时，可以联系商务经理进行申请开通权限，如CE的转非标群组协助处理，如有销售的可联系销售处理。

权限申请链接：https://winitlink.feishu.cn/share/base/form/shrcnzkMjSZP8g7ZXoYQ1QU0dQf

# 3 注意事项

① 、支持自验直发入库--快速自验，需要在验货前维护导入好第三方单品条码；

② 、支持海外验直发入库--海外验货，需要在货物入库前进行导入第三方单品条码；

如未及时进行导入维护，货物到仓后或验货时，会出现扫描第三方条码无法识别的情况，导致货物无法接    收，造成不必要的损失；

# 4  异常：商品有条码但系统无法识别，如果客户有开通第三方单品条码管理，上线有告知客服，异常对应第三方单品码已关联好，需要反馈仓库上架，怎么处理？

您好

请提供异常单号

内部查询

1：系统查询异常单号对应的单品条码XXXX ，复制单品码之后，去TOM-单品管理，用异常的单品条码查询关联关系

![图片展示的是系统界面中单品条码相关内容，其中“35364614000159”这一单品条码被红色框高亮突出显示。该图片对应文档中处理“商品有条码但系统无法识别”异常情况流程里，系统查询异常单号对应的单品条码后，在TOM - 单品管理中用异常单品条码查询关联关系步骤，用于直观呈现查询到的单品条码，以便后续对比异常单挂的入库单下单的SKU与客户第三方单品码关联的SKU是否一致。](img/EK5HwdY3_006.png)

![图片展示的是TOM - 单品管理系统界面。在“单品查询”板块，“商品条码”输入框内显示条码号“2304614802019”，下方有一个蓝色的“查询”按钮。界面下方是查询结果展示区域，目前无记录显示。该图片与上文提到的“系统查询异常单号对应的单品条码，复制单品码之后，去TOM - 单品管理，用异常的单品条码查询关联关系”内容相关，是对查询操作在系统界面上的直观呈现。](img/EK5HwdY3_007.png)

然后对比异常单挂的入库单下单的SKU，跟客户第三放单品码关联的SKU是否一致。

如一致    登记非标增值提交，按照原单重新扫描上架，此增值不收费

如不一致，请客户重新处理第三方单品条码关联。

# 5.第三方单品条码导入关联错SKU怎么办？

1先检查单品条码状态如果状态是未使用。

您好，您可以在这个位置找到关联有误的条码数据，之后全部勾选，点击批量删除，删除后在重新关联导入就好。

![图片展示的是万邑联系统中单品条码管理界面。左侧有“单品条码管理”导航栏标识，界面中显示了单品条码、商品编码等信息。其中，有三个单品条码前的复选框被勾选，右上角有“批量删除”按钮。图片与上下文紧密相关，对应文档中“第三方单品条码导入关联错SKU怎么办”问题下，单品条码状态为未使用时的处理步骤说明，即用户可在此位置找到关联有误的条码数据，全部勾选后点击批量删除，再重新关联导入。](img/EK5HwdY3_008.png)

2，单品条码状态如果是已使用。

您好，抱歉您的第三方单品条码已使用，无法直接修改，需要非标改数，提交非标询价。
