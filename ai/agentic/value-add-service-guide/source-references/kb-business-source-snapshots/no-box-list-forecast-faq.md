# 无箱单有预报常见Q&A

什么叫无箱单有预报？客户下入库单的时候，无需上传/填写装箱明细，只需要输入订单里sku+件数即可，与新自验流程一致。此流程仅限直发海外验

# 无箱单有预报流程使用于哪些业务场景？

答：亚马逊退仓，2B买家退货，第三方转仓

# 无箱单有预报支持什么产品类型？

只支持单一产品，不支持箱产品、套装产品

# 无箱单预报入库单跟正常直发海外验货入库单有什么区别

1，无箱单预报入库单只需要填写sku跟件数,无需填写箱单明细

2，包裹上需要贴上订单码(不能手写,入库单号作为识别码可打印)

3，可选择增值服务:1.全部上架到不良品区(仅限于有良品不良品权限的); 2.单一转箱产品.但仓库会验货时校验是否符合箱产品规格，仅有权限客户可以选择

4，直发地址在入库单提交后才会产生,且直发地址里会包含入库单号

5，入库单需上传识别码，识别码可以是快递单号、入库单号等，识别码必须点击保存.如果是批量上传无需单个点击保存,会自动保存

# 识别码是什么

识别码相当于是包裹条码，识别码需贴在实物上，在入库单关联之后，仓库扫描后会关联到对应的无箱单预报单

# 识别码的类型

识别码类型：入库单号，快递单号，其他。默认请选择。推荐客户使用入库单号作为识别码

识别码的填写需遵循下述规则：

- 识别码不能与其他入库单的入库单号/入库包裹号/快递单号/识别码重复

- 同个订单识别码不能重复

- 除入库单号外，识别码不允许填入WI开头（不区分大小写）的字符串

- 不支持客户使用当前客户编码和当前客户退货ID作为识别码填入

备注说明：快递单号设置半年/一年可重复使用,识别码选择快递的单号 还需要选择对应的物流公司

# 识别码是否支持修改编辑？

你好，入库单状态变更为已上架前，或订单对应的预约单状态是预约成功、等待送仓、已到仓、待审批，则仅支持修改识别码（但已被仓库扫描的识别码不允许删除）

# 识别码下单的时候没有填写后续补录可以吗？

你好， 目前下单至少要填写一个识别码才可以提交订单。

注：可在草稿状态让客户去亚马逊下单获取快递单号后在到仓之前维护在系统并提交订单

# 单一产品转箱产品的增值服务在哪里进行操作

你好，目前仅支持系统在入库下单勾选增值服务，入库阶段自动触发生成。

入库后仓库会检查是否有单一产品有对应的箱产品，如果满足按箱存储的规则，则会按箱上架（即客户勾选了也不一定会进行单一转箱，要按仓库实际操作结果为准）

# 无箱单预报单可以修改winit产品或者仓库吗?

你好，不支持进行修改。

无箱单的入库单下单后/回退草稿后，不可修改winit产品、仓库信息；系统也不支持有箱单的PSC要修改为无箱单的PSC

内部备注：如果客户未发货;但建议客户作废重新下单,若客户已经发出只能修改入库单得情况，走蓝凌非标改数，费用50美金/单

# 无箱单预报单可以修改箱单信息吗？

你好，可以的，但是需要在入库单状态变更为部分到仓之前且无预约单/预约单状态不为预约成功、等待送仓、已到仓、待审批，均支持编辑该入库单的客户订单号、商品信息、直发信息（预计送仓方式不可修改）、其他信息。

# 入库-预报单，系统显示货物已上架完毕，如有后送来的包裹是否还可以直接使用原单上架呢？

您好，不可以，建议创建新预报单，进行上架。

可以

# 货物在退仓入库之后，异常反馈无法识别商品条码，客户才补充关联第三方商品条码，异常怎么处理？

有两种方案处理

方案1：客户提交入库增值换标，换成WINIT商品标签后，用新单号新条码扫描上架，增值单号那边会同步反馈异常关闭。

方案2：客户有开通好商品化以及第三方条码，补充操作第三方条码关联，就可以反馈仓库继续扫描上架处理。

具体步骤：

1 ：客户没有在货物到仓之前关联第三方商品条码。仓库会登记异常：商品有条码但系统无法识别

2：客户收到异常通知后，补充操作关联第三方条码之后告知客服已关联好，需要仓库继续处理上架

3：客服收到反馈之后，需要先核查对应的异常 是否已更新【仓库待处理】（状态在云仓--异常管理-入库异常管理查询）（如没有更新，需要检查客户实际关联第三方条码的操作情况，没有处理关联 系统不会自动更新异常状态）

4：异常更新到【仓库待处理】状态后，仓库才可以用原单处理异常扫描上架。

5：仓库扫描处理完成上架之后，更新异常已处理状态， 关闭异常。
