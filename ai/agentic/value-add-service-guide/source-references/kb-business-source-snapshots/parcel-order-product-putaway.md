# 包裹内出现订单外商品-换新单上架

入库单遗漏下单/验货SKU，到仓后登记了计划外商品，需要做增值上架

步骤一：

先给客户申请上架单权限，指引客户将计划外商品下进去新上架单

内部备注:

在TOM-综合查询--权限申请管理--权限申请单-新增权限申请，选择申请仓内上架单权限

具体申请页面如下

![图片展示的是TOM系统中权限申请管理下的权限申请单页面。页面左侧有多个功能选项，其中“权限申请管理”被红框突出显示。右侧是权限申请单列表，显示了状态、申请编号、权限名称、高广编码、客户名称、申请内容、生效时间、失效时间等信息。页面右上角有“新增权限申请”按钮，该按钮被红框标注，是申请仓内上架单权限的入口。此图与文档中先给客户申请上架单权限的内容相关，指引客户在此页面进行权限申请操作。](img/JV2dwfxW_001.png)

![图片展示的是TOM系统中新增权限申请页面。在“权限类型”选项中，已勾选“PSC客户白名单”。客户处显示“GW01032004061 -- 商品仓内上架-含查验验货”，生效日期为2025年8月12日。页面右下角有“保存并提交”按钮。该图片与文档中“先给客户申请上架单权限，指引客户将计划外商品下进去新上架单”的内容相关，是具体申请权限时的系统操作界面展示。](img/JV2dwfxW_002.png)

然后去提交增值，增值提交步骤如下：

步骤二：去海外仓-异常单，点处理异常

![图片展示的是TOM平台海外仓界面。左侧为功能导航栏，其中“海外仓”被红色框突出显示。右侧是“异常管理”下的“异常单”选项，也被红色框圈出。该图片与文档中“步骤二：去海外仓-异常单，点处理异常”的内容相关，直观呈现了在TOM平台海外仓中找到异常单的操作路径，是完成后续新单上架等操作的指引。](img/AmHDwXvS_001.png)

![图片展示的是TOM系统中“异常处理”页面。页面左侧有导航栏，其中“异常处理”被红色框突出显示。右侧上方有“新建异常”按钮，下方是异常单列表，显示了订单编号、处理时间、WMS订单号、WMS产品、数量等信息，每条记录右侧有“查看详情”按钮，其中一条记录的“查看详情”按钮被红色框标出。该图片与文档中“先给客户申请上架单权限，指引客户将计划外商品下进去新上架单”及“去海外仓-异常单，点处理异常”等操作步骤相关，是处理异常操作的展示页面。](img/AmHDwXvS_002.png)

步骤三： 选增值服务--新单上架（客户创建入库单）

![图片展示的是增值服务页面，其中“新单上架（客户创建入库单）”选项被红色圆圈突出显示。该选项的产品说明为“客户提供入库单，万邑通使用客户提供的入库单操作上架”。此图片与文档中“先给客户申请上架单权限，指引客户将计划外商品下进去新上架单”及“然后去提交增值，增值提交步骤如下：去海外仓-异常单，点处理异常，选增值服务--新单上架（客户创建入库单）”的内容相关，是新单上架步骤中选择增值服务时的界面呈现。](img/JV2dwfxW_005.png)

![图片展示的是“新单上架（客户创建入库单）”的增值服务选项界面。界面中“入库-补贴原商品条码”和“入库-补贴包裹条码”两个选项被红色箭头突出显示。该图片与文档中“步骤三：选增值服务--新单上架（客户创建入库单）”的内容相关，对应下载表格后填写新入库单号和包裹号上传的步骤，直观呈现了增值服务中可选择的补贴条码类型。](img/JV2dwfxW_006.png)

对应下载表格，填写新入库单号和包裹号  上传

![图片展示的是包裹信息下载表格，分为原包裹信息和新包裹信息两部分。原包裹信息包含入库单号、异常单号、包裹条码等；新包裹信息有新入库单号、新包裹条码等。表格中“*”标识的“新入库单号”和“*包裹条码”处有红色背景提示，对应步骤三中填写新入库单号和包裹号上传的操作，是进行增值服务新单上架（客户创建入库单）时的关键信息填写区域。](img/JV2dwfxW_007.png)

收费标准：按照实际换标件数乘以单价计费，不足最低有最低收费

![图片为增值服务收费标准表，重点突出标签类、拍照类、包装类、数量抽验类增值服务项目及对应费用。如标签类中入库 - 更换新商品条码、入库 - 补充原商品条码等增值服务，费用为0.70 - 5.00元/件，是否收取最低收费为是。拍照类上架前拍摄箱照增值服务，费用为4.80 - 5.00元/件。包装类中更换商品包装增值服务，费用为0.60 - 5.00元/件。数量抽验类入库数量抽验增值服务，费用为0.27 - 0.24元/件。](img/JV2dwfxW_008.png)

![图片为增值服务单最低收费表，包含服务项目、增值服务类型、增值服务环节、对应产品、增值服务费用名称、计费单位、计费条件、AU、BE、CA、DE、UK、US等列。增值服务类型有标准增值服务和非标增值服务，增值服务环节有入库增值服务、库内增值服务、出库增值服务等。各列数据以数字和符号呈现，如AU列中AU18、AU35等。该表与文档中关于增值服务收费标准的内容相关，用于说明增值服务费用计算标准。](img/JV2dwfxW_009.png)
