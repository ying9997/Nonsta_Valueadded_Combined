# 包裹条码异常(需客户处理)--需要补贴包裹条码上架

背景说明：包裹条码异常(需客户处理)是指包裹实物已到仓，但包裹条码存在问题，导致仓库无法定位包裹号进行操作上架，会将包裹上架至异常暂存区，需要客户进行处理的异常情况。具体包括以下几种场景：无有效包裹条码：无条码、条码破损无法辨识、包裹条码状态异常、未录入万邑通系统包裹码。包裹上多个冲突的有效包裹条码 A+包裹重复条码

# 异常单未关联入库单场景

一般情况下属于包裹到仓时就无包裹条码，需要客户确认入库单信息进行操作上架，如果无法确认可以走新单-仓内上架单操作，因为入库单未关联入库单单号，增值服务需选择新单上架（不管是上要原单还是新单）。

# 异常单关联入库单场景

一般情况下属于包裹到仓时包裹条码磨损或者包裹条码重复等，需要客户确认入库单信息进行操作上架，
-若客户可以找到原单，增值服务选择原单上架 ，增值服务选择：补贴包裹条码
-若客户无法定位原单，走新单-仓内上架单操作，增值服务选择：补贴包裹条码
