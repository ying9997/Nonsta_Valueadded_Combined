# 非标增值拒接场景

> 在线客服需跟客户了解具体非标需求内容，包括需求具体的操作步骤或者视频（若需要），并且在非标询价中罗列清楚需求和背景，避免多次来回沟通。拒接场景如下，其它非标增值都可根据需求简易难度和仓库沟通是否可接，若无效率成本需运营规划提供成本模型。


未**影响买家出库，货物上架和二次销售**- 需判断会不会影响到买家出库，货物上架，退货是否影响二次销售，如果不满足该条件，则拒接
**不符合仓库操作合规性**- 新增/修改商品说明书
- 新增/修改电池属性
- 退货商品增加塑封膜做原厂包装出库
- 化妆品，化学物品做销毁，例如胶水
- WINIT做纯电/DG商品销毁（需要有电池销毁的供应商）
- 货物带有易燃气体（甲烷，丁烷等）需要仓库做点火测试。
**仓库设备不****支持**- 仓库测商品重量的设备只支持精确度到10g以上，尺寸精确到cm
- 特定工具维修商品（例如：工具：螺丝刀（螺丝刀型号多，仓库不一定有），热风机，电批（测量电量）等）
- 对商品进行通电测试/充电测试（若是商品自带电池，仓库只是启动开关检查商品是否有电可以接）
- 需要仓库穿防护服，护目镜，防辐射的装备，去污水等
- 需要仓库员工肉眼识别货物是否有灰尘操作（例如识别地毯，刷子，纺织上是否有灰尘等）
**需求不清晰****A类包裹****无法做指定批次换标（除批次管理的****SKU****）****A类包裹****不****支持****更换包裹纸箱，仓库可直接上架**A+包裹转FBA不支持单SKU单箱多SI/转第三方物流仓库贴产品条码 **不****支持****帮客户做自提单****供应商****提货预约****不****支持****客户自己员工上门到****WINIT****仓库操作**不支持仓库帮客户检查手机质量- 手机开机后，使用手机自带app播放视频或者音乐，检查声音是否会突然中断
**不****支持****代理进出口清关和代付税金增值**- 代理自提单或非WINIT出库订单出口清关
- 代理入WINIT仓直发订单进口清关或入非WINIT仓库的进口清关
- 所有代付税金增值
**官网无采购客户需求纸箱尺寸链接**- 需了解客户采购纸箱的原因和背景以及官网是否有符合客户需求纸箱尺寸的采购链接

## Q&amp;A

Q：客户可以提交非标询价采购气泡袋或者快递袋吗？

A：英国和美国可以采购气泡袋，美国没有快递袋采购
