# 异常单：入库单状态异常处理方案

# 一、异常定义及触发场景

海外仓场景：订单包裹已到仓，但入库单状态不符合要求无法上架，包含以下情况：直发国内验入库非 “运输中”、直发海外验入库非 “已下单”；订单状态为草稿或终止；直发自验订单未验货完成    注：若符合以下场景，系统将自动提交订单，仓库可直接上架，不生成异常：直发海外验订单信息齐全（已有箱单 / 英德订单已填写进口商）；直发自验订单已验货完成（英德订单已填写进口商）  国内中转仓场景：订单包裹到仓，但订单状态为作废 / 草稿、自验 Winit 承运订单未验货完成

备注说明：

入库单下单后超期未到仓，系统会自动退回到草稿状态，若仍需要继续发货到仓，请编辑入库单重新提交，避免因为到仓时入库单状态异常，产生异常单及异常费，公告说明：[海外仓入库单自动回退草稿功能上线通知]（[万邑联 管理平台](https://seller.winit.com.cn/SystemNotify/view?id=5213)）

# 二、处理方案

## 仓库自动处理

若符合以下场景，系统将自动提交订单，仓库可直接上架，不生成异常：

直发海外验订单信息齐全（已有箱单 / 英德订单已填写进口商）；直发自验订单已验货完成（英德订单已填写进口商）

## 需客户提供处理意见

若选择：要求补贴包裹条码后上架 选择增值： 新单上架（客户创建入库单）/新单上架（WINIT创建入库单） 增值服务选择： 入库-补贴包裹条码
