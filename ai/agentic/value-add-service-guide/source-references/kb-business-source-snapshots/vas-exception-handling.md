# 增值异常处理

> 🤖 **AI 摘要：**本文梳理了三类增值服务异常场景，分别为包裹或商品丢失导致仓库无法操作增值、提交“入库-第三方商品条码关联”增值时不符合对应场景、标准出库订单处于特定出库阶段时无法提交非标增值。针对不同异常场景，分别给出了参照标准申请赔付、按要求匹配对应服务、作废原有出库单后重新提交非标增值的对应处理方案。
> 来源：[飞书文档](https://winitlink.feishu.cn/wiki/BUS8w7U5FiiCtakZGB5cSxepnCd)

# 增值异常处理

常见“异常终止”场景包裹/商品丢失，仓库无法操作增值**🔹 异常场景：**增值操作对象，包裹/商品丢失，仓库无法进行下一步操作

**💡 处理方式：**参考《WINIT赔付标准》申请赔付

“入库-第三方商品条码关联”增值仅支持处理“商品有条码但是无法识别”异常**🔹 异常场景：**“入库-第三方商品条码关联”增值仅支持处理“商品有条码但是无法识别”异常，若客户提交“入库-第三方商品条码关联”增值，系统会强制校验退回

**💡 处理方式：**

标准出库订单状态为“拣选中”、“拣选完成”、“打包完成”、“出库完成”、“派送中” 无法提交非标增值** 🔹异常场景：**标准出库订单状态为“拣选中”、“拣选完成”、“打包完成”、“出库完成”、“派送中” 无法提交非标增值

**💡 处理方式：**无法提交增值，请客户作废出库单重新提交非标增值
