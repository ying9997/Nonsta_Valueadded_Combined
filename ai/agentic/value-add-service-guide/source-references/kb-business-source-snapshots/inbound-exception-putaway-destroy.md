# 入库异常需要处理上架前销毁

海外仓登记了入库异常，客户反馈安排仓库直接销毁处理，需要提交增值上架前销毁

增值提交步骤如下：

步骤一：去海外仓-异常单，点处理异常

# 常见问题

# A+包裹提交销毁增值为什么被退回，退回原因：入库-包裹销毁，增值对象只能是包裹;整单退回，要怎么处理？

回复话术：你好，异常单登记的是包裹/商品，请更改增值选择，选择上架前包裹销毁/上架前商品销毁 ,重新提交增值单。

内部知悉：

客服需要留意检查异常单异常对象是：商品or包裹，

异常单如果挂的是商品异常，增值选择：上架前商品销毁

异常单如果挂的是包裹异常，增值选择：上架前包裹销毁

举例异常单EB0125092622815750  异常对象：商品 增值单：VASC000000165294 选择上架前包裹销毁被退，增值单：VASC000000166866  上架前商品销毁 增值正常完成
