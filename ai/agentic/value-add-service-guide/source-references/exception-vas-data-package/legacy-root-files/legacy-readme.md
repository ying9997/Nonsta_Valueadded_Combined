# 异常与增值服务知识库

本目录是正式知识库，用于沉淀入库异常、增值产品 VASC、增值原子、字段配置和证据来源之间的关系。

## 范围

- 异常是什么，以及异常可选哪些 VASC。
- VASC 的 whole picture，包括适用异常、客户意图、场景分支、原子编排和处理结果。
- VASC 下各原子的属性字段、附件/模板/上传关系字段和字段来源。
- 本地 JSON、TOM 快照、接口文档、SOP 和既有 KB 文档的使用规则。

## 入口文件

- [index.md](index.md)：目录索引。
- [SCHEMA.md](SCHEMA.md)：路径、命名、frontmatter 和标签规范。
- [AGENTS.md](AGENTS.md)：AI 生成和更新文档时必须遵守的约束。
- [log.md](log.md)：变更记录。

## 维护原则

- 先确认数据来源，再写业务结论。
- 不能主观猜测可选、置灰、互斥关系。
- 不能把普通属性字段、附件字段、页面上传关系混写。
- 文档应保留未确认点，方便后续补证据。
