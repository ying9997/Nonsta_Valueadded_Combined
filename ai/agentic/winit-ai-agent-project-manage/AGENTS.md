# AGENTS — 仓库协作说明

面向在本仓库工作的 **人机协作 / Agent**：计划、结论与 Prompt 均以 **可追溯、可对齐数据源** 为准；修改文档前请先理解结构与口径。

---

## 工作前先同步

- **`git pull`**：查看或编辑计划、报告前，**先拉取远端**，避免在过期版本上改字或重复劳动。
- 本仓库以 **Markdown 文档与 prompt 资产** 为主，一般无构建命令；若后续增加脚本，在对应目录补充说明即可。

---

## 仓库用途

万邑通 **AI 客服项目** 的分析、周计划、OKR/目标基线、专家说明与分类提示词集中地；与飞书 Wiki、群聊、业务表同步时，优先在文档中 **标注数据源或链接**。

## 编辑约定

1. **整体项目目标**：若业务重排路线或数字，以飞书主表为准更新 **`README.md` →「整体项目目标」**，并保留/更新该节 **数据源** 链接。
2. **综合分析长文**：新版本请另存为 **`reports/万邑通AI客服项目分析报告-YYYYMMDD.md`**（或带版本后缀的清晰命名），**不要**覆盖历史归档件（除非勘误）。
3. **周计划 / 专项计划**：新阶段尽量 **新建独立报告**（如已有 `W20-W21-入库任务计划.md` 模式），避免把无关阶段塞进已封口的周次文档。
4. **少而准**：只改任务相关段落；不擅自扩大范围（例如顺带大改无关文档），除非用户明确要求。
5. **中文**：面向团队的说明与标题默认使用 **简体中文**（专有名词、代码与 URL 保持原文）。
