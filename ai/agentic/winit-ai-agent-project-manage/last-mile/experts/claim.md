## 一、支持索赔场景

| 场景 | 说明 |
|------|------|
| **丢失（未妥投丢失）** | 标准出库单尾程运输中包裹一直没有更新妥投，轨迹出现断更等情况 |
| **破损** | 标准出库单轨迹更新显示包裹破损或者买家收到反馈包裹破损 |
| **妥投未收到** | 标准出库单轨迹显示已妥投，但是买家反馈未收到 |

## 三、标准时效

| 阶段 | 时效标准 |
|------|---------|
| **受理时效** | 提交后 **1 个工作日内** 完成受理 |
| **调查时效** | 平均 **XX 个工作日**，部分渠道时效可能大于 XX 个工作日，具体以对应渠道赔付说明为准 |
| **赔付到账时效** | WINIT 收到供应商赔偿款且核对无误后，**3 个工作日内** 提交财务退款至卖家账号 |
| **内部价卡时效** | 按对应渠道价卡规则执行 |

## 四、基于状态的标准回复话术

### 情况1：出库单暂未提交代客索赔

> 你好，出库单未查询到提交代客索赔申请，可在万邑联 → 售后管理 → 代客索赔管理 → 新增代客索赔件进行代客索赔申请

---

### 情况2：代客索赔状态 = **草稿**

> 您好，此单代客索赔为草稿未提交状态，请您在草稿单页面点击提交，完成后我们将为您跟进处理。

---

### 情况3：代客索赔状态 = **已提交**（尚未受理）

| 提交时间 | 话术 |
|----------|------|
| **≤ 1 个工作日** | 您好，此单代客索赔刚提交，请耐心等待受理，我们会持续跟进进度。 |
| **> 1 个工作日（超期未受理）** | 您好，此单代客索赔受理已超期，我们已为您申请加急处理，会尽快同步受理进度。 |

---

### 情况4：代客索赔状态 = **已受理/已提交供应商**

| 提交时间 | 话术 |
|----------|------|
| **≤ X 个工作日（调查初期）** | 您好，您的包裹已提交至物流商进行调查，目前尚在调查初期（提交第 X 天）。代客索赔平均调查时效为 XX 个工作日内，我们会持续跟进，一旦有结果将立即通知您，请您耐心等待。 |
| **X ～ XX 个工作日（调查中）** | 您好，包裹目前正在物流商调查中（提交第 X 天），暂未收到最终反馈。我们已为您备注催促，正常调查时效内请您稍候，有进展我们会第一时间同步。 |
| **> XX 个工作日（超期未出结果）** | 非常抱歉，代客索赔已超过平均代客索赔时效仍未返回结果。我们已升级给索赔专员加急跟进，要求物流商优先处理，有结果会第一时间邮件反馈给您，请您稍等。 |

---

### 情况5：代客索赔状态 = **供应商确认赔付待到账 / 待付款**

> 您好，您的代客索赔已由供应商确认赔付，目前款项正在待支付流程中。WINIT 收到赔偿款并核对无误后，将在 3 个工作日内提交财务退款至您的海外仓账户，请您留意账户余额变动。

---

### 情况6：代客索赔状态 = **已完成**

#### 子情况 6.1：索赔被拒

> 您好，您的代客索赔已调查完成，结果为**索赔被拒**，拒赔原因为：【此处填写具体拒赔原因】。若您对结果有异议，可在规定时效内提交申诉，具体申诉路径可咨询我们。

**常见拒赔原因及处理：**

| 拒赔原因 | 处理指引 |
|---------|---------|
| **包裹退回/退回到仓** | 供应商调查反馈已退回发件人，请客户留意查询退货单<br>查询路径：<br>1. 卸货精准查询 → 海外仓 > 退货管理 > 退货轨迹记录<br>2. 卸货模糊查询 → 海外仓 > 入库 > 入库限制查询<br>3. 退货单查询 → 海外仓 > 出库全部订单 > 出库单详情页 / 退货管理 > 退货全部订单 |
| **已妥投（索赔类型：丢失/非妥投未收到）** | 通用话术：您好，您的包裹已经投递，请您联系收件人核实是否收到包裹。<br>• **支持申诉**：DE DPD 和 DE DHL 渠道，支持签署"未收到声明"进行申诉<br>• **不支持申诉**：其他渠道，已妥投无法申请索赔 |
| **索赔资料不符** | 典型问题：发票（含中文/税率不符/金额不符）、货值证明（不完整/缺少英文）、照片（不符合规范）<br>处理要求：<br>1. 所有证明文件必须为**全英文**（含买卖双方信息、价格、日期、付款方式）<br>2. 确保发票金额与索赔金额一致<br>3. 破损需提供外包装图 + 内包装及填充物图<br>4. 在理赔时效截止前重新提交 |
| **收件人未备案** | 部分渠道要求买家在当地完成破损备案，未备案/超时效将拒赔<br>• **时效内**：联系买家完成备案 → 重新提交申诉<br>• **超时效**：无法申诉和赔付 |
| **买家不配合调查** | 物流商需电话核实，买家失联导致无法联系将拒赔<br>• 时效内：请买家配合联系物流商 → 重新提交申诉<br>• 超时效：无法赔付 |

#### 子情况 6.2：索赔成功/已赔付客户

> 您好，您的代客索赔申请目前状态为**已退回**，需您补充 / 修改相关信息后重新提交。退回原因为：【此处填写具体退回原因】。
>
> 退回原因查询路径：万邑联 → 售后管理 → 代客索赔管理 → 全部代客索赔

**常见退回原因处理：**

| 退回原因 | 处理指引 |
|---------|---------|

## 五、加急处理规则

### 场景1：提交时间 ≤ X 个工作日 → 无需加急

> 您好，核实到您的查件申请提交尚未满 1 个工作日。目前工单正在正常受理流程中，物流商系统同步及受理需要一定时间。建议您先耐心等待，我们会按标准时效持续跟进，一旦有受理进度会立即更新，感谢您的理解。

---

### 场景2：提交时间 > XX 个工作日 → 可加急，需询问原因

> 您好，理解您对包裹进度的焦急。目前该单代客索赔已提交超过XX个工作日，我们可以为您尝试申请加急催促。 为了更有效地向物流商施压，**麻烦您提供一下具体的加急原因**，我们备注后可优先升级处理。

客户告知原因后：

> 已经为您登记加急需求并备注具体原因，现已升级给索赔专员优先催促物流商。 温馨提示： 虽然已申请加急，但最终回复时效仍取决于物流商的调查进度（代客索赔平均调查时效为 30 个工作日内，部分渠道大于该时效）。我们会密切监控，一有最新进展会第一时间邮件/消息反馈给您，请您稍候。

---

### 场景3：超过渠道调查时效 → 超期必须升级

> 非常抱歉，该单代客索赔已超过平均调查时效。我们非常重视您的体验，已将此单标记为"超期"，并升级给索赔专员进行专项跟进。我们会要求物流商优先处理此单，有结果会第一时间通知您，感谢您的耐心等待。

## 六、AI 处理要点

### 关键参数提取
1. **出库单号 / 索赔单号 / 快递单号** → 用于查询索赔状态
2. **客户诉求类型** → 进度查询 / 时效咨询 / 赔付状态确认
3. **客户是否要求加急** → 判断是否需要走加急流程
4. **加急原因** → 如果要求加急，必须获取原因才能升级

### 需要对接的系统数据
- TOM / 万邑联系统 → 查询索赔单状态、提交时间、当前处理节点
- 索赔状态机 → 根据状态返回对应标准话术
- 渠道配置表 → 获取不同渠道的调查时效标准

### 特殊规则
- **话术标准化**：严格按照SOP使用标准话术
- **超期必须升级**：超过调查时效必须内部升级到尾程救火群
- **资料要求严格**：必须告知客户所有证明文件必须全英文
- **渠道差异**：不同渠道支持的索赔类型不同（如仅DE DPD/DE DHL支持妥投未收到申诉）
