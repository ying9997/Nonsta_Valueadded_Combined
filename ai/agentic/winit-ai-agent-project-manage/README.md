### KR-1：AI-Driven 客服智能体（客服）— 提升 AI 客服有效覆盖率

#### 核心指标

**AI 对话自动化处理率（场景覆盖率）≥ 80%**

- **分母**：**AI 处理的数据部分** + **从 AI 转人工处理的数据部分**。
- **假设与波动**：分阶段数字为规划目标；每推进一块，可能因前期问题识别不透而在运营中补洞，叠加用户心智培养，**实际曲线可能非单调**（甚至出现阶段性回落后再增长）。

#### 分阶段目标（场景覆盖率）

| 时间 | 目标覆盖率 | 环比增量 | 建设主题 |
|------|------------|----------|----------|
| 4 月 | **35%** | +20% | **尾程售后** — 轨迹咨询 / 查件 / 索赔 |
| 6 月 | **50%** | +15% | **入库环节**流程提升 |
| 6 月 | **55%** | +5% | **平台同步**咨询 |
| 8 月 | **65%** | +10% | **出库流程**提升（场景分类见下） |
| 9 月 | **70%** | +5% | **退货流程**提升 |
| 10 月 | **75%** | +5% | **商品咨询** + **库内丢失** |
| 12 月 | **80%** | +5% | **费用核实 / 充值 / 价卡解读** |

#### 4 月 — 尾程售后（35%）能力要求

- **出库单**：能准确解读出库单状态（包括暂存、增值等场景）。
- **尾程轨迹**：准确解读尾程轨迹，调用订单状态与轨迹标识判断原因：
  - 能够读取 **供应商与 Winit** 两侧轨迹状态，结合当前时间与业务规则做出正确解读。
  - 能够 **代客户发起查件**，或告知客户 **在哪儿查件**。
  - 必要时给出 **正确的服务商电话**，要求买家协助联系。
  - 实现 **vPOD / ePOD** 的实时校验，判断是否 **符合** 规范。
  - 客户需要时能提供 **妥投证明**。
- **查件 / 索赔业务 AI 化**：实现查件/索赔人工流程中 **80%** 常见场景 —
  - 能够解读查件/索赔状态并正确返回给客户；
  - 理解业务赔付标准，并能根据场景对应赔付标准。
- **面单**：实现 **面单获取流程化**。

#### 5 月 — 入库流程（50%）场景分类

- 数据整理 — 人工客服 / AI客服 / 内部商务咨询，找出入库咨询的部分，判断哪些无法被当前qa-gen知识库解决
- 对齐场景并完成应用

#### 8 月 — 出库流程（65%）场景分类

- 出库管理 — **超时未出库**
- 出库管理 — **出库调查申请**
- 出库管理 — **退费申请**
- 出库管理 — **自提单出库确认**
- 出库管理 — **增值操作指引**
- 出库管理 — **自提仓库信息获取**
- 出库管理 — **异常处理**

#### KR-1 【衡量指标】

| 指标 | 目标 |
|------|------|
| **AI 回答准确率** | ≥ **95%** |
| └ 知识库匹配类 | > **95%** |
| └ 订单查询类 | > **98%** |
| └ 内部流程协作类 | = **100%** |
| └ 主动操作类 | = **100%** |
| **AI 首次解决率**（观测值） | ≥ **80%**（无二次询问、无人工接入的解决比例） |
| **AI 响应时长** | **P50** ≤ **20** 秒；**P95** ≤ **40** 秒 |
| **AI 咨询后客户满意度** | ≥ **90%** |

### KR-2：万邑联主要功能页（含报错页）— 可交互且答案准确

#### 能力范围

1. **UI / 业务功能辅助引导**
   - 日常使用中，主要页面功能有 **AI 辅助说明**，并解答 **当前操作中** 的常见问题 — **（2 月）**
   - **增值服务**时，告知客户如何 **搭配增值选项** — **（6 月）**
2. **报错解读**
   - 解读报错码含义，结合 **Q-s（Q&A / 知识库）**，告知客户：错误 **因何产生**、**有哪些解法**、**应如何操作**、**下次如何避免** — **（6 月）**

#### KR-2 【衡量指标】

| 指标 | 目标 |
|------|------|
| 主要功能界面常见问题覆盖率 | **100%** |
| 报错码 / 报错信息覆盖率 | **95%** |
| 回答准确率 | **95%** |

### 【效果场景】

客户在使用 **万邑通订单履约服务** 过程中遇到的疑问，可以通过 **万邑联页面内嵌的 AI-Driven 客服智能体** 做快速咨询并得到解答：

- 客户在操作过程中途径的 **主要功能**，能够获得 **AI Agent** 的辅助引导并解决。
- 客户在操作过程中遇到的 **系统报错**，能够获得 **AI Agent** 的解答，告知可能的原因和处理方法，并 **跟踪解决**。
- 客户使用过程中，**AI 遵循已共识的方案** 指导客户解决问题。

### 「解决」定义（闭环）

**解决**：跟踪客户直至确认解决，**从客户处获得是否已解决** 的反馈。

**未解决**：**人工转接**，且人工侧 **100% 解决**。

## 当前项目状态 (Q1 2026)

- **目标**：通过AI自动化处理海外仓客服咨询
- **灰度放量**：已覆盖 2289 家客户，覆盖率 **82.88%**
  - 业务线：覆盖率 84.29%，准确率 64.41%
