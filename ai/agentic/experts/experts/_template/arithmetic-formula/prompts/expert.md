# 领域说明：四则运算（仓库拆分用）

> **线上 Prompt**：运算规则正文已**内嵌**于 `main.md` 的 **「领域背景：四则运算规则」** 一节，避免 LLM 无法访问本文件。  
> 本文件仅作仓库内独立编辑、或供其它非 `llm-comment` 节点复制；修改规则时请同步更新 `main.md` 中对应段落。

- **优先级**：先 `*` `/`，后 `+` `-`；括号内先算。
- **允许**：非负/正数、小数、空格。
- **不允许**：除 **`SKU_QTY(wh=,sku=)`** 与（单独使用时）**`SKU_QTY`**（由代码节点替换为数字）外的变量、函数、`**` 幂、`//`、百分号未转换等。

代码节点 `evaluate-expression` 使用与 JavaScript 相同的运算顺序（括号 → 乘除 → 加减）。
