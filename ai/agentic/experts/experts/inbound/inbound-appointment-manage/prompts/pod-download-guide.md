# 预约单 POD（签收证明）下载指引

> **客服 Agent 不调用** `wh.inboundSigned.exportPodPdf`（B.6）。该接口返回 **base64 编码的 PDF**，当前 Agent 对话通道**无法将文件/base64 附件安全投递给客户**，因此只能引导客户在 **万邑联自行下载**。

## 什么是预约 POD

预约 POD 是仓库对**按预约送仓**货物完成卸货/签收后生成的**签收证明 PDF**，与预约单（booking）绑定，用于客户留存或对外证明「货已按约到仓」。

## 何时可以下载

| 预约状态 | 代码 | 能否下载 POD |
|----------|------|----------------|
| 预约成功、未到仓 | SBO | **否**，需等待货物到仓 |
| 已到仓 | RBO | **是**，一般可下载 |
| 到仓异常 | EXRBO | 视平台是否生成；建议万邑联查看或联系客服 |
| 已取消 | CANCEL | **否** |

客户 ERP 对接时序：创建预约 → 定期查 `list` → 到仓后由**客户系统**调 `exportPodPdf` 落盘。  
**客服场景**：不调该 API，只告知万邑联入口与前置状态（RBO）。

## 万邑联操作步骤（客户自行下载，唯一可行路径）

1. 登录 **万邑联** → 海外仓 → 入库 → **预约单管理**
2. 按 **预约单号** 或关联 **入库单号（WI）** 找到对应预约单
3. 确认预约单状态为 **已到仓**（RBO）
4. 在预约单详情/操作栏选择 **下载 POD** / **签收证明** / **导出 PDF**（以平台当前文案为准）
5. 保存 PDF 到本地

**勿向客服索要「发 POD 文件/截图」**：Agent 不能代调 `exportPodPdf`，也不能在对话中转发 PDF/base64 附件。

在线预约入口 **booking.winit.com.cn** 与万邑联预约单管理功能一致，可在同一入口尝试下载。

## 常见问题

| 情况 | 处理 |
|------|------|
| 找不到下载按钮 | 确认是否已到仓（RBO）；未到仓需等待 |
| 状态仍 SBO | 货物尚未按约完成到仓签收，暂无 POD |
| 需要签收时间/包裹数明细 | 可同时查入库单轨迹 → `inbound-arrival-status` |
| 快递逐件面单（免预约） | 无预约单 POD；卸货记录走快递轨迹专家 |
| 系统无预约记录 | `requiresManualAction=true`，引导客服核实 |

## 与到仓专家的分工

| 问法 | 本专家 | `inbound-arrival-status` |
|------|--------|--------------------------|
| 怎么下载预约 POD PDF | ✅ 本指引 | — |
| 货到了吗 / 签收了几件 | 仅看预约状态 RBO | ✅ 轨迹与签收摘要 |
| PEWC 为何未变 EWC | — | ✅ |

## 对客原则

- **永不**代客调用 `exportPodPdf`（base64 响应无法经 Agent 发给客户）
- 不承诺客服可「邮件/聊天发送 POD 文件」
- 有 WI 时仅查预约状态（`booking.list` / 表头）判断是否 **RBO 可下**，不提供文件内容
- 不索取客户账号密码代登录万邑联
- 不输出内部 API 名、base64 或飞书链接
