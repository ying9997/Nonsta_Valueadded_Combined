# 预约送仓操作规范

## 通用说明

- **适用链路**：卖家直发产品（OW01021/22/31/32）+ 客户自验/海外验货；货物到海外仓前须预约送仓时段
- **标准头程 OW01011** 通常由 Winit 安排，客户无需预约
- **操作入口**：万邑联 → 海外仓 → 入库 → 预约单管理 → 新增预约单
- **在线预约**：booking.winit.com.cn（与万邑联预约单管理同功能）
- **核心判断**：每个包裹是否有**独立快递面单** → 有则快递免预约；无（托盘/散件/整柜）→ 必须预约
- **送仓方式一致性**：预约单送仓方式须与入库单创建时选择的一致，**不可在预约单级别修改**；变更须将入库单「回到草稿」重选 PSC
- **Slot 查询**：在万邑联预约页面查看可约时段；仓级负载不对客透露（→ `inbound-capacity-availability` 仅答客户额度）

## Express 快递（免预约）

| 情形 | 是否预约 |
|------|----------|
| 逐件快递面单派送 | **不需要** |
| 打托整托送仓但每包裹独立面单 | **不需要** |
| 快递托盘（一托只贴一张面单） | **必须预约**（按散货处理） |

**风险提示**：
- 下单选散货、实际快递送 → 产生散装卸货费，**不退费**
- 下单选快递、实际散货到仓 → 产生未预约违规费，**不退费**

## LCL 散货

1. 确认入库单送仓方式为散货（LCL），且已进入可预约状态（通常在途 TS 后可约）
2. 万邑联 → 预约单管理 → 新增预约单（或在「待预约」列表勾选）
3. 勾选需预约的入库单：**同一目的仓**且均为 LCL 才可合并；**不可与 FCL 混约**
4. 在预约页查看可约 **Slot**（仓库当地时间），填写：目的仓、预计到仓日期、送仓数量（CBM/件数）、联系人电话（建议填**司机电话**）
5. 至少提前 **1 个自然日**预约；最早可提前 **12 天**
6. 提交后获取**预约码**，送仓时告知司机凭码送货

**卸货方式**：LCL 一般为 **LIVE**（现场卸货）

## FCL 整柜

1. 同 LCL 入口，送仓方式选整柜（FCL）
2. 至少提前 **2 个自然日**预约（建议 2–3 天以确保 Slot；迟取消可能产生费用）
3. **必填**：送仓联系人（姓名/邮箱/电话，电话建议**司机电话**）、柜型、柜号、托盘数；有封条号则填写
4. 确认卸货类型：
   - **DROP**（仅 FCL）：司机落柜后离开，美国整柜多为 DROP；到仓时间以预约卸货时间为准
   - **LIVE**：司机现场等候卸货；到仓时间以实际到仓为准
5. 柜型可选：20GP / 40GP / 40HQ / 45HQ / 53HQ
6. 未预约整柜可能**拒收**；若收货则收未预约违规费

## 合并预约

- 多个入库单可绑定**同一预约单、同一 Slot、同一目的仓**送仓
- 须**相同送仓方式**（均为 LCL 或均为 FCL）；**FCL 与 LCL 不可合并**
- 目的仓或送仓方式不一致须分别创建预约单

## 仓内上架单（PSC）

仓内上架单只需下单选择对应 PSC，**无需预约**，不产生未预约违规费或散装卸货费。

## 修改 PSC / 送仓方式

入库单在 **OD / 验货完成 / TS** 状态下可「回到草稿」修改 PSC：
万邑联 → 海外仓 → 入库 → 全部订单 → 回到草稿 → 重新选择 PSC 与送仓方式
