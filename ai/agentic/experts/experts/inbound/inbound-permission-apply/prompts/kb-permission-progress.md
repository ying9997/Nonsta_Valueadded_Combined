# 权限审批进度查询指引

## 查询方式

1. **万邑联平台**
   - 个人中心 → 产品权限 → 申请记录
   - 查看状态：待审核 / 审核中 / 已通过 / 已拒绝

2. **邮件通知**
   - 审核结果通常会发送至申请时填写的联系人邮箱

3. **客服查询**
   - 提供公司名称、申请类型、申请日期
   - 飞书审批 API 当前为 Gap，无法实时查单

## 状态说明

| 状态 | 含义 |
|------|------|
| 待审核 | 已提交，排队中 |
| 审核中 | 运营/合规审核中 |
| 已通过 | PSC/额度已开通 |
| 已拒绝 | 需补充材料后重新申请 |

## 预计时长

KB 参考：通常 3–5 个工作日，**不承诺**具体时长。

## 当前 Sprint 限制

- 有 applicationId 时仍无法调用 Bitable API 查进度
- 引导客户通过万邑联平台或联系客服
