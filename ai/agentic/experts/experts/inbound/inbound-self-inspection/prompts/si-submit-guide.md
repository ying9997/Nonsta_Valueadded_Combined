# 自验提交操作指引（SI / QSI）

## OW01021 经典自验（SI）

1. 在万邑联平台创建入库单并选择自验产品
2. 上传箱单（须与验货数据一一匹配）
3. 选择提交方式：
   - **PDA App**：现场扫描，须更新至最新版
   - **API 对接**：批量推送验货数据
   - **Excel 模板**：下载模板填写后上传
4. 验货完成后方可创建预约单（自验直发）

## OW01022 快速自验（QSI）

1. 下单仅需 SKU + 数量（SelfInspectionPlanSKU 模式）
2. 支持「重验」更新验货数据
3. 无需预先完整箱单
4. 提交路径同 PDA / API / Excel

## 修改与重验

- 新自验（QSI）：在万邑联点击「重验」更新数据
- 旧自验（SI）：按平台修改流程操作，超过时间窗需联系客服

## 对客原则

- 明确「您需要在万邑联平台自行操作」
- 不代客提交；写接口 selfinspection.submit 仅作 SOP 入口说明
