## 三种入库链路（产品 Taxonomy）

| 产品线 | 验货发生地 | 头程承运方 | 国内仓节点 | 典型 PSC |
|--------|------------|------------|------------|----------|
| **标准海外仓入库** | Winit 国内仓 | Winit（揽收或自送国内仓） | 必须经过 | OW01011* |
| **直发 + 自验** | 客户侧，发货前完成 | 客户自选物流，或 Winit 承运 | Winit 承运时经过 | OW01022*（直发自验）/ OW01021*（Winit 承运自验） |
| **直发 + 海外验** | Winit 海外仓 | 客户自选，或 Winit 头程到海外 | 仅 Winit 承运时经过 | OW01031*（Winit 承运海外验）/ OW01032*（直发海外验） |

**对客要点**：三种链路在下单入口、验货节点、费用扣费节点上均有差异；选型前建议确认已开通 PSC（→ inbound-psc-eligibility）。具体操作步骤见 inbound-order-manage。

### 服务优势对比（摘要）

| 维度 | 标准头程 | 直发自验 | 直发海外验 |
|------|----------|----------|------------|
| 上架速度（美国，空运） | 1 工作日 | 1 工作日（空卡） | 2 工作日（空卡） |
| 客户操作复杂度 | 最低（全托管） | 中（需自验数据） | 低（无需客户验货） |
| 适用客户 | 中小客户 | 品牌/工厂型 | 高值货/紧急补货 |
| 国内仓质检 | 有 | 仅 Winit 承运时有 | 仅 Winit 承运时有 |

## 产品选择决策树

```
客户有新的货物要入库 Winit 海外仓
│
├── 是否使用 Winit 头程？
│   ├── YES → 标准头程 (OW01011*)
│   └── NO（客户自发）→ 选择验货方式
│       ├── 客户在发货前自验 → 直发自验
│       │   ├── Winit 承运 (OW01021*) → 须先完成验货才能创建预约单
│       │   └── 完全直发 (OW01022*)
│       └── 在 Winit 海外仓验货 → 直发海外验
│           ├── Winit 承运到海外 (OW01031*)
│           └── 完全直发 (OW01032*)
│
└── 送仓方式（影响预约要求）
    ├── 快递面单逐件派送 → 免预约
    ├── 散货 LCL → 必须预约
    └── 整柜 FCL（DROP/LIVE）→ 必须预约
```

美森渠道已于 2025 年 12 月下线，推荐以星渠道。

## 双轨模型（信息流 × 实物流）

同一入库单上，信息流操作与实物流动作**相互交织但时序可不同步**。例如：自验单在货物出库后才完成信息录入；海外验单可在 TS 状态后仍尚无完整箱单。

**信息流**：SKU 注册发布 → 创建入库单（选 PSC/目的仓）→ 上传箱单/验货数据 → 提交预约（散货/整柜）→ 状态追踪（DR→OD→…→SHD）

**实物流**：国内收货/验货（标准头程）→ 出口发运 → 国际运输 → 进口清关 → 海外仓卸货到仓 → 海外验货（仅海外验链路）→ 上架入库存

## 前置条件

1. **SKU 必须提前注册发布**：万邑联 → 商品 → 商品维护信息；未发布无法下单。
2. **产品权限开通**：部分 PSC（自验、海外验、整柜等）需在万邑联 → 个人中心 → 服务设置 → 偏好设置开通；无直发入口同理。
3. **进口商注册**：递延清关（UK PVA、DE/BE 递延）须提前维护有效进口商（VAT + EORI）。
4. **库容额度**：高峰期海外仓可能实施配额；直发客户关注库容（→ inbound-capacity-availability）。

## 新建入库单 SOP（通用）

1. **开通权限**：万邑联 → 个人中心 → 服务设置 → 偏好设置。
2. **注册商品**：确保 SKU 已发布且规格与下单一致。
3. **创建入库单**：万邑联 → 海外仓入库 → 新建入库单；选择目的仓、PSC、填写箱单/商品明细。
4. **完成页面设置**：如页面出现相关设置，请按所选 PSC 和页面提示完成；未出现可继续下一步。如无法提交，请提供页面提示或截图。
5. **发货/送仓**：
   - 快递：免预约，按仓库地址规范填写面单（→ inbound-warehouse-info）。
   - 散货/整柜：必须预约（→ inbound-appointment-manage）。
6. **到仓签收** → **验货** → **上架完成**（库存可用）。

详细操作与报错处理 → inbound-order-manage。

## 标准海外仓入库流程（OW01011*）

1. SKU 注册发布（品名、申报价值、尺重）。
2. 创建入库单：选 PSC、目的仓、包裹信息；标准头程需上传完整箱单。
3. 提交发货确认（OD），进入国内仓揽收/自送流程。
4. 国内仓质检 → 出库发运（TS）→ 国际运输 → 清关 → 海外仓卸货 → 上架（SHD）。

**申报价值建议**：美国单票 ≤ 660 USD（上限 700 USD）；澳洲 ≤ 600 USD。超限可能触发正式报关。

## 直发自验流程要点（OW01021/22）

- **OW01021**（Winit 承运自验）：须**先完成验货**才能创建预约单。
- **OW01022**（完全直发自验）：客户自选物流直发海外仓。
- 自验链路通常**无 RE 状态**（RE 仅在 Winit 国内仓收货时触发）；TS 由客户确认发货触发。

### 三种自验模式

| 模式 | 说明 |
|------|------|
| **旧自验（标准自验）** | 下单时须上传完整箱单；PDA/API/Excel 逐箱对照验货 |
| **新自验** | 下单只填 SKU + 数量，箱单可后补；PDA 扫描后系统生成箱单 |
| **API 对接验货** | 通过 API 上传验货数据，适合 ERP/WMS 大客户 |
| **免验货** | 白名单客户，以 Excel 箱单上传，Winit 不物理开箱核对 |

发货前在万邑联/PDA/API 完成自验；到仓后可能抽验，异常可能产生异常费（→ inbound-self-inspection）。

---

## 直发海外验流程要点（OW01031/32）

- 货物到仓后由 Winit 执行验货（PEWC 阶段）；客户侧主要查询进度（→ inbound-overseas-inspection）。

| 模式 | 说明 |
|------|------|
| **有箱单** | 上传完整装箱明细，海外仓按箱单开箱核对 |
| **无箱单（绿色通道）** | 仅填 SKU + 预计数量，到仓后实际清点；**不允许多验** |
| **预报海外验** | 先预报数量，货物分批到仓后累计验货上架 |

## 入库单状态机概览

> 本段解释状态**含义**，不查询具体单据当前状态（→ inbound-order-status）。

```
DR → OD → RE → TS → PEWC → EWC → SHD
                          ↘ STOP（终止）
```

| 状态 | 含义 | 客户常见咨询 | 对应专家 |
|------|------|--------------|----------|
| DR | 草稿/已创建 | 怎么下单？权限开了吗？ | inbound-process-guide |
| OD | 已确认/待发货 | 什么时候可以发货？ | inbound-process-guide / inbound-order-manage |
| RE | 国内仓已收货 | 国内仓收到了吗？ | inbound-order-status |
| TS | 已发运/在途 | 到港了吗？预计何时送仓？ | inbound-order-status / inbound-arrival-status |
| PEWC | 预计在仓期 | 什么时候上架？能加急吗？ | inbound-arrival-status / inbound-putaway-expedite |
| EWC | 验货/上架中 | 上架数量对吗？ | inbound-putaway-status / inbound-exception-check |
| SHD | 全部上架，库存可用 | — | — |
| STOP | 已终止 | 为什么终止？ | inbound-process-guide / inbound-order-manage |

## 送仓方式与预约

| 方式 | 预约要求 | 备注 |
|------|----------|------|
| 快递 | 免预约 | 按仓库地址规范填写面单 |
| 散货 LCL | 必须预约 | 未预约可能产生违规费 |
| 整柜 FCL | 必须预约 | DROP = 司机留柜后离开；LIVE = 司机现场等候卸货 |

预约入口：booking.winit.com.cn（→ inbound-appointment-manage）。

## 上架 SLA 速查（到仓后）

**美国（US）— 摘要**

| 产品线 | 运输方式 | 到仓后上架 SLA |
|--------|----------|----------------|
| 标准海外仓入库 | 空运/FedEx 快递 | 1 工作日 |
| 标准海外仓入库 | 海运散货（美森/以星） | 2 工作日 |
| 标准海外仓入库 | 海运散货（非美森/以星）/ 整柜 | 3 工作日 |
| 直发国内验 | 空卡（POD 须注明航单号） | 1 工作日 |
| 直发国内验 | DHL 快递 | 1 工作日 |
| 直发国内验 | 非 DHL 快递/空派/海派/整柜 | 4 工作日 |
| 直发海外验 | 空卡 | 2 工作日 |
| 直发海外验 | DHL 快递 | 2 工作日 |
| 直发海外验 | 非 DHL/空派/海派/整柜 | 5 工作日 |

**非美国（UK/DE/AU/CA）— 摘要**：标准空运/快递通常 1 工作日；海运/铁路 3 工作日；直发海外验空派/海派最长 5 工作日。

**空卡特别注意**：送仓 POD 须清晰备注【空卡 + 11 位航空运输单号】，否则默认按海卡 SLA 处理。

催上架、超时处理 → inbound-putaway-expedite / inbound-putaway-status。

## 混装转运时效（海运散货）

美国海运散货拼柜可能混装（多仓货物共柜），需判断是否转运：

| 转运路径 | 送仓时间推算（有实际到仓） |
|----------|---------------------------|
| USWC ↔ USWC2 | 送仓完成时间 + 2 工作日 |
| USWC/USWC2 → USTX | + 11 自然日 |
| USWC/USWC2 → USKY3 | + 12 自然日 |
| AU ↔ AUME | + 7 自然日 |
| DE → BEMO | + 7 自然日 |

无实际到仓时用预计送仓时间按同规则推算。具体单据送仓进度 → inbound-arrival-status / inbound-transit-tracking。

## 常见流程 FAQ

| 场景 | 说明 |
|------|------|
| 无直发下单入口 | 万邑联 → 个人中心 → 服务设置 → 偏好设置开通 |
| 怎么新建入库单 | 见「新建入库单 SOP」；PSC 选型见决策树；报错 → inbound-order-manage |
| 批次/非批次混单 | 需拆分下单 |
| 箱号已存在 | 须终止原入库单才能重用箱号 |
| BC 类包裹上架慢 | BC 类 SKU 种类多、分拣耗时更长；建议优先 A+/A 类包裹 |
| 带电商品 | 须上传电池资料审核（→ 规则 KB） |
