# 入库规则与禁限运知识库

> 来源摘要：新增海外仓入库单 FAQ、inbound-rules、playbook §八 前置条件、件型限制。

---

## 下单报错与规则解释

| 报错/场景 | 规则解释要点 |
|-----------|--------------|
| 逾期账单 | 还清欠款后额度自动恢复；延期联系商务 |
| 商品不存在 | 检查 SKU 注册发布状态、规格（Specification）与下单一致 |
| 体积超限 | 未验货取注册尺寸；已验货取验货尺寸；验货后体积错误需申请海外仓复核 |
| B/C 包裹含大件 | 大件/超大件（T120/T240/TM）仅 A/A+；B/C 含大件会报错 |
| 批次/非批次混单 | 需拆分下单 |
| 箱号已存在 | 须终止原入库单才能重用箱号 |
| 不支持 Winit 头程 | SKU 被限制直发，提供 SKU 核实原因 |
| 带电无电池证书 | 上传电池资料并完成审核 |
| 没有直发下单入口 | 个人中心 → 服务设置 → 偏好设置开通 |

## 件型与包裹类型

| 件型 | 尺寸/重量（摘要） | 包裹限制 |
|------|-------------------|----------|
| 小件 | 长≤50cm，宽≤40cm，高≤13cm，重≤3kg | USTX/USGA/USNJ2 仅 A；其他仓 A/A+/B/C |
| 大件/超大件 | T120/T240/TM 货型 | 仅 A/A+ 包裹可含 |

- **A / A+**：标准小件；A+ 为全新完好。
- **B / C**：混装/异常包裹；BC 类上架效率低于 A 类。
- **USTX / USGA / USNJ2**：小件仅 A 类包裹。

---

## 申报价值（标准头程）

- **美国**：单票申报价值建议 ≤ 660 USD（上限 700 USD）；超限可能触发正式报关，关税实报实销。
- **澳洲**：单票 ≤ 600 USD。

---

## CBM 额度规则（说明口径）

- CBM 为入库容量额度概念，满额时需等待释放或申请扩容（→ inbound-capacity-availability 查剩余）。
- 本专家仅解释规则，不提供实时剩余额度。

---

## 禁限运品类别

| 类别 | 说明 |
|------|------|
| 危险品 | 需符合目的国法规与仓库配置；最终合规判断需人工核实 |
| 带电商品 | 须上传电池资料；按仓库配置说明电池类型/功率限制 |
| 液体 | 需确认包装与 MSDS；部分仓/PSC 不支持 |
| 易碎品 | 注意包装要求，可能需增值包装服务 |
| 特殊货型 | 涉及合规争议 → 转人工 |

**对客约束**：仅提供类别说明，不做最终合规判断。

## 权限与入口

- 无直发入口：万邑联 → 个人中心 → 服务设置 → 偏好设置。
- SKU 注册：万邑联 → 商品 → 商品维护信息。
- 件型查询（人工核实）：TOM → 管理商品管理 → 商品。

---

## 国别/仓别差异化（摘要）

- **德国仓**：地址 Straße 字符问题见 inbound-warehouse-info。
- **美国部分仓**：小件仅 A 类（USTX/USGA/USNJ2）。
- **递延清关**（UK PVA、DE/BE）：须提前维护进口商信息（→ inbound-customs-doc-manage）。
- 具体仓库规则结合 `country` 与 `productLine` 过滤。
