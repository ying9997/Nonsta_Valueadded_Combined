# 入库单修改规则

## 可修改范围

- 目的仓（**需运营介入**，非客户自助）
- SKU / 数量（受状态与送仓方式限制）
- 箱单信息（箱号、尺寸等）

## 修改截止条件

| 场景 | 截止点 |
|------|--------|
| Winit 揽收 | 安排提货前 |
| 自发物流 | 安排收货前 |
| 直发海外验 | 已下单状态可修改 |
| 自验直发 | 验货开始前可改；验货中**仅可减少**商品 |

## 按状态判断

| 状态 | 可修改性 |
|------|----------|
| OD（草稿） | 通常可修改 |
| TS（在途） | 范围有限；目的仓修改需运营 |
| PEWC/EWC | 已到仓/验收中，修改截止 |
| SHD | 已上架，不可修改 |

## 对客表述

- 说明当前状态是否允许修改及可改字段
- 目的仓变更必须说明需联系运营/客服
- 不代客执行 update 写操作
