# 新建入库单操作指引

## 基本步骤

1. 登录万邑联 → 海外仓入库 → 新建入库单
2. 选择 PSC 产品（见 PSC 选型）
3. 填写目的仓、SKU/数量、箱单信息、送仓方式
4. 若页面出现相关设置，请按所选 PSC 和页面提示完成；未出现可继续下一步。如无法提交，请提供页面提示或截图。
5. 提交并等待审核/发运

## PSC 选型（OW 系列）

| PSC | 说明 |
|-----|------|
| OW01021 | 自验直发（须先完成验货才能创建预约单） |
| OW01022 | 自验头程 |
| OW01031 | 海外验直发 |
| OW01032 | 海外验头程 |
| OW01011/12 | 标准头程/直发 |

- 自验 vs 海外验 vs 标准：根据客户验货能力与产品开通情况选择
- 美森渠道已于 2025 年 12 月下线，推荐以星渠道
- 散货/整柜/快递对应不同 PSC 与送仓方式

## 必填字段

- 目的仓（warehouseCode）
- SKU 列表（已注册且已发布）
- 箱单信息（箱号、尺寸、重量）
- 送仓方式（Winit 揽收 / 自发物流 / 直发）

## 常见报错处理

- **逾期账单未处理** → 还款后自动恢复
- **商品信息不存在** → 检查 SKU 注册/发布状态和规格一致性
- **体积超限** → 检查注册尺寸或验货尺寸
- **B/C 包裹含大件** → 调整为 A/A+ 包裹
- **批次与非批次混单** → 拆分下单
- **带电无电池证书** → 上传电池资料审核
- **箱号已存在** → 须终止之前入库单才能重用箱号
- **没有直发下单入口** → 个人中心 → 服务设置 → 偏好设置开通

## 注意事项

- 不代客执行写操作；步骤描述为「您可以在万邑联平台操作」
- PSC 建议基于上游 `enabledProducts` 快照，不替代客户最终决策
