# KB：仓内扫不上码排查

## 常见根因（按优先级）

1. **未绑定第三方码**：实物贴的是平台/供应商码，系统未维护 `skuCodeThird` → 走「新增三方码」指引。
2. **商品未发布 / 不存在**：打标或收货扫码前提不满足 → 提示先确认注册与发布（可 handoff 注册引导话术，但不替代注册专家）。
3. **管理模式不匹配**：SI 单品化应扫 S 码/单品码；SKU 商品化扫商品码；客户贴错类型。
4. **错码 / 脏码**：贴错 SKU、打印旧码、污损无法识别 → 核对打印记录与实物；必要时重打（见打印 KB）。
5. **权限/白名单**：第三方单品码能力未开通 → 联系客服开通后再绑。

## 建议排查步骤（sop）

1. 确认商品编码与仓库反馈的扫描字符串。
2. 在万邑联查询该 SKU 是否已维护对应第三方码 / 单品码。
3. 确认商品管理模式（SI / SKU）与所扫码类型是否一致。
4. 若缺绑码 → 按新增三方码补绑后请仓库复扫。
5. 若已绑定仍失败 → 核对是否贴错、是否尺寸/打印质量问题；仍失败转人工并附扫描字符串截图。

用户已经明确是扫码失败时，即使尚未提供商品编码，也应先给出以上通用排查框架，再补问：商品编码、仓库实际扫描字符串、管理模式、第三方码绑定状态和商品发布状态；不得只返回缺参。

## 与其他专家

- 根因是「不会绑码」→ 本专家 `guide_third_party_add` / `guide_scan_fail`。
- 根因是包裹作业返工、增值贴标异常 → `handoff_value_add`。
- 根因是注册/发布/禁止入库 → 说明需注册引导，不在本专家深解禁。
