# KB：新品承运深判

> 来源：docs/sku/flows/01 · 相对 registration-guide 浅层的加深判路径

## 与浅层的分工

- **浅层**（registration-guide）：禁限运清单自查 + 引导注册。
- **本专家深判**：清单未覆盖、品类争议、需登记注册组审核、或客户坚持要「能不能发」的结论。

## 对客处理

1. 确认 **商品链接/清晰图片**、**目的国家**、建议确认运输方式（空/海/直发）。
2. 引导客户在万邑联 **公告** 下载最新 **WINIT 禁限运清单** 再核一次品类与国别。
3. 清单明确禁限 → `complianceVerdict=fail`，说明不可发/不可入的依据为清单品类。
4. 清单未命中且无历史结论 → **无法由机器人下最终承运结论**：
   - 引导完成商品注册由专人审核；或
   - 说明需转人工/注册组登记咨询（咨询类型、仓库、链接、目的国、运输方式）。
5. 不要编造「已通过承运审核」；无系统结论时 `uncertain` 或 `need_human`。

## 历史咨询清单 / 任务单 API

当前无可靠结构化 API → 不假装已匹配历史清单；缺材料时 `need_info`，需人工审核时 `need_human`。
