# KB：证书齐备（MSDS / UN38.3 / GPSR 等）

> 来源：docs/sku/flows/07、05

## 上传路径

万邑联 → 商品管理 → 商品信息 → 点击 SKU → 商品详情 → **资料证书** → 国家选 **ALL**（或按指引选国）→ 选择证书类型 → 提交。

## 电池 / DG

头程常要求：含电池商品须 **当年有效期内** 的 **MSDS（SDS）+ UN38.3**，且与商品匹配。

| 情况 | 动作 |
|------|------|
| 过期/缺失/不一致 | 按上路径上传有效文件 |
| 确认已上传仍报错 | `need_human` 排查 |

客户发 SDS 问「能不能用」→ 引导先注册/选定 SKU 并在资料证书栏上传后提交审核，避免口头预审。

## GPSR 与禁售

未关联 GPSR → 库存可能出现 **不合规禁售**。解除：在系统完成 GPSR 信息关联。禁售数量细节在库存查询（非本专家主责）。

## 禁止入库常见文案

纯电或 DG 未提供有效期内 SDS 及 UN38.3 → 无法接收入库。补齐路径同上。

## missingDocuments 示例

- `MSDS` / `UN38.3` / `GPSR` / `WEEE注册号` / `德语说明书` 等，按客户问题与档案摘要列出，勿编造已上传。
