# KB：禁限解禁浅层（guide_unban）

> 来源：docs/sku/flows/05 · 与 profile 禁限事实配合

## 原则

- **事实**（是否禁止、原因摘要、来源）优先来自上游 `sku/profile` 快照。
- **解禁浅层**：系统规则类 → 指引补资料 / 改属性 / 看待办。
- **`prohibitSource=manual`** 或来源不明且个案争议 → **`need_human`**，话术：请联系客服协助解禁，勿假装可自助一键解除。
- **深判**（品类国别细则、申报要素、证书是否满足解禁条件）→ `handoff_compliance`。

## 浅层 SOP 模板

1. 万邑联查看该 SKU 的禁止入库/出库标记与原因感叹号。
2. 对照待办「待补充」项，按清单上传证书或修改属性。
3. 提交后等待审核；关注维护任务状态。
4. 仍无法解除 → 转人工并说明已尝试的补件。
