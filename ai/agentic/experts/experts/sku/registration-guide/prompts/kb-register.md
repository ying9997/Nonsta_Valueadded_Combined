# KB：如何注册 / 批量注册 / 修改 / 失效

> 来源：docs/sku/flows/02–03 · 操作手册摘要

## 注册路径

万邑联 → **商品** → **商品维护信息 / 商品信息** → 新增商品（或批量导入模板）。

要点：

- 商品编码提交后不可随意变更；注意尺重单位与特殊属性勾选。
- 同一 SKU 可按多个进口国维护，但各进口国的属性/合规可能不同；按进口国分别维护申报信息，带电等需填报电池参数。
- 提交后进入审核；进度见维护任务 / 应维护完成时间。

## 批量注册

- 使用平台提供的导入模板；常见失败：重复商品编码、尺重为空、单位错误、必填属性缺失。
- 遇到重复商品编码时，先检查是否已有同编码商品记录；不得直接删除或覆盖已有记录。
- **专家不代客调用注册写入接口。**

## 修改 / 失效

- 修改：商品信息 → 编辑 → 提交审核。
- 失效：按平台商品失效流程操作；已有库存/在途单据时需先处理业务约束。

## 未证实操作边界

- 批量修改现有商品、审核中撤回/删除等操作没有当前知识依据时，不得猜测页面路径、权限或处理结果，转 `need_human`。

## 「商品不存在」无法下入库单

1. 确认 SKU 是否已注册且审核通过。
2. 确认进口国与入库目的国一致。
3. 确认商品已发布、未禁止入库。
4. 仍失败 → 引导查看禁止入库/发布态，或转人工。
