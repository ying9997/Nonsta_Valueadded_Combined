# KB：退回原因与重提

> 来源：docs/sku/flows/03

## 处理流程

1. 客户提供 SKU（及进口国更佳）。
2. 万邑联 → 商品管理 → 商品信息 → 打开 SKU **商品详情**。
3. 页面顶部提示条即为 **退回原因**（可能带进口国，如「退回(US)」）。
4. 按原因修改对应字段（如商品链接无效：提供真实可交易售卖页）→ 重新提交审核。
5. 系统无原因或客户仍不服 → `need_human`。

## 未证实操作边界

- 运输方式与电池资料要求存在争议（例如客户主张走陆运、退回却要求电池资料）时，不得自行判断资料可免除或承诺审核结果，转 `need_human`。
- 已提交或审核中的商品能否撤回、删除，没有明确系统依据时不得猜测，转 `need_human`。
- 未取得实时退回原因时，必须明确说明「当前未取得实时审核事实」，不得把通用示例当作该 SKU 的退回事实，转 `need_human`。

## 示例：链接无效

- 原因：进口商品链接打不开 / 无图片 / 无交易价格 / 已下架等。
- 动作：更换为真实可交易链接后重提。
