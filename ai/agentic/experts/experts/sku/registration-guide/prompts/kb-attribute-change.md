# KB：特殊属性解除（取消勾选）

> 来源：docs/sku/flows/06

## 原则

1. 先确认 **实物**（以实际发货为准）。
2. 实物确有该属性 → 不可取消。
3. 实物没有 → 修改后提交审核。
4. 仍无法解决 → `need_human`。

## 修改路径

万邑联 → 商品管理 → 商品信息 → 找到 SKU → **商品编辑** → **商品特性 / 商品属性** → 取消对应勾选 → **提交** → 等待审核。

## 属性摘要

| 属性 | 要点 |
|------|------|
| 带电池 | 本体或包装内是否含电池 |
| 带液体 | 含少量液体也算（如湿巾） |
| 带磁性 | 含弱磁性也算 |
| 带粉末 | 含干燥剂也算 |
| 带刀片 | 确有危险刀片则不可取消 |
| DG | 先核对电池参数是否填错；复杂个案转人工 |
