# 查件专家 — 知识摘录（KB）

> 维护说明：话术细则与枚举以业务文档为准（飞书 SOP）；本文件仅保留对客安全摘要。**禁止**在对客回复中引用本文件名或内部 wiki 标题（见 `REQUIREMENTS.md` §4）。

## 1. 受理与整体时效（摘要）

- **受理时效**：提交后 **1 个工作日内** 完成受理。
- **整体时效**：预计 **10 个工作日内** 完成调查。

## 2. 标准话术分支（第五节摘要）

- **情况 1 · 未查到查件记录**：说明当前查询条件下无记录；引导客户核对单号或在卖家端自助发起查件（见下文「自助发起查件」）。
- **情况 2 · 待受理（SU，且无受理完成时间）**：按提交起算工作日区分 ≤1 个工作日 / 超期未受理。
- **情况 3 · 已提交供应商查件（SSC 等）**：调查初期 / 调查中 / 超期未出结果三档表述。
- **情况 4 · 已完成（CP）**：结合 `checkingResults` 与 `checkingType` 解释结果含义；勿复述内部 ID。

## 3. 「五·补充」— `checkingStatus` / `sopBranch` 要点

事实节点会推导 **`sopBranch`**，模型应与之对齐口径（勿自相矛盾）：

| 典型状态 | 话术侧重点 |
|----------|------------|
| 空列表 | 情况 1；勿编造单号 |
| SU + 无 `acceptTime` | 情况 2 · 待受理 |
| SU + 有 `acceptTime` | 视为已受理，按情况 3 计时 |
| NSC | 待提交供应商；可比照调查初期语气，勿承诺物流商已收到 |
| SSC | 情况 3 |
| WCR | 待确认结果；仅在 `feedbackMsg` / `checkingResults` / `returnReasons` 非空时引用具体结果，否则说明接口暂未返回可对客说明的结果；勿推断供应商未反馈，勿承诺主动通知 |
| CP | 情况 4 |
| RT / CC | 退回 / 已取消的补充说明 |

## 4. 自助发起查件（卖家端）

本期 **不通过 OpenAPI 代客户创建查件单**。若客户需要**新建查件**或当前查询无记录需自助提交，请引导至卖家端固定页面：

**https://seller.winit.com.cn/Tracking/create**

说明时使用「卖家账户 → 尾程查件 → 新建/发起查件」等客户可理解的表述即可，**勿**暴露内部接口名或网关 action。

新建查件类型由代码根据结构化事实给出：若存在 RDscan（退回妥投），或上游出库专家查到 `DF / 派送失败` 的关联退货单，选择“退回原因”（接口类型 `FR`，即查派送失败原因），不要选择“超时未妥投”。
