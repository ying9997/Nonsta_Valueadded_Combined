### 1.1 UPS - Standard Single Parcel（Standard 1-5 工作日）

| 属性 | 说明 |
|------|------|
| 计费标准 | 以计费重量为准，体积重=长(cm)×宽(cm)×高(cm)/7000，与实重取大者 |
| 重量限制 | 实际重量≤150 lbs |
| 尺寸限制 | L≤274 cm (108 inches)，长+2*(宽+高)≤419 cm (165 inches) |
| 时效 | 1-5 个工作日（不含偏远区域） |
| 挂号 | 已含 |
| 主要附加费 | 燃油附加费（每周更新）；住宅地址附加费；地区附加费 DAS/Extended/Remote/Super Remote（4级）；超长/超重附加费；超大附加费 Large Package；超限制附加费 Overmaximum；不规则包装附加费；旺季附加费；签名附加费；地址修正费；派送失败退货费（与正向一致） |
| 其他 | 不支持签名服务；不支持改址/改派/截件；超长/超大附加费供应商按英寸计费，可能存在换算差异 |
| 增值服务 | Return Label 退货服务（UPS Standard Return，买家可联系 UPS 上门提货，超 30 天面单作废，继续退货特殊处理费 10 CAD/票） |

### 1.6 发货限制与注意事项

#### 电池限制

| 产品 | 内置电池 | 配套电池 | 纯电池 | 备注 |
|------|---------|---------|--------|------|
| UPS Standard | √ | √ | √ | 电池组≤300Wh 按普货；>300Wh 为危险品不支持 |
| UNI Domestic | √ | √ | × | |
| Canada Post Expedited | √ | √ | × | |
| Purolator Ground | √ | √ | × | |

> 注：CA 电池标准为电池组≤100WH / 电池芯≤60WH。

#### 其他限制

- **Purolator Ground**：刀具类刀刃未开口且不超 8CM，军用刀具不能发
- **UPS Standard**：不支持签名服务；不支持改址/改派/截件
- **Canada Post Expedited**：支持 POBox；不支持签名/改址/改派/截件

> 通用说明：如因出库包裹包装不符合国际电池货物标准，可能导致退货/销毁或产生额外费用，Winit 将实报实销向卖家补收，必要时有权冻结客户库存直至完成相关增值服务确保包裹符合运输要求。
