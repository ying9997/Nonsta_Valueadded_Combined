## 二、排期原则

1. **专家开发完成**：比 OKR 达标月 **提前 1～2 个月**
2. **联调与灰度**：预留 2～3 周
3. **数据积累**：至少 2～4 周才能观测覆盖率与准确率
4. **假设性干扰**：前期发现问题可能带来反曲线，需预留缓冲

## 五、衡量指标与专家质量要求

| 指标 | 目标 | 专家侧要求 |
|------|------|------------|
| AI 回答准确率 | ≥95% | 知识库匹配 >95%、订单查询 >98%、流程协作 =100% |
| AI 首次解决率 | ≥80% | 减少二次询问、人工接入 |
| AI 响应时长 | P50≤20s, P95≤40s | 节点与 LLM 调用优化 |
| 客户满意度 | ≥90% | 回答质量、解决定义闭环 |

## 六、风险与缓冲

1. **反曲线增长**：前期发现问题导致覆盖率短期下降，需预留 1～2 周缓冲
2. **API 依赖**：供应商/Winit 轨迹、面单等 API 需提前对接，建议开发提前 2 周启动
3. **知识库质量**：查件/索赔、赔付标准等需业务侧提供权威数据，建议 1 月完成初版
