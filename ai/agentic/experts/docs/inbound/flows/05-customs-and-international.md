# Flow 05：出口报关、国际运输与进口清关

> **适用范围：** 本分册覆盖货物从国内出口、经国际运输到达目的国并完成进口清关的全链路，涉及所有入库产品线（标准头程 + 直发均在国际段经过此节点）。
> **状态对应：** `TS`（运输中）阶段的实物流细节。
>
> 见 [playbook.md](../playbook.md)「维度交叉索引」运输与清关维度。

---

## 一、出口报关

### 1.1 快件申报（快递/标准头程默认方式）

`[KB]` 来自 [`海外仓头程快递入库服务常见问题.md`](../../../_kb/service-team/inbound-services-doc/海外仓头程快递入库服务常见问题.md)

- 所有通过 Winit 头程的快递产品均采用**快件申报**（快递出口通道）
- 不提供一般贸易申报（不含正式报关通道）
- 申报价值建议：
  - **美国**：单票 ≤ 660 USD（上限 700 USD）
  - **澳大利亚**：单票 ≤ 600 USD
  - 超限货物可能被要求转正式报关，关税实报实销

### 1.2 正式报关（触发情况）

- 申报价值超限，被出口海关要求正式申报时触发
- Winit 收到通知后当日通知客户，并提供报关行联系方式
- 费用由客户与报关行直接结算 `[KB]`

## 二、国际运输方式详解

### 2.1 运输方式分类与特点

| 运输方式 | 描述 | 典型时效（中国→美国）| 适用场景 |
|---|---|---|---|
| **空运（AIR）** | 飞机直飞或转运 | 5–10 天 | 小体积、高价值、紧急补货 |
| **海运散货（LCL）** | 拼箱，与其他客户共柜 | 20–35 天 | 中批量，成本优先 |
| **海运整柜（FCL）** | 独立整柜 | 18–30 天 | 大批量，低单价 |
| **快递（FedEx/UPS/DHL）** | 门对门快递 | 5–10 天 | 小单量，有重量限制（21–99 kg/单）`[KB]` |
| **空卡（Air + Truck）** | 空运+陆运联运，目的地不在港口城市 | 7–12 天 | 内陆仓库目的地 |
| **空派（Air + Last-mile）** | 空运+尾程派送 | 7–15 天 | 特定国家/地区 |
| **海卡（Ocean + Truck）** | 海运+陆运联运 | 20–35 天 | 内陆目的仓 |
| **海派（Ocean + Last-mile）** | 海运+尾程派送 | 20–40 天 | 特定国家 |
| **铁路** | 中欧班列或跨境铁路 | 15–25 天 | 欧洲目的地 |
| **美森快船** | 美线优先快船，MSC/ONE 等 | 约 14 天（USWC）| 美西线时效优先 |

### 2.2 混装柜与转运

`[KB]` 部分来自服务团队话术

- **混装柜**：多个客户货物共用一个整柜，减少成本
- **中转转运**：货物到达中转港（如 USWC - 洛杉矶/长滩）后，拼柜内不同目的地货物拆分，再转运至最终仓库（如 USTX - 德克萨斯、USKY3 - 肯塔基）
- 转运时效：USWC→USTX 约 4–6 天 `[推断]`；USKY3 一般到港后 12 天送仓 `[KB]`

## 三、进口清关分支

### 3.1 标准一般贸易清关

- 最常见的进口清关方式
- 通过快递商或 Winit 合作的清关代理完成
- 缴纳进口增值税和关税（税费转嫁给客户的产品申报价值）

### 3.2 预清关（美国 / 澳洲 / 加拿大）

`[KB]` 来自 [`为什么进口清关时间比到港时间早？.md`](../../../_kb/service-team/inbound-services-doc/为什么进口清关时间比到港时间早？（美国_澳洲_加拿大）.md)

- 美国、澳洲、加拿大支持**预清关**：货物尚未到港即可提前准备并提交清关文件
- 因此，**清关完成时间可能早于到港时间**，这是正常现象，不表示货物已提前到达
- 如果货物到港后海关要求**实物查验**，会延长整体时效

### 3.3 英国 PVA 递延清关

`[KB]` 来自 [`英国PVA递延清关常见问题以及申请流程.md`](../../../_kb/service-team/inbound-services-doc/英国PVA递延清关常见问题以及申请流程.md)

- **PVA（Postponed VAT Accounting）**：增值税递延入账制度，自 2021 年 1 月 1 日起实施
- 适用条件：在英国已注册 VAT（本土或离岸均可）的企业
- 效果：进口时无需支付进口增值税，而是在 VAT 申报时体现（降低资金占用）
- 下单 PSC：选择含「英国递延」的产品
- 所需文件（无变化）：发票、装箱单、提单、E2、C88

### 3.4 欧盟递延清关（德国 / 比利时）

`[KB]` 来自 [`关于比利时清关递延常见问题.md`](../../../_kb/service-team/inbound-services-doc/关于比利时清关递延常见问题.md)

| 项目 | 说明 |
|---|---|
| 适用国 | 比利时（BE）、德国（DE）欧盟成员国 |
| 核心机制 | 使用自有进口商在比利时/德国做递延清关，进口时无需缴纳增值税 |
| 要求 | 有效欧盟销售链接（eBay / Amazon）；申报价值 ≥ 产品销售价格的 30%；需提前获取海关建议申报价 |
| 进口商要求 | 自有进口商（德国 VAT + 欧盟 EORI）；需提前在万邑联注册并审核 |
| 报关方式 | 「自有进口商递延清关」 |
| 递延有效期 | 6 个月 |
| 费用 | 空运：40 USD/票；海运：100 USD/票 |
| 开通流程 | 销售提交申请（多维表格链接）→ 万邑联系统提交进口商资料 → 审核通过 |

### 3.5 电商清关 `[推断]`

- 部分目的国提供电商专项清关通道（低价值货物免税或简化申报）
- 美国 $800 以下（De Minimis）免关税，PSC 选择对应「电商」产品 `[推断]`
- 政策变化风险较高，需以最新产品公告为准

## 四、清关时效参考

`[KB]` 来自内部服务文档

| 目的国 | 清关方式 | 到港后清关时效（参考）|
|---|---|---|
| 美国 | 预清关 | 到港前可完成；有查验时 +3–7 天 |
| 澳大利亚 | 预清关 | 同美国 |
| 英国 | 一般贸易 / PVA | 到港后 1–3 工作日 |
| 德国 / 比利时 | 一般贸易 / 递延 | 到港后 1–3 工作日 |
| 加拿大 | 预清关 | 同美国 |

> 内部说明：美森散货和普船散货为**包税渠道**，清关和送仓由供应商统一安排，系统不会显示独立的「清关完成」轨迹节点。USWC 到港后清关+送仓合计 6 工作日内；USKY3 约 12 天。`[KB]`

## 五、常见异常与处理

| 异常类型 | 说明 | 对应处理 |
|---|---|---|
| **到港延误** | 离港/到港异常事件（C03 系列）`[KB]` | 查 TOM 异常管理 → C03 开头事件 |
| **实物查验** | 海关要求开箱检查，延误时效 | 提示客户知悉，无需客户操作 |
| **出口正式报关** | 申报价值超限触发 | Winit 通知客户，联系报关行 |
| **清关完成早于到港** | 美/澳/加预清关正常现象 `[KB]` | 解释预清关机制 |
| **递延清关进口商未通过** | 进口商审核未完成或信息错误 | 让客户重新维护进口商信息 |

## 六、状态追踪路径

客服查询 TOM 系统路径 `[KB]`：
- **到港时间**：TOM → 智运 → 跨国运输 → 空运/海运物流单（查实际到港时间）
- **清关进度**：TOM → 入库单查询 → 轨迹页签 → 查清关里程碑
- **异常事件**：TOM → 智运 → 异常管理 → 异常处理（C03 系列 = 到港相关）
