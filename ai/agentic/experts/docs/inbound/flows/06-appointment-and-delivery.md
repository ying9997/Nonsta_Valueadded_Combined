# Flow 06：预约送仓（直发产品）

> **适用范围：** 所有直发产品（`OW01021*`、`OW01022*`、`OW01031*`、`OW01032*`）的送仓预约与实际送仓规则。标准头程（`OW01011*`）由 Winit 统一安排，通常无需客户提交预约单。
>
> 见 [playbook.md](../playbook.md)「维度交叉索引」→ 送仓维度。

---

## 一、核心规则：预约 vs 免预约

`[KB]` 来自 [`直发预约送仓（常见问题）.md`](../../../_kb/service-team/inbound-services-doc/直发预约送仓（常见问题）.md)

| 送仓方式 | 是否需要预约 | 说明 |
|---|---|:---:|
| **快递（逐件快递面单）** | **不需要** | 每个包裹独立贴一张快递面单，快递商分批次派送 |
| **快递（打托整托送仓）** | **不需要** | 包裹打托但每包裹有独立面单 |
| **散货（LCL / 卡车散件）** | **必须预约** | 非整车卡车，以托盘/散件方式送仓 |
| **散货（快递托盘）** | **必须预约** | 快递公司用托盘送、一托只贴一张面单 |
| **整柜（FCL）** | **必须预约** | DROP 或 LIVE 卸货均需预约 |

> **判断核心**：看每个包裹是否有独立快递面单。有 → 快递免预约；无（以托盘/散件形式）→ 散货必须预约。

---

## 二、送仓方式选择错误后果

`[KB]` 来自 [`直发散货预约常见问题.md`](../../../_kb/service-team/inbound-services-doc/直发散货预约常见问题.md)

| 下单选择 | 实际送仓 | 后果 | 是否可退费 |
|---|---|---|---|
| 快递 | 散货送仓 | 收取**散装卸货费** | **不退费** `[KB]` |
| 散货 | 快递面单逐件送 | 收取**未预约违规费** | **不退费** `[KB]` |
| 散货 | 散货但未预约 | 收取**未预约违规费** | 不退费 |

### 未预约违规费标准

`[KB]`（按订单维度收取，无最低收费）：

| 目的国 | 单价 | 最高上限 |
|---|---|---|
| 美国（US）| 10 USD/CBM | 650 USD |
| 澳大利亚（AU）| 14.5 AUD/CBM | 940 AUD |
| 英国（UK）| 8.5 GBP/CBM | 550 GBP |
| 德国/比利时（DE/BE）| 9.5 EUR/CBM | 620 EUR |
| 加拿大（CA）| 14 CAD/CBM | 880 CAD |

## 三、预约单操作流程

### 3.1 创建预约单

1. 登录万邑联 → 海外仓 → 入库 → 预约单管理 → 新增预约单
2. 勾选需要预约的入库单（同一送仓方式才能合并预约）`[KB]`
3. 填写预约信息：目的仓、送仓方式、预计到仓日期、送仓数量（CBM / 件数）、联系人电话（司机电话）
4. 提交后获取**预约码**，送仓时告知司机凭码送货

> **注意**：预约单的送仓方式与入库单创建时选择的保持一致，**不可在预约单级别修改**。如需变更，须将入库单退回草稿状态后重新选择 PSC 和送仓方式。`[KB]`

### 3.2 多订单合并预约

- 支持将多个入库单绑定到同一个预约单，实现同一时间槽送仓
- 相同送仓方式的订单才可合并 `[KB]`
- 预约单联系人电话建议填**司机电话**（整柜务必填司机电话，以便仓库通知提空柜）`[KB]`

## 四、整柜（FCL）送仓特殊规则

### 4.1 DROP 卸货 vs LIVE 卸货

| 类型 | 说明 | 到仓时间计算 |
|---|---|---|
| **DROP** | 司机将货柜停在仓库，离开后仓库自行安排卸货 | 取**预约卸货时间** |
| **LIVE** | 司机现场等候，仓库当场卸货 | 取**预约单实际到仓时间** |

### 4.2 未预约整柜处理

`[KB]` 来自 [`直发预约送仓（常见问题）.md`](../../../_kb/service-team/inbound-services-doc/直发预约送仓（常见问题）.md)

- 若整柜未预约直接送仓，仓库**可能拒收**
- 若仓库安排了收货，则收取**未预约违规费**（按订单维度）
- 建议提前 2–3 天预约，以确保有足够的 Slot 资源

## 五、Slots 与库容限制

`[KB]` 来自 [`inbound-quota-knowledge.md`](../../../_kb/product-team/winit/overseas/inbound-quota-knowledge.md)

- **Slots**：海外仓预约时间窗口资源，每日可用数量有限
- 高峰期（电商大促前后）Slots 可能快速被占满
- 库容紧张时，仓库可能对特定件型/品类实施**入库配额**
- 客户应提前关注库容信号（`warehouse/capacity-signal`），避免货物到达时无 Slot 可用

## 六、分批到仓处理

`[KB]` 来自 [`一、背景说明.md`](../../../_kb/service-team/inbound-services-doc/一、背景说明.md)（分批到仓货物确认操作文档）

当一个预约单下的多个入库单货物分批次到达时：

1. 仓库卸货完成确认后，系统生成**未到仓货物待办**并邮件通知客户
2. 客户须在 **3 个自然日**内确认未到仓货物的处置：
   - **确认不发货**：系统将相关包裹终止
   - **确认分批到仓**：系统自动拆分为新入库单（原单号 + 后缀 A/B/C），可重新预约
   - **确认已发货需调查**：提交质控调查，调查结果通知客户
3. 若超过 3 个自然日未确认，系统**自动终止**未到仓包裹 `[KB]`

> 特殊情形：若整个入库单均未到仓，不支持拆单。客户需在预约单中解绑入库单后重新预约。`[KB]`

## 七、修改 PSC / 送仓方式

`[KB]`：入库单在以下状态下可退回草稿自行修改 PSC（送仓方式）：

- **已下单（OD）**
- **验货完成**
- **运输中（TS）**

修改路径：万邑联 → 海外仓 → 入库 → 全部订单 → 点「回到草稿」→ 重新选择 PSC

## 八、常见坑

| 问题 | 说明 |
|---|---|
| 预约码忘记给司机 | 仓库可能拒收或无法识别货物，造成延误 |
| 预约时间与实际到仓时间不符 | 提前/延迟到仓均可能触发违规或 Slot 浪费 |
| 多个订单合并预约但送仓方式不一致 | 系统不允许合并，需分别创建预约单 |
| 仓内上架单是否需要预约 | **不需要**：仓内上架单只需下单选择对应 PSC，不触发预约也不产生散装卸货费 `[KB]` |
