# Flow 07：海外仓到仓、卸货、上架与异常处理

> **适用范围：** 货物到达 Winit 海外仓后的所有环节：卸货、验货（仅海外验链路）、上架入库，以及各类入库异常的分类与处置。
> **状态对应：** `PEWC → EWC → SHD`，以及 `STOP` 异常终止场景。
>
> 见 [playbook.md](../playbook.md)「上架 SLA 速查」与「状态机」。

---

## 一、海外仓到仓时间定义

`[KB]` 来自 [`咨询入库单上架时间及催上架处理流程.md`](../../../_kb/service-team/inbound-services-doc/咨询入库单上架时间及催上架处理流程.md)

| 送仓方式 | 到仓时间取值 |
|---|---|
| **快递** | 快递单号的妥投时间；无快递单号则取实际卸货时间 |
| **散货** | 预约单的实际到仓时间 |
| **整柜 LIVE 卸货** | 预约单的实际到仓时间 |
| **整柜 DROP 卸货** | 预约单的**预约卸货时间** |

---

## 二、卸货流程

### 2.1 快递到仓

- 仓库根据快递妥投扫描记录完成收货
- 系统自动关联到对应入库单（按包裹条码匹配）
- 到仓后状态更新为 `PEWC`（首个包裹卸货），全部到仓后变 `EWC`

### 2.2 散货到仓

- 司机凭**预约码**到仓，仓库按预约单核对货物信息
- 仓库工作人员逐托/逐件清点包裹条码，完成卸货登记
- 到仓时间取预约单实际到仓时间

### 2.3 整柜到仓

- **DROP**：司机留柜，仓库排班后自行卸货，到仓时间取预约卸货时间
- **LIVE**：司机等候，仓库现场开柜卸货，到仓时间取实际到仓时间
- 卸货完成后，系统逐包裹更新到仓状态

---

## 三、上架流程

### 3.1 标准头程与自验链路

- 卸货完成（`PEWC`/`EWC`）后，仓库按 SLA 安排上架
- 仓库按 SKU 分区上架，上架完成后状态变 `SHD`
- 分批上架：多批次包裹可以陆续达到 `PEWC → EWC → SHD`

### 3.2 海外验链路

- 卸货后先进行**验货**（开箱点数、SKU 核对），再上架
- 海外验完成后产生验货数据，驱动上架
- 验货时间包含在 SLA 计算内（到仓后上架 SLA 已包含验货时间）

### 3.3 催上架流程

`[KB]`：

- **SLA 内**：提示客户上架时效稳定，将在 SLA 内完成
- **SLA 超期**：提交加急申请，需提供：加急具体原因、包裹号/箱号列表、核心 SKU 明细及数量
- **客户反馈已送仓但系统未更新**：需提供快递妥投 POD 或快递单号截图，转交仓库人工核对

## 四、异常类型地图

`[KB]` 来自 [`inbound-exception-handling.md`](../../../_kb/product-team/winit/in-warehouse/inbound-exception-handling.md)

### 4.1 按处理方式分类

| 异常类型 | 说明 | 客户需操作 |
|---|---|---|
| **知悉类** | 仅记录备案，推送通知，无需物理操作 | 不需要 |
| **操作类** | 仓库按标准化流程直接处置，同步通知 | 不需要 |
| **操作增值类** | 仓库暂存货物，等待客户下发增值服务指令 | **需要**（下增值单） |

### 4.2 常见异常类型详解

#### 数量差异异常

| 场景 | 处理路径 |
|---|---|
| 标准海外仓入库单少货 | 查 TOM 异常事件 → 有异常事件：复制仓库通知给客户；无异常：走「上架少单品」SOP |
| 直发海外验/自验单少货 | 提交增值服务（库内盘点）核实；确认万邑通原因漏上可免收盘点费 `[KB]` |

库内盘点费用参考 `[KB]`：
- AU：标准尺寸 0.55 AUD/SI；超大 1.20 AUD/SI；最低 55 AUD/单
- US / UK / DE：见价卡

#### 条码类异常

| 异常 | 场景 | 处置方式 |
|---|---|---|
| **包裹条码异常** | 无条码 / 条码破损 / 条码状态异常 / 多个冲突条码 | 货物上架至异常暂存区；客户提交「贴标/换标」增值 |
| **单品条码无法识别** | SKU 无条码、条码不完整、重复、系统未录入 | 关联第三方编码（FNSKU 等）到 Winit SKU；或提交拍照增值 |
| **单品条码无法扫描** | 标签磨损，扫描枪无法读取，人工可识别 | 仓库直接补打条码，操作类异常（不需客户操作）|

#### 串仓异常

`[KB]` 来自 [`inbound-exception-handling.md`](../../../_kb/product-team/winit/in-warehouse/inbound-exception-handling.md)

- **场景**：直发包裹（自验或海外验）送到了错误的仓库（非入库单指定目的仓）
- **处置选项**（客户选择）：
  1. 更改目的仓，在当前仓库完成验货上架
  2. 转运至原目的仓（客户自提转运或联系客服提交非标增值转运）

#### 包装/质量异常

| 异常 | 处置 |
|---|---|
| 外包装破损 / 受潮 / 未封口 | 操作增值类，暂存；客户提交「销毁」或「包装加固」增值 |
| 商品裸装（无外包装）| 仓库上架后冻结；客户勾选裸货标签，开通出库加包装权限 `[KB]` |
| 商品质量明显异常（碎片等）| 暂存；客户提交「销毁」增值 |

#### 尺重异常

- **场景**：入库单商品实物尺重与系统登记尺重不符
- **处置**：仓库复测后修改系统尺寸重量，直接上架（操作类，无需客户操作）`[KB]`
- **费用影响**：尺重变化可能影响后续计费，客户可关注

#### SKU 尺重异常（出库超重拦截）

- 出库打包完成后发现包裹重量超出供应商限制
- 仓库拦截超重包裹，作废订单，重新上架
- 客户需提交「库内随机检查商品体积重量」增值服务复测 `[KB]`

## 六、增值服务触发节点

入库到仓阶段常见触发增值服务的场景：

| 增值服务 | 触发条件 |
|---|---|
| 贴标 / 换标 | 包裹/商品条码缺失或无法识别 |
| 库前拍照 | 高值商品或需存证 |
| 包装加固 | 外包装破损需修复 |
| 销毁 | 包装质量异常，客户放弃 |
| 库内盘点 | 数量异常核实 |
| 库前换标 | 替换第三方条码（如 FNSKU→Winit SKU）|
