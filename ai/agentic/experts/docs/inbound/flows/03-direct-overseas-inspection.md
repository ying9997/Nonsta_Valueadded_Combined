# Flow 03：直发 + 海外验（Winit 海外仓验货）

> **适用条件：** 客户货物到达 Winit 海外仓后，由海外仓工作人员完成开箱点数验货，再上架入库。客户不在国内自验，发货时可不提供完整箱单（走绿色通道/预报）。
> **PSC 前缀：**
> - `OW01032*`：直发海外验（客户自行安排头程直发）
> - `OW01031*`：Winit 承运 + 海外验（Winit 承运头程到海外仓）
>
> 见 [playbook.md](../playbook.md)「产品选择决策树」→「直发 + 海外验」分支。

---

## 一、全链路概览

```
[信息流]
 下单（选 PSC OW01031/32）→ 填写 SKU + 数量
  ├── 有箱单：上传完整装箱明细
  └── 无箱单（绿色通道）：仅上报 SKU 和预计数量，海外仓开箱后核实
 → 轨迹追踪（DR→OD→[RE]→TS→PEWC→EWC→SHD）

[实物流]
 客户/Winit 发货 → 国际运输 → 海外仓卸货（PEWC）
  → 海外仓开箱验货（数量 × SKU × 条码）→ 上架（SHD）
```

---

## 二、三种海外验模式

`[KB]` 来自 [`inbound-faq.md`](../../../_kb/product-team/winit/in-warehouse/inbound-faq.md) 与 [`inbound-product-details.md`](../../../_kb/product-team/winit/in-warehouse/inbound-product-details.md)

### 2.1 标准海外验（有箱单）

- 客户下单时上传完整装箱明细（SKU × 数量 × 箱号）
- 海外仓按箱单完成开箱核对，数量/SKU 对齐后上架
- 规则：上架前允许多验（可比箱单多验）；上架后是否允许多验看白名单 `[KB]`
- 少货处理：标准流程见 [`客户反馈上架数量异常处理流程.md`](../../../_kb/service-team/inbound-services-doc/客户反馈上架数量异常处理流程（标准海外仓入库单+直发海外验）.md)

### 2.2 无箱单绿色通道

- 下单时**不提供箱单**，仅填写 SKU 和预计数量
- 货物到仓后，海外仓开箱实际清点，系统按实际数量上架
- 适合货物来源复杂、无法提前整理装箱明细的情况
- PSC 示例：`OW01032*` 中含「绿色通道」相关条目 `[推断]`
- 规则：海外验无箱单**不允许多验**（实际数量超出入库单不能继续上架）`[KB]`

### 2.3 预报海外验

- PSC `OW01032*` 中含「预报」条目 `[KB]`
- 特点：客户先预报货物信息，货物实际到仓后海外仓再根据预报做验货
- 适用于分批次发货但提前锁定入库单的场景
- 信息流：创建入库单（预报数量）→ 货物多批到仓 → 海外仓按批次验货累计上架

---

## 三、信息流步骤

| 步骤 | 说明 |
|---|---|
| 1. SKU 注册 | 必须提前在万邑联注册并发布，否则海外仓无法识别 |
| 2. 创建入库单 | 选择 OW01031/OW01032，填写目的仓 |
| 3. 上传箱单或预报 | 有箱单：上传装箱明细；无箱单：仅填 SKU 预报数量 |
| 4. 安排发货（OD→TS） | 客户自发或 Winit 承运（OW01031） |
| 5. 海外验完成后系统更新 | EWC → SHD（验货数量以仓库实际为准） |

---

## 四、实物流步骤

### 4.1 发货与国际运输

- `OW01032`：客户自行安排物流（快递/散货/整柜）直发海外仓
- `OW01031`：Winit 安排头程运输（类似标准头程，但目的是直接送海外仓验货）
- 散货/整柜必须提前预约（见 [flows/06](06-appointment-and-delivery.md)）

### 4.2 海外仓卸货（`PEWC`）

- 到仓方式决定到仓时间计算规则（同标准头程，见 [playbook.md](../playbook.md)「上架 SLA」）
- 卸货后仓库工作人员开箱，逐件扫描 SKU 条码

### 4.3 海外验货过程

- 仓库根据入库单（有或无箱单）进行实物核对
- **有箱单**：与箱单逐项对比，差异登记异常事件
- **无箱单**：仓库实际清点，按实际数量完成系统录入
- 如发现 SKU 无法识别（条码缺失/损坏），需登记条码异常事件并等待客户处理（见 [flows/07](07-receiving-putaway-exceptions.md)）

### 4.4 上架（`SHD`）

海外验上架 SLA（见 [playbook.md](../playbook.md)「上架 SLA 速查」直发海外验部分）：
- 美国空卡/DHL：**2 工作日**
- 美国其他：**5 工作日**
- 非美国空卡：**2 工作日**；快递：**3 工作日**；海运：**4 工作日**；空派/海派：**5 工作日**

## 五、有箱单 vs 无箱单 对比

| 项目 | 有箱单（标准海外验） | 无箱单（绿色通道） |
|---|---|---|
| 下单要求 | 需上传完整箱单 | 仅填 SKU 预报数量 |
| 上架数量 | 按箱单核对，差异登异常 | 按实际清点数量上架 |
| 多验规则 | 上架前允许多验（白名单后不可）`[KB]` | 不允许多验 `[KB]` |
| 少货处理 | 异常事件 + 赔偿流程 | 以仓库实际为准 |
| 上架速度 | 稍快（箱单对照效率高） | 相对慢（需逐件点数）`[推断]` |

---

## 六、常见坑

| 问题 | 说明 |
|---|---|
| SKU 未注册 | 海外仓无法识别条码，触发条码异常，上架延误 |
| 无箱单但多验 | 系统直接拒绝，超出预报数量的商品无法上架 `[KB]` |
| 串仓 | 发错仓库触发「直发包裹串仓」异常，需客户确认处置方式（见 [flows/07](07-receiving-putaway-exceptions.md)） |
| 送仓方式错选 | 选快递实际散货送 → 散装卸货费；选散货实际快递送 → 未预约违规费 |
