# Flow 04：国内仓/中转仓节点

> **适用范围：** 本分册描述 Winit **国内仓（中转仓）**在入库链路中的作用节点，仅与以下产品线相关：
> - **标准海外仓入库** (`OW01011*`)：全程经过国内仓
> - **Winit 承运自验** (`OW01021*`)：头程段经过国内仓，但国内仓不复检内容
>
> 客户直发产品（`OW01022*`、`OW01032*`）**不经过 Winit 国内仓**，本分册不适用。
>
> 见 [playbook.md](../playbook.md)「产品选择决策树」与「状态机 RE 节点」。

---

## 一、国内仓在链路中的位置

```
[标准头程 OW01011*]
揽收/自送 → 国内仓收货(RE) → 质检/验货 → 出库发运(TS) → 国际运输 → 海外仓

[Winit承运自验 OW01021*]
揽收/自送 → 国内仓收货(RE) → 转运发出(TS) → 国际运输 → 海外仓
（国内仓不做验货内容核对，客户已完成自验）
```

---

## 二、国内仓节点详解

### 2.1 收货（`OD → RE`）

- 国内仓完成货物签收扫描后，入库单状态变为 `RE`（已收货）`[KB]`
- 客户可在万邑联查看 `RE` 状态确认国内仓已收货
- 揽收上门与客户自送均通过此节点

### 2.2 质检与验货（仅标准头程 OW01011*）

- Winit 国内仓对货物进行**质量检验**，主要核对：
  - 包裹完好性（A+ / A / B / C 分级）
  - SKU 与箱单匹配度（数量、条码）
  - 重量/体积（计费依据）
- 验货完成后，出库前系统已锁定货物清单

### 2.3 出库发运（`RE → TS`）

`[KB]` 来自 [`海外仓头程快递入库服务常见问题.md`](../../../_kb/service-team/inbound-services-doc/海外仓头程快递入库服务常见问题.md)

**国内仓出库时效（快递产品）：**

| 收货时间 | 出库时效 |
|---|---|
| 周一至周五验货完成 | 验货完成**次日**交给快递供应商 |
| 周六至周日验货完成 | **下周一**交给快递供应商 |

> 注意：出库时效指的是交给承运快递商的时间，不等同于货物起飞/出港时间。起飞/出港时效取决于快递商的操作节点。

### 2.4 出口报关

- 国内仓出库后同步完成出口报关（快件申报）
- 报关完成后触发 `TS` 状态，进入国际运输阶段
- 详细出口清关分支见 [flows/05-customs-and-international.md](05-customs-and-international.md)

## 三、国内仓与实物流对齐关系

| 信息流状态 | 实物流位置 | 说明 |
|---|---|---|
| `DR`（草稿）| 货物在客户手中 | 未下单确认 |
| `OD`（已确认）| 等待揽收/客户送货 | Winit 已接受委托 |
| `RE`（已收货）| 国内仓收货完成 | 国内仓已扫描入库 |
| `TS`（运输中）| 国内仓出库，交给承运商 | 出口发运，开始国际段 |

> 此阶段**不产生海外预约单**。直发链路的预约在 `TS` 之后、货物实际到仓前提交（见 [flows/06](06-appointment-and-delivery.md)）。

## 四、Winit 承运自验（OW01021*）的国内仓角色

`OW01021*` 经过国内仓，但与标准头程有以下差异：

| 项目 | 标准头程（OW01011） | Winit 承运自验（OW01021） |
|---|---|---|
| 国内仓验货 | 完整质检（SKU + 数量对照箱单） | 仅收货扫描，不对验货内容复核 |
| 箱单要求 | 必须上传完整箱单 | 客户已完成自验，箱单在客户侧 |
| 状态 RE | 收货后生成 | 收货后生成 |
| 出库时效 | 同上（次日/下周一） | 同上（次日/下周一） |

## 五、常见问题

| 问题 | 说明 |
|---|---|
| 客户询问国内仓多久出库 | 按「验货次日」或「下周一」给出参考；如超期查 TOM 是否有异常 |
| 显示 RE 后迟迟未变 TS | 可能是等待仓库排班出库，或有异常需确认 |
| 国内仓损坏赔付 | 国内仓质检若发现货物损坏，标注包裹等级（B/C 包），后续出库不承运 C 包 `[推断]` |
