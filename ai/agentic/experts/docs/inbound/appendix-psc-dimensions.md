# 附录：PSC 维度矩阵

> **定位：** 本文件是 PSC 编码的**决策路由摘要**，帮助快速定位客户使用的产品所属产品线与关键特征。
> 完整 76 条 PSC 编码及中英文对照见：[`_kb/system-team/inbound-psc-codes.md`](../../_kb/system-team/inbound-psc-codes.md)

---

## 一、PSC 编码体系概览

所有入库相关 PSC 编码均以 `OW01` 开头，第 5–7 位标识产品系列：

| PSC 前缀段 | 产品系列 | 产品线 | 验货方式 | 典型头程 |
|---|---|---|---|---|
| `OW01011*` | 头程产品 | 标准海外仓入库 | Winit 国内仓验货 | Winit 承运 |
| `OW01021*` | Winit 承运自验 | 直发 + 自验 | 客户自验 | Winit 承运 |
| `OW01022*` | 直发自验 | 直发 + 自验 | 客户自验 | 客户自发 |
| `OW01031*` | Winit 承运海外验 | 直发 + 海外验 | Winit 海外仓验货 | Winit 承运 |
| `OW01032*` | 直发海外验 | 直发 + 海外验 | Winit 海外仓验货 | 客户自发 |
| `OW01041*` | 国际快递 | 标准头程（快递产品）| Winit 国内仓验货 | 国际快递商 |

### 客户自验系列（OW01021 / OW01022）

| PSC 系列 | 描述 | 头程方式 | 自验模式 |
|---|---|---|---|
| `OW01021*` | 客户自验 · Winit 承运 | Winit 安排头程 | PDA / API / Excel / 免验 |
| `OW01022*` | 客户自验 · 卖家直发 | 客户自选物流 | PDA / API / Excel / 免验 |
| `OW01023*` `[推断]` | 客户自验 · Winit 承运快递 | Winit 承运快递 | PDA / API（抽验规则文档中出现） |

自验模式细分 `[KB]`：

| 验货方式 | 新/旧自验 | 下单时是否需要箱单 |
|---|---|---|
| PDA 扫描枪 | 旧自验 + 新自验 | 旧自验需要；新自验不需要 |
| API 对接 | 旧自验 + 新自验 | 旧自验需要；新自验不需要 |
| Excel 导入 | 旧自验 + 新自验 | 需要 |
| 免验货 | 仅旧自验 | 需要（但不做物理核对）|

### 直发海外验系列（OW01031 / OW01032）

| PSC 系列 | 头程方式 | 箱单状态 | 验货场所 |
|---|---|---|---|
| `OW01031*` | Winit 承运头程到海外 | 有箱单 / 无箱单均支持 | Winit 海外仓 |
| `OW01032*` | 客户自发直送海外仓 | 有箱单 / 无箱单（绿色通道）/ 预报 | Winit 海外仓 |

`OW01032` 常见变体 `[KB]`：

| 变体名称（参考）| 说明 |
|---|---|
| 有箱单海外验 | 客户提供完整装箱明细 |
| 无箱单绿色通道 | 无箱单，海外仓开箱实数 |
| 海外验（预报）| 客户预报 SKU 与数量，分批验货 |
| 仓内上架单 | 货物已在仓库内，直接上架，无需预约，无散装卸货费 |

## 三、清关类型维度

| 清关类型 | 适用 PSC 名称关键词 | 目的国 | 说明 |
|---|---|---|---|
| 标准一般贸易 | （默认，无特殊后缀） | 所有 | 正常缴纳进口税 |
| 电商清关 | `*-电商清关` | 美国等 | 低税率或简化申报，适合小件 |
| 包税 | 美森散货 / 普船散货 | 美国 | 税费包含在产品价格内，供应商代办 |
| 英国 PVA 递延 | 含「递延」或「PVA」的产品 `[推断]` | 英国 | 进口 VAT 递延入账 |
| 德/比递延清关 | 含「递延清关」 `[推断]` | DE / BE | 自有进口商递延，需提前申请开通 |

## 四、送仓方式维度

| 送仓方式 | 预约要求 | PSC 选择对应 |
|---|---|---|
| 快递面单（逐件） | 免预约 | 选「快递」类 PSC |
| 散货（LCL / 卡车散件）| 必须预约 | 选「散货」类 PSC |
| 整柜（FCL）| 必须预约 | 选「整柜」类 PSC（20GP / 40GP 等）|

> 送仓方式选错会产生违规费（散装卸货费或未预约违规费），且**不支持退费**。见 [flows/06](flows/06-appointment-and-delivery.md)。
