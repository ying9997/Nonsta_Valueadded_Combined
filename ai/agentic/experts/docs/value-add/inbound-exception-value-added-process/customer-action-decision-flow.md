# 客户处理意图决策流程

本文件用于 `value-add-product-recommendation` 将用户诉求归一到 VASC 推荐方向。

| 用户意图 | 推荐方向 | 缺失确认项 |
|---|---|---|
| 继续上架 / 原单上架 | 原单相关 VASC 候选 | 原入库单状态、异常对象、是否允许继续上架 |
| 新单上架 | 新单相关 VASC 候选 | 新入库单号、对象层级、是否已创建新单 |
| 销毁 | 销毁处理方向 | 销毁对象、数量、仓库限制、是否需要客户确认 |
| 自提 | 自提处理方向 | 自提对象、提货人、仓库/阶段限制 |
| 拍照 / 测量 / 质检 | 拍照、测量、QC 相关服务项 | 拍照维度、数量、附件或模板证据状态 |
| 补条码 / 补标签 / 包装处理 | 条码、贴标、换标、包装处理相关服务项 | 包裹/商品/单品层级、原子互斥、字段证据 |

## 约束

- 意图归一只产生推荐方向和缺失确认项。
- 首选 VASC 必须由异常到 VASC 映射和 VASC 产品知识共同支撑。
- 对 inactive 或证据不足的 VASC，只能作为待确认线索。
