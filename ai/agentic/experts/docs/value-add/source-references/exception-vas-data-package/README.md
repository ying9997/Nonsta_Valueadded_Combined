# Exception VAS Data Package

本目录预留入库异常、VASC、服务项编排和字段证据相关的机器可读数据副本。

| 子目录 | 用途 | 当前状态 |
|---|---|---|
| `source-snapshots/` | 标准异常、增值服务事件、VASC master、字段快照 | 待补全量副本 |
| `data/raw/` | VASC 详情页 `detail_items` 等原始抓取证据 | 待补全量副本 |
| `data/normalized/` | 编排、映射、字段证据状态的标准化数据 | 待补全量副本 |
| `data/reports/` | 覆盖率、缺口和审查报告 | 待补全量副本 |

当前运行时和规划先消费 `docs/value-add/relationship-mappings/` 中的人读摘要。
