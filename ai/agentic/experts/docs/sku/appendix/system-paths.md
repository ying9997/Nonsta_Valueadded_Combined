# 万邑联 / TOM 系统路径速查

> 供 `sku/profile`、`sku/registration-guide`、P2 `compliance-check` 引用。对客描述用「万邑联」「平台」，不输出 TOM URL。

---

## 万邑联（卖家）

| 场景 | 路径 |
|------|------|
| 商品列表 / 发布态 | 商品管理 → 商品信息 |
| 商品编辑 / 特殊属性 | 商品信息 → 编辑 → 商品特性 → 商品属性 |
| 进口国维度（德国 WEEE 等） | 商品编辑 → 进口申报信息 → 选择进口国行 |
| 退回原因 | 商品信息 → 商品详情（顶部提示条） |
| 头程直发限制原因 | 商品信息列表 → 头程类型列 → 感叹号 |
| 禁止入库原因 | 商品信息列表 → 禁止入库列 → 感叹号 |
| 资料证书上传 | 商品详情 → 资料证书 → 国家 ALL |
| 审核任务 SLA | 商品维护任务列表 → 应维护完成时间 |
| 待办汇总 | 商品信息 → 待办提醒（待提交/待修改/待补充） |
| 禁限运清单 | 公告 → 搜索「禁限运清单」 |
| 偏好 / 服务设置 | 个人中心 → 服务设置 → 偏好设置 |
| 海外仓库存禁售详情 | 库存相关 → 不合规禁售详情（卖家视图） |

---

## TOM（客服内部）`[KB]`

| 场景 | 路径 |
|------|------|
| 禁售原因 | 库存 → 库存管理 → 库存查询 → 不合规禁售列 → 点击数量 |
| 商品主数据（内部） | 管理商品管理 → 商品（引用退回/直发等内部页） |

**查询条件**：库存查询须选仓库，或提供商品条码/商品编码。
