# 06 — 特殊属性解除（取消勾选）

> 场景：客户认为 SKU 标注了带电池/液体/磁性/粉末/刀片/DG 等，实物不符，要求取消。各 <2%。

---

## 通用原则 `[KB]`

1. **先确认实物**（以实际发货为准）  
2. 若实物**确有**该属性 → 不可取消，无需改  
3. 若实物**没有** → 万邑联修改并提交审核  
4. 仍无法解决 → 转人工

**修改路径（统一）**：

万邑联 → **商品管理** → **商品信息** → 找到 SKU → **商品编辑** → **商品特性 / 商品属性** → 取消对应勾选 → 右下角 **提交** → 等待审核

---

## 分属性话术摘要

| 属性 | 实物确认要点 | 特别说明 |
|------|--------------|----------|
| **带电池** | 本体或包装内是否含电池 | 见 `OnZEbCmrnoDVvgxlV6IctXPynig.png` |
| **带液体** | 含少量液体也算（如湿巾） | |
| **带磁性** | 含弱磁性也算 | |
| **带粉末** | 含干燥剂也算 | |
| **带刀片** | 能切割皮肤造成严重伤害的刀片类 | 确有刀片则**不可取消**；法规参考英国 2019 法案 |
| **DG** | 先查电池参数 WH 是否填错 | 见 [07](07-compliance-certificates.md) §DG |
| **化工** | 是否尼斯分类 1–4 类或化学加工物质 | 查询 https://www.tmkoo.com/tm-class/ |

---

## DG / 电池能量自查 `[KB]`

公式：**电池能量(Wh) = 电压(V) × 容量(Ah)**；1Ah = 1000mAh  

示例：200mAh、3V → 0.2Ah × 3V = **0.6Wh**

参数错误 → 修改后重提；确认无误仍标 DG → 转人工。

---

## 尺重异常（注册/自验）`[KB]`

触发词：「注册尺寸重量异常」「验货尺重密度不符」

说明：万邑联长宽厚重指 **包装完成后入库状态** 的实际数据。

- 填错 → 修改重提  
- 确认无误仍报错 → 转人工
