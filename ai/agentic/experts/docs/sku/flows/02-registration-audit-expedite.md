# 02 — 注册审核与加急

> 场景：SKU 已提交注册，客户问审核进度、要求加急。  
> 咨询量约 **61%**（最高频）。

---

## 触发词 `[KB]`

- 「SKU 加急审核」「注册加急」「审核要多久」

---

## 标准话术 `[KB]`

尊敬的客户，您好！您提交的 SKU 已进入审核流程，预计审核时效：**{引用系统应维护完成时间}**。

如以上时效符合预期，请您耐心等待；如若需加急，可点击 **加急**（加急原因：①急需下入库单 ②急需打印条码标签 ③急需关联退货商品），我们会尽快处理。

---

## 系统界面事实（截图转写）`[KB]`

**路径**：商品维护任务列表（维护编号 MT 开头）

| 字段 | 含义 |
|------|------|
| 状态 | 待维护 / 已维护等 |
| 应维护完成时间 | **对客承诺的审核完成时点**（红框高亮字段） |
| 维护原因 | 如「智能匹配」 |
| 维护编号 | 如 `MT01000000011143981` |
| 子行 SKU | 如 `GD11003608W01`，进口国、申报价值等 |

机器人应优先读取 **应维护完成时间** 填入话术，而非编造 SLA。

---

## 加急产品方案 `[KB]`

- 给客服加急功能：**无需填表单**、无需商品组重复回复
- 识别「SKU 加急审核」「注册加急」→ 自动弹出上述话术 + 加急按钮

---

## 分支

| 条件 | 动作 |
|------|------|
| 时效可接受 | 引导等待 |
| 客户点击加急 | 记录原因枚举（下入库单 / 打标 / 退货关联） |
| 待修改（退回） | 转 [03-return-resubmit](03-return-resubmit.md) |
| 待补充（缺 WEEE/GPSR/条码/证书） | 转 [07-compliance-certificates](07-compliance-certificates.md) |

---

## 待办提醒区（商品信息页）`[KB]`

万邑联 → 商品管理 → 商品信息顶部 **待办提醒**：

| 分类 | 含义 |
|------|------|
| 待提交 | 草稿信息完整，待提交审核 |
| 待修改 | 初审退回（858）或更新退回（20） |
| 待补充 | 缺 WEEE/德语说明书/GPSR/包材（91）；缺第三方商品条码（32）；缺证书资料（15） |
