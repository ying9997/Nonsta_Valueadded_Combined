# computer-science-foundation — 计算机基础学习体系

> 用 AI_EXPERT 的真实项目学习数据结构、操作系统、网络/协议。  
> 当前重点：接触、浏览、记忆、理解、搭建体系。

## 学习层级

| 层级 | 判定标准 | 在本目录里的动作 |
|------|----------|------------------|
| 接触 | 翻过书、见过名词 | 知道项目里哪里出现了这个概念 |
| 浏览 | 看过材料 | 能顺着路径读到相关 README、方案或代码 |
| 记忆 | 能复述 | 能说出概念定义、典型用途、项目例子 |
| 理解 | 能用自己的话讲出来 | 能说明“为什么这里要用它，不用会怎样” |
| 搭建体系 | 能把知识点串联起来 | 能把项目、数据结构、OS、网络协议放进一张图 |
| 贯通 | 能举一反三灵活解题 | 后续补：跨项目练习题 |
| 辨析 | 能发现异同 | 后续补：相似概念对比卡 |
| 提炼 | 能从做题中总结规律 | 后续补：错题/案例复盘模板 |
| 创新 | 能融汇多个领域知识催生新知识 | 后续补：新 Agent / 新流程设计题 |
| 内化 | 能用知识改变自己的行为 | 后续补：日常开发检查清单 |

## 使用方式

1. 先读 [project-concept-map.md](project-concept-map.md)，建立“项目里哪里有这个概念”的接触层。
2. 顺着“仓内路径”打开项目 README、方案、关键脚本，完成浏览层。
3. 对每个项目写 3 句话：概念定义、项目例子、不用它会怎样，完成记忆层。
4. 把概念改写成自己的业务语言，完成理解层。
5. 最后把同类概念连起来：树负责层级，队列负责顺序和解耦，哈希表负责快速定位，协议负责系统间协作。
