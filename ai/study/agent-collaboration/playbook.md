# Agent 协作 Playbook（可复制口令）

> 从复盘提炼。UI 没有 Ask 模式时，用**消息头模式锁**即可。  
> 真源：`learn(xuexi)/agent_collaboration/playbook.md`

---

## 1. 三种模式（一会话尽量只干一种）

| 模式 | 干什么 | 禁止 |
|------|--------|------|
| **DO** | 改文件、出用例、回填 HANDOFF | 长解释、换仓库、扩场景 |
| **ASK** | 只解释概念/路径/截图含义 | **任何写盘**、给新执行方案 |
| **FIX** | 修明确偏差 | 顺手重构、扩 eventCode |

同会话模式切换 ≥2 次 → 收工回填，**新开聊天**；首条只贴主线文档 + 当前一条目标。

**答疑助手会话** 与 **HANDOFF 交付执行会话** 物理隔离：搞懂了再回 DO 窗下指令。

---

## 2. 消息头模板

### ASK（无 Ask 按钮时用这个）

```text
【模式=ASK｜只解释不改任何文件｜不要跑写盘命令】
我只想搞懂：……（一句话）
对照主线文档哪一条：……
回答≤5 条；不要给执行清单、不要改路径建议以外的方案。
```

### DO

```text
【模式=DO｜执行】
必读：……（HANDOFF 或指定文件）
唯一目标：……
只改：……
禁止：……
收工：回填 HANDOFF §5 一行 + 三行（归属/主线推进/已改路径）
```

### FIX

```text
【模式=FIX｜不扩 scope】
现象：……（1 句；关键字段最多 5～10 行，禁止整包 JSON dump）
期望：……（1 句）
只改：……
禁止：改正式包 / 新建进度 md / 扩场景
改完回填 HANDOFF §5 一行。
```

### 新参考登记（扔路径前必做）

```text
【登记参考｜不执行】
真源路径：D:\...\xxx
本任务：只读 / 可改（二选一）
产物应落：哪一层（权威料 / 编排 / 决策层 / 运行时）
```

## 3. 失控前兆（出现就熔断）

- 连续截图且没有「我要你做什么」  
- 贴整包 Coze/节点 JSON  
- 同一条里又问概念又叫改文件  
- 参考路径和当前产物目录不在同一层地图  
- 仓库 URL 说错（experts vs service-guide 等）  
- 感觉慌、想连发 → 先写清：主线是标准还是非标？成功长什么样？当前 DO/ASK/FIX？

---

## 4. Cursor 备注

「添加」菜单里的计划模式 ≠ Ask。  
没有 Ask 时：Plan +「只讨论不改文件」，或直接用上面 ASK 口令。
