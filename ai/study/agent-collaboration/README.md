# Agent 协作复盘

> 专门沉淀：**人和 Agent（Codex / GPT / Cursor / Claude）协作时怎么失控、根因、可执行规矩**。  
> 与业务交付文档（HANDOFF / D6）分离——这里只记「协作方法」，不记业务结论。  
> 归属：`learn(xuexi)/` 学习层（与 [working-habits](../working-habits/) 并列）。

## 怎么用

1. 新开 Agent 会话前：扫一眼最新一篇 `retros/` 的「失控前兆」与「模式锁」。  
2. 一次协作明显走偏后：新增一篇 `retros/YYYYMMDD_主题.md`，只写事实轨迹 + 根因 + 下轮改法。  
3. 可复用模板、口令集中在 [`playbook.md`](playbook.md)。
