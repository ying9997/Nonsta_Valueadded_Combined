## Codex 校验规则

每次 Codex 继续训练前，必须先读取：

- `agent-map-training/110-question-curriculum.md`
- `runtime/curriculum.json`
- `runtime/progress_state.json`
- `_inbox/current-session-sync.md`

每次回复用户时，必须先给出一行进度：

```text
进度：阶段 4/8 · 文件与能力层级映射 · 当前 4.7-4.9/10 · 已完成 6/10
```

回答训练题必须使用：

```text
【回答结论】 -> 【思考过程】 -> 【依据】
```

如果用户说“进入下一阶段”，Codex 必须先校验：

1. 当前阶段的所有题目是否完成。
2. 是否已有对应 `ARCHIVE_PACKET`。
3. `progress_state.json` 是否已经更新。
4. `progress-board.md` 是否同步更新。

校验未通过时，不能直接进入下一阶段。
