# AI Agent 地图式学习训练：110 题主课程表

状态：2026-08-10 由用户提供并确认，后续训练题目必须以本文件为唯一主课程来源。

## 使用规则

- 每次进入新阶段或新题组前，必须先读取本文件。
- 不允许在本文件之外自行编造阶段题目。
- 如果本文件与 `runtime/curriculum.json`、`progress-board.md` 不一致，以本文件为准，并先修正状态文件。
- 回答训练题时默认使用结构：`【回答结论】 -> 【思考过程】 -> 【依据】`。

## 阶段 6：概念四步法训练

目标：针对“来源优先”的思维定势，训练“作用优先”。

每遇到一个概念，都问：

| # | 问题 | 目的 |
|---|---|---|
| 6.1 | 它是什么？ | 定义概念类型 |
| 6.2 | 它在当前模块里控制什么？ | 明确作用 |
| 6.3 | 没有它会怎样？ | 明确缺失兜底 |
| 6.4 | 它从哪里来？ | 最后再追来源 |

要训练的 baseline 概念：

| 概念 | 为什么要拆 |
|---|---|
| intent | 决定业务分支 |
| routePath | 决定 KB-only / API-chain |
| branch | 决定最终输出类型 |
| kb_only | 纯知识指引路径 |
| api_chain | 查数 + 解读路径 |
| booking.list | 系统事实来源 |
| load-booking-kb | 知识注入节点 |
| llm-analyze | 非确定性分析节点 |
| format-output | 输出契约节点 |
| need_human | 人工兜底分支 |
