# B 类场景 SOP 模板

> 用途：LLM 生成 SOP 时参考本文件中的模板结构
> 来源：非标增值单审核SOP知识库-新版

---

## 1. 良品/不良品检测

**模板结构：**
```
【需求背景】
{客户原因/异常背景}

【检测要求】
- 检测SKU：{SKU编码}
- 检测方式：{外观检查/功能测试/尺寸核对/其他}
- 检测数量：{数量}

【判定标准】
- 良品标准：{具体标准}
- 不良品标准：{具体标准}

【处理方式】
- 良品处理：{重新上架/原库位不动/其他}
- 不良品处理：{不良品库位上架/销毁/退回客户/其他}

【操作步骤】
1. 从指定库位取出商品
2. 按检测要求逐一检测
3. 按判定标准分类
4. 良品按要求处理
5. 不良品按要求处理
6. 系统更新库存状态
```

## 2. 拆分SKU

**模板结构：**
```
【需求背景】
{为什么需要拆分}

【拆分明细】
- 原SKU：{原SKU编码}
- 拆分后SKU-1：{编码} × {数量}
- 拆分后SKU-2：{编码} × {数量}
- （如有更多）

【前置条件】
- 新入库单：{入库单号}
- 标签文件：{是否已提供/文件名}

【操作步骤】
1. 从原SKU库位取出商品
2. 按拆分要求分拣
3. 贴新SKU标签
4. 按新入库单扫描入库
5. 系统确认库存变动
```

## 3. 商品组合

**模板结构：**
```
【需求背景】
{组合原因}

【组合明细】
- 主产品：{SKU} × {数量}
- 配件1：{SKU} × {数量}
- 配件2：{SKU} × {数量}（如有）
- 组合方式：{捆绑/装袋/装盒/缠绕膜/其他}

【前置条件】
- 新入库单：{入库单号}
- 组合后新SKU：{编码}（如需）

【操作步骤】
1. 分别从各库位取出主产品和配件
2. 按组合方式进行组装
3. 贴组合后标签（如需）
4. 按新入库单入库
5. 系统确认
```

```
- 出库单号：{单号}

【检查项】

【操作步骤】
1. 系统取消出库单
2. 检查商品状态
3. 如已拣货则从打包区取回
4. 按新入库单重新入库（或归位）
5. 系统确认
```

## 13-23 场景（简化模板）

### 13. 更换商品生产日期标签
核心字段：SKU、数量、新日期标签内容

### 14. 不良品转良品
核心字段：SKU、数量、原不良品原因、转良品依据

### 15. 更换SKU做不良品上架
核心字段：原SKU、新SKU、数量、不良品原因

### 16. A+包裹更换标签上架
核心字段：A+包裹条码、新入库单号

### 17. 指定位置贴标
核心字段：SKU、库位、标签类型、贴标位置要求

### 18. 包装破损商品更换包材重新上架
核心字段：出库单、WINIT包材型号、新入库单、标签文件

### 19. SN采集+管理方式变更+重新上架
核心字段：案例背景、适用条件、前置条件、SN管理规则

### 20. 库内仓间调拨
核心字段：源仓、目标仓、商品、数量、调拨单

### 21. 良品转不良品上架
核心字段：SKU、数量、转移原因、背景说明

### 22. 异常单：自提单取消出库
核心字段：异常单号、审核要点、短期方案、关闭路径

### 23. WINIT标准包材线下寄件出库
核心字段：包材类型、规格、数量、用途、前置条件（需尾程线下面单）
