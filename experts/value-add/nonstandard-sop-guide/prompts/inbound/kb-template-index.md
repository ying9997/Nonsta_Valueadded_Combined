## 匹配规则

1. 优先完全匹配场景名称
2. 其次匹配关键词（多关键词命中得分更高）
3. 异常名称/编码可作为辅助匹配信号
4. 匹配 B 类 → 进入字段检查 → SOP 生成
5. 匹配 C 类 → 转人工
6. 无匹配 → 视为 C 类转人工
