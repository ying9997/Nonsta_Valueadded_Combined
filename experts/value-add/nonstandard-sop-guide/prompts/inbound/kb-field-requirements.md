# 各场景必填/可选字段及追问话术

> 用途：check-completeness 节点检查字段完整性时参考
> 规则：required=true 的字段缺失时输出对应的 clarificationPrompt 追问客户

---

## 1. 良品/不良品检测

| 字段 | 必填 | 追问话术 |
|------|------|---------|
| 检测SKU | 是 | 请提供需要检测的 SKU 编码 |
| 检测要求 | 是 | 请描述具体的检测要求（如外观检查、功能测试等） |
| 判定标准 | 是 | 良品和不良品的判定标准是什么？ |
| 良品处理 | 是 | 检测为良品后如何处理？（如重新上架、新入库单上架等） |
| 不良品处理 | 是 | 检测为不良品后如何处理？（如不良品库位上架、销毁等） |

---

## 2. 拆分SKU
