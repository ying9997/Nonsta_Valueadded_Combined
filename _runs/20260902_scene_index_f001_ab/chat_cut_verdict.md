# 会话正文切点结论（人工复读，覆盖自动打分）

自动脚本把「飞书摘要里出现确认/提交」打成 L1+L2，**过松**。下面按 F-001 已有切点标准复读：要有「背景/意图 → 追问 → 收到能填/能拦的一刀」。

本轮排除：

- g010 / g011：F-001 然后 B 的前后双场景，不进准确率
- 标准增值 / 库内换标 / 只催审 / 只问到仓时间 / 只靠 WI 误绑

Udesk 标成 both 的多数是 **AI 调研邀请**，不是客服对话。真有来回的只有 B 的 g002、g008、g009。

---

## 结论（先看这个）

| 场景 | 能不能切 L1+L2 | 说明 |
|------|----------------|------|
| F-001 | **1 组可以**（g032） | 靠的是旧 Udesk 空对话 ID 那通（已有切点预览），不是这次飞书 |
| A | **0 组可以双刀** | 飞书是内部催审/问时机；Udesk 是调研短信。最多 1～2 组只能切 L1 |
| B | **2 组可以双刀**（g002；g008+g009 算一通） | 真客服来回 + 飞书写清拍照要求。g024 飞书有方案收束，可当第 3 刀候选（审核员侧，不是客户侧） |

**不是「三个场景各有 1 条金标」。**  
**也不是「飞书已经够切 3 组」。** 飞书大多是群里问背景/催审的一段话，切不出客户侧 L2。能凑的 3 组里，2 组是 B，1 组是旧 F-001；A 还缺。

## 对评测的含义

- 客户侧「背景 → 追问 → 收束」目前 **F-001 1 + B 2**，A 没有。
- 若接受飞书内部讨论当切点，F-001 可再加 g061（只 L1），B 可再加 g024（L1 稳、L2 弱），A 仍只有 g029 这种时机 L1。
