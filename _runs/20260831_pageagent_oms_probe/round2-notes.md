## 失败组（组 E）该怎么处理

| 用例 | 原始信号 | 给人看 | 后面还填不填 |
|------|----------|--------|----------------|
| E-1 框还没出来 | 选择器为空 | 还没有「需求背景说明」，请先选增值服务 | 停 |
| E-3 映射写错 | 选择器为空 | 找不到这个字段，请核对配置 | 停 |
| E-4 编号无效 | `success:false` + index 99999 | 控件编号无效或已过期 | 停 |
| E-5 API 说成功但点错了 | `success:true`，页面是「销毁」 | 已点击但处理方式不是原单上架，实际是销毁 | 停 |
| E-6 链式 | 译不成编号 | 还没有这张服务卡片，请先选处理方式 | 不停填两个框 |

**必须信页面，不信 `success:true`。** E-5 点「销毁」时 PageAgent 回报成功，还连带选出了「上架前包裹销毁」。

**选择器找到 ≠ 现在能点。** E-2 在隐藏的残留 DOM 里仍能找到「入库其他服务需求」。前端要同时看：节点在不在、看不看得见、选中值对不对。
