## 结论

- **判对条数：** v1 = 0/6；只做 A = **1/6**（326295）；A+RAG = **0/6**。
- 任务书 B 类「至少 3 条判对」：这一小试 **未达到**。
- RAG **没有帮助**：唯一被 A 修好的 326295，开 RAG 后又判错；其余 5 条与关 RAG 相同。
- **默认保持 RAG 关闭**（`RAG_ENABLED=0`，跑批不加 `--rag`）。
- **门禁已判定：** 开 RAG 变好条数 **0 < 3** → 40 条整批 **不开 RAG**。

下一步若继续，应针对「不良品三兄弟仍判成检测」「拍照暂存仍走尺重兜底」单独加边界或信号，而不是开 RAG。
