## 总判断

- **不是需求完全看不懂**：6 条里 4 条 LLM 自己的一句话已经接近正确答案（拍照、上架不良品、包裹条码异常）。
- **主要是 prompt 边界 + 规则 A/C 漏网 + 信号重叠**（检测卡和转不良都抢「不良品」；A+ 卡「重新上架」太宽）。

## 修法（已落地）

1. 规则 A：异常名「包裹条码异常」也映射补贴包裹标签，并在 `applyExceptionNameOverride` 强制改回。
2. 规则 C：本轮拍照回传、返回照片后再辨识 → 拍照暂存，不走尺重兜底。
3. 上架不良品且无检测动作 → 不准选检测；质量异常走异常转不良，单品条码无法扫描走良品转不良。
4. 没写 A+ 却写错装/按实际SKU → 外观辨识。
5. 场景卡：拍照/外观/T1 补客户用词；检测卡去掉「不良品」强信号；A+ 去掉过宽的「重新上架」。
