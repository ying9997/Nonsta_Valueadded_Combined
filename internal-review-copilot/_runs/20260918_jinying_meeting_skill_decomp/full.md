# 专家经验原矿（先别封装）
- 事实（系统里长什么样、字段叫什么）
  1. 销毁出库大分类分为「气质出库」、「销毁出库」两类
  2. 仓内销毁由万邑通自有设备在仓库完成压缩破坏，可出具万邑通销毁证明
  3. 专业销毁细分为三类：普货专业销毁、危废专业销毁、TS合规专业销毁
  4. 仓内销毁仅美国站点支持，德国、澳洲、加拿大、英国站点受当地法规和仓库条件限制不支持仓内销毁
  5. IM码无法直接在出库单页面读取商品属性，必须通过商品编码关联后跳转商品信息页查询
  6. 带电纯电池类商品不支持普货销毁
  7. 客户下单增值侧的销毁选项只有「飞标专业销毁询价」，不会直接显示三类专业销毁的选项
  8. TS类销毁商品标记存放在「商品备案管理」页面中
- 判断规则（如果…就…）
  1. 如果客户选的销毁出库商品属于电子元器件、金属、液体类特殊品类，则不可走仓内销毁，只能走气质或专业销毁
  2. 如果商品是带电类商品，则不可选择普货专业销毁，仅支持危废销毁或有备案的TS合规销毁
  3. 如果校验发现客户所选销毁路径不是当前商品当前站点下成本最低的合规路径，且存在多个可选合规路径，则自动提示客户确认是否要切换至更便宜的方案
  4. 如果所有可选销毁路径都不符合商品属性规则，则驳回该询价单让客服联系客户重选
  5. 如果站点非美国站点，则自动隐藏仓内销毁选项，不给客户展示选择入口
- 例外/坑（什么情况下规则失效）
  1. 存在客户在出库单填写IM码，无法直接关联查询属性的情况，必须跳转商品信息页核对商品原始码确认是否为同一商品
  2. 普通无特殊属性的商品比如枕头，本身没有合规销毁的强制限制，客户误选高价专业销毁的情况非常常见
  3. 仓内销毁路径因为站点限制多，下单路径长，客户很容易被前端挡掉看不到选项，直接选了更贵的销毁类型
- 流程步骤（先做什么后做什么）
  1. 审核销毁飞标询价单第一步：先查询对应的出库单
  2. 取出库单里的所有商品SKU信息
  3. 逐个关联查询商品主数据详情，确认商品分类、商品特性
  4. 校验商品属性与所选销毁类型是否匹配合规
  5. 遍历该站点下该商品所有支持的销毁路径，匹配最优低成本方案
  6. 若选的不是最优路径则提示客户确认，否则正常流转审批
- 工具/系统动作（点哪个按钮、查哪张表、找谁确认）
  1. 打开「非增值单审核SOP知识库-新版」定位销毁出库章节
  2. 导航到WINIT后台产品库-适用条件库页面查询销毁方式适用条件
  3. 导航到「商品备案管理」页面检索SKU确认是否为TS合规销毁类
  4. 用商品编码关联查询商品主数据，核对IM码对应的商品原始信息
  5. 前台出库单页选中对应站点，加载站点允许的销毁方式列表
- 质量标准（怎样算做对）
  1. 所有匹配出来的销毁路径必须完全符合站点法规、商品属性限制，没有合规风险
  2. 给客户展示的所有可选路径必须标注预估费用，让客户明确感知价格差异
  3. 校验覆盖率100%，没有属性校验遗漏导致客户选错销毁类型

### match-optimal-lowest-cost-destruction
- 中文名：匹配当前商品当前站点下最低成本合规销毁方案
- 一句话何时启用：拿到商品特殊品类标签、TS标记、站点可用销毁集合后，遍历筛选出所有合规路径中预估费用最低的方案
- 原子性检验：是，输入全参数的情况下可以独立输出最优方案
- 输入：商品品类标签、是否TS备案、站点可用销毁集合
- 输出：返回合规销毁路径列表，按预估费用从小到大排序
- 步骤：1. 用商品品类标签过滤掉该商品不支持的销毁方式 2. 用TS备案标记过滤掉需要TS资质但没有备案的销毁方式 3. 和站点可用销毁集合取交集得到最终合规路径集合 4. 按路径对应预估费用从小到大排序输出
- 硬规则 / 例外：如果合规路径集合为空，直接返回无合规销毁路径结果
- 依赖的其它 skill：judge-goods-special-category、check-ts-product-flag、verify-site-destruction-availability
- 复用场景：所有客户销毁下单自动推荐最优方案场景
- 证据时间戳：22:00-22:40

### generate-destruction-path-suggestion
- 中文名：生成销毁路径优化提示给客户
- 一句话何时启用：校验发现客户选中的销毁路径不是当前最优低成本方案时，生成友好提示告知客户可切换的更优路径
- 原子性检验：是，拿到客户所选路径和最优排序路径即可生成提示语
- 输入：客户选中的销毁类型、按费用升序排列的合规销毁路径列表
- 输出：返回提示文案「检测到您选择的XX销毁，可选更便宜合规的XX销毁，是否确认切换，预计可节省XX费用」
- 步骤：1. 取出排序后的合规路径第一个最低费路径 2. 如果客户选中的销毁路径排序大于1，说明不是最低成本 3. 计算两个路径预估费用差值 4. 拼接生成对应提示文案
- 硬规则 / 例外：如果客户所选路径是唯一合规路径，不需要弹出提示
- 依赖的其它 skill：match-optimal-lowest-cost-destruction
- 复用场景：所有非最优下单路径的客户友好提示场景
- 证据时间戳：23:00-23:40

# 复合工作流（由原子 skill 编排）
1. 销毁增值单审核工作流
   触发：收到客户提交的销毁飞标专业询价单
   skill调用顺序：identify-destruction-type-from-order → fetch-skus-from-outbound-order → 逐SKU执行verify-im-mapping-to-product → 逐SKU执行judge-goods-special-category、check-ts-product-flag → verify-site-destruction-availability → match-optimal-lowest-cost-destruction → generate-destruction-path-suggestion
   停手条件：所有SKU校验通过，确认最终销毁路径，要么正常流转询价要么驳回重下
2. 客户出库单销毁下单引导工作流
   触发：客户在万邑通前台新版出库单页面选中「销毁出库」分类
   skill调用顺序：verify-site-destruction-availability → 客户上传完所有商品SKU后逐SKU执行judge-goods-special-category、check-ts-product-flag → match-optimal-lowest-cost-destruction → 前台自动展示所有合规路径的预估费用，优先高亮最便宜的推荐选项让客户选
   停手条件：客户选中对应销毁类型，进入下一步下单流程
3. 异常销毁单驳回工作流
   触发：审核校验后发现该出库单所有SKU没有共同兼容的合规销毁路径
   skill调用顺序：identify-destruction-type-from-order → 生成驳回通知
   停手条件：客户收到驳回通知，确认重提新单
