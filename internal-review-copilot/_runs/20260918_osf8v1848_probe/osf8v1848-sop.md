# 专业销毁非标询价：OMS SOP 文本框写什么

给审核员看的是：**这张出库单能走哪些万邑通产品、客户已经选了哪个。** 不是绿橙红口号，也不是仓库怎么拆货。

客户选的路在**出库单** `winit_product_name`（库存弃置 / 仓内销毁 / 普货专业销毁 / 危废专业销毁 / TS合规专业销毁），不在增值属性「物理销毁」。

---

## 【审核参考摘要】

（系统拼装，供审核核对，不等于已审核通过。）

### 一、系统事实

- 增值询价单：专业销毁非标询价（OSF8V1848）
- 出库单：WO…
- 仓库 / 国家：…
- **客户已选出库产品：编码 + 名称**（例：OSF831009111 普货专业销毁）
- 商品：商品编号、M码、中文名、是否带电；其它特性未查到要写明

### 二、本单能走哪些出库产品

逐条写能 / 不能 + 原因。价格第一刀用占位：弃置 < 仓内 < 普货专业 < 危废 < TS（待业务价卡替换）。

### 三、和客户已选对比

- 已选是否在允许集合内
- 有没有更便宜且允许的
- 有 → 建议问销售客服要不要改；没有 → 写「不通知，按当前询价走」

---

## 【仓库询价步骤】（产品模板，保留）

1. 仓库报价；
2. 客户若同意报价，仓库开始作业，打包完成后联系销毁公司出库；
3. 销毁完成后，将销毁公司提供的销毁证明上传。
