2. 这类增值服务的 SOP（从存量单生成）

不要写成仓库怎么拆枕头。专家从来没改过这段，99 张都是产品模板：

  1. 仓库报价；
  2. 客户若同意报价，仓库开始作业，打包完成后联系销毁公司出库；
  3. 销毁完成后，将销毁公司提供的销毁证明上传。

这段保留在 SOP 框下半部分。上半部分回填【审核参考摘要】（系统事实 + 规则判断）。危废/TS 细类要写进摘要，第一刀不自动改服务。不代点审核通过。

6. 这个原子要查哪些 API

事实现在有没有第一刀怎么用
仓 / 国家增值单 header 已有非美 → 禁止推荐仓内
出库单号 WOheader.businessNo 已有绑单；缺则红
销毁细类（普货/危废/TS）增值单只有「物理销毁」摘要必写；只有确认普货才建议仓内
出库 SKU / IM / 商品编码增值「商品清单」空摘要必写；美国站建议仓内的前提
商品特性Copilot 还没有接口摘要必写；缺则写未查到、不建议仓内
TS 备案没有摘要写有/无/未查到；第一刀不自动改判
失败要收口，不要猜。 非美只凭仓/国家就能判「不要推荐仓内」。美国「误下专业销毁 → 建议仓内/弃置」必须先确认是普货；出库商品查不到，就转人工。
